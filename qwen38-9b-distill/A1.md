## 出力

```python
import csv
import os
from typing import Optional


def convert_csv_encoding(
    input_path: str,
    output_path: str,
    input_encoding: str = "shift_jis",
    output_encoding: str = "utf-8"
) -> None:
    """
    Shift-JIS 形式の CSV ファイルを読み込み、UTF-8 形式で保存し直す関数。

    Args:
        input_path: 読み込む CSV ファイルのパス。
        output_path: 保存する CSV ファイルのパス。
        input_encoding: 入力ファイルの文字コード（デフォルト: "shift_jis"）。
        output_encoding: 出力ファイルの文字コード（デフォルト: "utf-8"）。

    Raises:
        FileNotFoundError: 入力ファイルが存在しない場合。
        UnicodeDecodeError: 入力ファイルの文字化けが発生した場合。
        UnicodeEncodeError: 出力ファイルの文字化けが発生した場合。
        csv.Error: CSV 形式が不正な場合。
    """
    # ファイル存在チェック
    if not os.path.exists(input_path):
        raise FileNotFoundError(f"入力ファイルが見つかりません: {input_path}")

    # ファイルの読み込み（文字コード変換）
    try:
        with open(input_path, "r", encoding=input_encoding, newline="") as f_in:
            reader = csv.reader(f_in)
            rows = list(reader)
    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(
            f"入力ファイルの文字化けが発生しました: {input_path}",
            e.object,
            e.start,
            e.end,
            e.reason,
        ) from e
    except csv.Error as e:
        raise csv.Error(f"CSV 形式が不正です: {input_path}") from e

    # CSV の書き込み（文字コード変換）
    try:
        with open(output_path, "w", encoding=output_encoding, newline="") as f_out:
            writer = csv.writer(f_out)
            writer.writerows(rows)
    except UnicodeEncodeError as e:
        raise UnicodeEncodeError(
            f"出力ファイルの文字化けが発生しました: {output_path}",
            e.object,
            e.start,
            e.end,
            e.reason,
        ) from e
    except csv.Error as e:
        raise csv.Error(f"CSV 書き込み中にエラーが発生しました: {output_path}") from e


# --- 実行例 ---
if __name__ == "__main__":
    input_file = "input_shift_jis.csv"
    output_file = "output_utf8.csv"

    try:
        convert_csv_encoding(input_file, output_file)
        print(f"変換成功: {input_file} → {output_file}")
    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError as e:
        print(f"エラー: {e}")
    except UnicodeEncodeError as e:
        print(f"エラー: {e}")
    except csv.Error as e:
        print(f"エラー: {e}")
```

## 実装のポイント

| 項目 | 対応内容 |
|------|----------|
| **ファイル存在チェック** | `os.path.exists()` で事前に確認し、存在しない場合は `FileNotFoundError` を発生させる |
| **文字化け（入力）** | `UnicodeDecodeError` を `try/except` でキャッチし、エラーメッセージ付きで再スロー |
| **文字化け（出力）** | `UnicodeEncodeError` を `try/except` でキャッチし、エラーメッセージ付きで再スロー |
| **CSV 形式エラー** | `csv.Error` をキャッチして適切に処理 |
| **newline 処理** | `newline=""` を指定することで、Windows/Linux 両方で改行コードを正しく処理 |

## 使用例

```python
convert_csv_encoding("input_shift_jis.csv", "output_utf8.csv")
```

## 注意点

- `newline=""` を指定することで、Python 3 の CSV モジュールがプラットフォームに依存しない改行コードを生成します。
- 出力ファイルが既に存在する場合、上書きされます（必要であれば `os.path.exists()` で確認し、警告を出すように拡張できます）。
- 文字化けが発生した場合は、元のファイルのエンコーディングが実際には Shift-JIS ではない可能性があります（例：UTF-8 で Shift-JIS の文字が含まれている場合など）。その場合はエンコーディングを指定し直す必要があります。
