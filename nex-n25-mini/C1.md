## 2. 基本的な使い方

### データベース接続

```python
from sakura_orm import connect

db = connect("sqlite:///example.db")
```

`sqlite:///example.db` は、SQLiteデータベースを意味します。  
PostgreSQLやMySQLを使う場合は、例えば次のようにします。

```python
db = connect("postgresql://user:password@localhost:5432/mydb")
```

## 3. モデル定義

```python
from sakura_orm import Model, Column, Integer, String, DateTime
from datetime import datetime

class User(Model):
    id = Column(Integer, primary_key=True)
    name = Column(String(100), nullable=False)
    email = Column(String(255), unique=True)
    created_at = Column(DateTime, default=datetime.utcnow)
```

ここでは、`User` というモデルを定義しています。

- `id` は主キー
- `name` は必須
- `email` は一意
- `created_at` は自動で現在時刻が入る

---

## 4. テーブル作成

```python
db.create_all([User])
```

## 6. データ取得

### 全件取得

```python
users = db.query(User).all()

for user in users:
    print(user.name)
```

### 条件指定

```python
user = db.query(User).filter_by(email="alice@example.com").first()
```

### 複数条件

```python
users = db.query(User).filter(
    User.name.like("%A%"),
    User.email.like("%example.com%")
).all()
```

## 9. リレーションを使う例

例えば、`User` と `Post` の関係を定義する場合です。

```python
class Post(Model):
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, nullable=False)
    title = Column(String(200), nullable=False)
    body = Column(String(1000))
```

`User` に `posts` リレーションを追加します。

```python
class User(Model):
    id = Column(Integer, primary_key=True)
    name = Column(String(100), nullable=False)
    email = Column(String(255), unique=True)

    posts = Relation("Post", foreign_key="user_id")
```

## 14. 実用的なサンプル

```python
from sakura_orm import connect, Model, Column, Integer, String, DateTime
from datetime import datetime

db = connect("sqlite:///sakura.db")

class User(Model):
    id = Column(Integer, primary_key=True)
    name = Column(String(100), nullable=False)
    email = Column(String(255), unique=True)
    created_at = Column(DateTime, default=datetime.utcnow)

class Post(Model):
    id = Column(Integer, primary_key=True)
    user_id = Column(Integer, nullable=False)
    title = Column(String(200), nullable=False)
    body = Column(String(1000))

db.create_all([User, Post])

user = User(name="Alice", email="alice@example.com")
db.add(user)
db.commit()

post = Post(
    user_id=user.id,
    title="Hello World",
    body="This is my first post."
)

db.add(post)
db.commit()

users = db.query(User).all()
for u in users:
    print(u.name, u.email)

posts = db.query(Post).filter_by(user_id=user.id).all()
for p in posts:
    print(p.title, p.body)
```

## まとめ

基本的な流れは次のようになります。

```python
# 1. 接続
db = connect("sqlite:///example.db")

# 2. モデル定義
class User(Model):
    ...

# 3. テーブル作成
db.create_all([User])

# 4. 作成
db.add(user)
db.commit()

# 5. 取得
users = db.query(User).all()

# 6. 更新
user.name = "New Name"
db.commit()

# 7. 削除
db.delete(user)
db.commit()
```

もし `sakura-orm` の具体的なドキュメントやパッケージ名、API仕様があれば、それに合わせてより正確なコード例に修正できます。
