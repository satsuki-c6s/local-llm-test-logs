# sakura-orm の基本使い方

`sakura-orm` は、PythonのORMライブラリです。以下に基本の使い方をコード例付きで紹介します。

## 1. インストール

```bash
pip install sakura-orm
```

## 2. モデル定義

```python
from sakura_orm import SakuraORM, BaseModel

class User(BaseModel):
    id: int
    name: str
    email: str
    age: int = 0
```

## 3. データベース接続

```python
from sakura_orm import SakuraORM

db = SakuraORM("sqlite:///sakura.db")
```

## 4. クエリ実行

```python
# 全件取得
users = db.query(User).all()

# 条件付き取得
adults = db.query(User).filter(User.age > 18).all()

# 1件取得
user = db.query(User).first()

# 件数カウント
count = db.query(User).count()

# 更新
db.query(User).filter(User.id == 1).update({"age": 25})

# 削除
db.query(User).filter(User.id == 1).delete()

# 追加
db.add(User(id=2, name="山田", email="yama@example.com", age=30))
db.commit()
```

## 5. 詳細な使い方

```python
# 複数件取得
users = db.query(User).filter(User.age > 18).order_by(User.age.desc()).limit(10).all()

# 集計
total_age = db.query(User).filter(User.age > 18).sum(User.age)

# 関連付け
class Order(BaseModel):
    id: int
    user_id: int
    amount: float

order = db.query(Order).filter(Order.user_id == user.id).first()
```

## 6. エラー処理

```python
try:
    db.query(User).filter(User.id == 999).first()
except SakuraORMError as e:
    print(f"エラー: {e}")
```

## 7. 接続のクローズ

```python
db.close()
```

## 8. 追加の機能

```python
# 一括追加
db.add_all([User(id=1, name="山田", email="a@example.com", age=20),
            User(id=2, name="鈴木", email="b@example.com", age=25)])

# 一括更新
db.update(User, {"age": 21})

# 一括削除
db.delete_all(User)

# 接続のクローズ
db.close()
```

## 9. 関連付けの例

```python
class User(BaseModel):
    id: int
    name: str
    email: str
    age: int = 0
    orders: list[Order] = []

# 関連付けの追加
user = db.add(User(id=1, name="山田", email="a@example.com", age=20))
db.add(Order(id=1, user_id=1, amount=1000.0))
db.commit()

# 関連付けの取得
orders = user.orders
```
