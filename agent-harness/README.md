# エージェントハーネス検証シリーズ — 生ログ

YouTube「さつきのOSS研究室」エージェントハーネス検証シリーズの、採点前の実行ログです。
共通ハーネス OpenClaw 2026.7.1-2 (Ollama native API・ツール6種・スキル0・1課題ごとに状態を新規作成) に
ローカルモデルを載せ替え、同じ3課題 (T1 修正 / T2 調査 / T3 作成) を流しています。課題文・判定条件は実行前に固定しています。

- `<model>/<task>/task.md` — モデルに渡した課題文そのまま
- `<model>/<task>/transcript.md` — セッションログから、ツール呼び出し・ツール結果・アシスタント本文だけを抜き出したもの (システムプロンプトは OpenClaw 由来のため省略。作業ディレクトリのパスは `<runDir>` に伏せています)
- `<model>/<task>/result.json` — 判定器の出力 (段・理由・要件ごとの実測)・ツール呼び出し回数 (2ルート)・所要時間・外部接続の有無
- `<model>/<task>/workspace-diff.json` — フィクスチャと作業後の差分 (追加/変更/削除ファイル)

WikiSkill 回 (`ws-*`) では、モデルが自分の実行ログから書いたパターンとスキルの実物を
`ws-memories/` に置いています。`<model>.json` はフィルタ前 (`patternsRaw` / `skillsRaw`) と
フィルタ後 (`patterns` / `skills`) と除外分 (`*Excluded`) をすべて含み、
`<model>-AGENTS.md` は2周目に実際に注入した AGENTS.md そのものです。

判定は機械で行い、モデルの自己申告は使っていません。900 秒到達は無条件 ×。
