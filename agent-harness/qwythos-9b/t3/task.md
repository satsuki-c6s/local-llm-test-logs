ワークスペース直下の project フォルダです。作業が終わったら、何をしたかを3行以内で報告してください。

ブラウザで動くToDoアプリを、外部ライブラリやCDNを使わず、単一のHTMLファイル1つだけで作ってください。要件: (1) テキスト入力と追加ボタンでタスクを追加できる (2) 各タスクはチェックで完了/未完了を切り替えられる (3) 各タスクは削除できる (4) 各タスクはダブルクリックで内容を編集できる (5) 「すべて/未完了/完了」の3つのフィルタ切り替えがある (6) 未完了タスクの件数が表示される (7) localStorageに保存され、リロードしても消えない。
ファイルは project/todo.html として保存してください。保存したら、ローカルHTTPサーバーを起動して todo.html が HTTP 200 で取得できることを自分で確認し、確認後にそのサーバーを停止してください。
