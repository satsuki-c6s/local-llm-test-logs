# sakura-orm の基本使い方

`sakura-orm` は、Python 向けの軽量な ORM ライブラリです。以下に基本の使い方をご紹介します。

## 1. インストール

```bash
pip install sakura-orm
```

## 2. モデルの定義

```python
from sakura_orm import SakuraORM, Model, Column, String, Integer, DateTime, ForeignKey, Relationship

class User(Model):
    id = Column(Integer, primary_key=True)
    name = Column(String, nullable=False)
    email = Column(String, unique=True, nullable=False)
    age = Column(Integer, default=0)
    created_at = Column(DateTime, default=datetime.now)

    # 1対多の関連付け
    posts = Relationship("Post", backref="user")
```

## 3. データベースの初期化

```python
from sakura_orm import SakuraORM

db = SakuraORM("sakura.db")
db.create_all()  # テーブルを作成
```

## 4. データの追加

```python
user = User(name="山田花子", email="hanako@example.com", age=28)
db.add(user)
db.commit()  # 変更をコミット
```

## 5. データの取得

```python
# 1件取得
user = db.query(User).first()

# 複数件取得
users = db.query(User).all()

# 条件付き取得
adults = db.query(User).filter(User.age > 20).all()

# 1件取得（条件付き）
user = db.query(User).filter(User.email, "hanako@example.com").first()

# 件数カウント
count = db.query(User).count()

# 合計
total_age = db.query(User).sum(User.age)
```

## 6. 更新と削除

```python
# 更新
user = db.query(User).filter(User.id, user.id).first()
user.age = 29
db.commit()

# 削除
db.delete(user)
db.commit()
```

## 7. 関連付けの操作

```python
# 1対多の追加
post = Post(title="こんにちは", content="世界", user=user)
db.add(post)
db.commit()

# 関連付けの取得
posts = user.posts.all()

# 関連付けの更新
post.title = "更新されたタイトル"
db.commit()

# 関連付けの削除
db.delete(post)
db.commit()
```

## 8. 複数件追加・削除

```python
# 複数件追加
users = [User(name="太郎", email="taro@example.com"),
         User(name="次郎", email="jiro@example.com")]
db.add_all(users)
db.commit()

# 複数件削除
db.delete_all(users)
db.commit()
```

## 9. クエリの詳細

```python
# 並び替え
users = db.query(User).order_by(User.age, desc=True).all()

# 制限とオフセット
users = db.query(User).limit(10).offset(5).all()

# 集計
avg_age = db.query(User).avg(User.age)
```

## 10. 接続のクローズ

```python
db.close()
```

## 注意点

- `db.commit()` は必ず実行してください
- 変更後のコミット忘れでデータが失われることがあります
- 関連付けの操作は必ずコミットしてください
- 接続は使用後に必ずクローズしてください
