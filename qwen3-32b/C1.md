## 出力

`sakura-orm` は Python 用の軽量な ORM（Object-Relational Mapping）ライブラリで、データベース操作をコードで簡潔に書くことを目的としています。ただし、このライブラリは非常にニッチで、一般的な ORM（例: SQLAlchemy、Django ORM）ほど広く使われているわけではありません。そのため、公式ドキュメントやコミュニティサポートが限られている可能性があります。

以下に、`sakura-orm` の基本的な使い方をコード例付きで説明します。ただし、ライブラリが変更されている可能性があるため、最新の情報は公式リポジトリやドキュメントを参照してください。

---

## 🌸 1. インストール

まず、`sakura-orm` を pip でインストールします。

```bash
pip install sakura-orm
```

---

## 🌸 2. データベース接続

`sakura-orm` は SQLite、MySQL、PostgreSQL などに対応しています。ここでは SQLite を例に使います。

```python
from sakura.orm import create_engine, Model, Column, Integer, String

# SQLite データベースに接続
engine = create_engine('sqlite:///example.db')
```

---

## 🌸 3. モデルの定義

モデルはデータベースのテーブルを Python クラスで表現します。

```python
class User(Model):
    __tablename__ = 'users'

    id = Column(Integer, primary_key=True)
    name = Column(String(50))
    email = Column(String(100))

# モデルをデータベースに反映
User.metadata.create_all(engine)
```

---

## 🌸 4. データの挿入

```python
from sakura.orm.session import sessionmaker

Session = sessionmaker(bind=engine)
session = Session()

# データを挿入
new_user = User(name='Taro', email='taro@example.com')
session.add(new_user)
session.commit()
```

---

## 🌸 5. データの取得（クエリ）

```python
# 全件取得
users = session.query(User).all()
for user in users:
    print(f"ID: {user.id}, Name: {user.name}, Email: {user.email}")

# 条件付き取得
user = session.query(User).filter(User.name == 'Taro').first()
print(f"Found: {user.name}")
```

---

## 🌸 6. データの更新

```python
user = session.query(User).filter(User.name == 'Taro').first()
user.email = 'taro_new@example.com'
session.commit()
```

---

## 🌸 7. データの削除

```python
user = session.query(User).filter(User.name == 'Taro').first()
session.delete(user)
session.commit()
```

---

## 🌸 8. セッションのクローズ

```python
session.close()
```
