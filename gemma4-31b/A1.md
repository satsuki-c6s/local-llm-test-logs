```
PythonでShift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数を書いてください。
存在しないファイルと文字化け(デコード失敗)のエラー処理も含めてください。
```

## 出力

PythonでShift-JIS（CP932）のCSVを読み込み、UTF-8で保存する関数を作成します。

実務上のポイントとして、Windowsで作成されたCSVは厳密には`shift_jis`ではなく、拡張版である`cp932`（Microsoftコードページ932）であることが多いため、ここではより汎用性の高い`cp932`を指定しています。

### サンプルコード

```python
import csv
import os

def convert_sjis_to_utf8(input_file, output_file):
    """
    Shift-JIS (CP932) のCSVファイルを読み込み、UTF-8で保存する。
    
    Args:
        input_file (str): 読み込み元のファイルパス
        output_file (str): 保存先のファイルパス
    """
    try:
        # 1. ファイルの存在確認
        if not os.path.exists(input_file):
            raise FileNotFoundError(f"指定されたファイルが見つかりません: {input_file}")

        # 2. Shift-JIS (CP932) で読み込み
        # newline='' はCSV読み込み時の推奨設定です
        with open(input_file, mode='r', encoding='cp932', newline='') as f_in:
            reader = csv.reader(f_in)
            data = list(reader)

        # 3. UTF-8 で書き出し (BOMなしUTF-8)
        with open(output_file, mode='w', encoding='utf-8', newline='') as f_out:
            writer = csv.writer(f_out)
            writer.writerows(data)
            
        print(f"成功: {input_file} -> {output_file} に変換しました。")

    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError:
        print(f"エラー: 文字コードのデコードに失敗しました。ファイルがShift-JIS形式ではない可能性があります。")
    except PermissionError:
        print(f"エラー: ファイルへのアクセス権限がありません。ファイルが開いたままになっていないか確認してください。")
    except Exception as e:
        print(f"予期せぬエラーが発生しました: {e}")

# --- 動作テスト ---
if __name__ == "__main__":
    # テスト用のダミーファイル作成 (Shift-JIS)
    test_sjis = "sample_sjis.csv"
    with open(test_sjis, "w", encoding="cp932") as f:
        f.write("名前,年齢\n田中,25\n佐藤,30")

    # 正常系テスト
    convert_sjis_to_utf8(test_sjis, "sample_utf8.csv")

    # 異常系テスト：存在しないファイル
    convert_sjis_to_utf8("non_existent.csv", "out.csv")
```

### 解説

#### 1. 文字コードの選択 (`cp932`)
Pythonの`shift_jis`は標準的な規格ですが、Windows特有の機種依存文字（例：①や㈱など）が含まれているとエラーになります。`cp932`を指定することで、これらの文字も正しく処理できます。

#### 2. エラー処理の内容
*   **`FileNotFoundError`**: `os.path.exists()` で事前にチェックし、ファイルがない場合に明示的なメッセージを出します。
*   **`UnicodeDecodeError`**: 指定したエンコーディング（CP932）で読み込めなかった場合に発生します。これにより「実はUTF-8だった」あるいは「全く別の文字コードだった」ことを検知できます。
*   **`PermissionError`**: Windowsなどで、保存先のファイルがExcel等で開かれたままだと書き込みができずこのエラーが発生するため、追加しています。

#### 3. CSV操作のポイント
*   **`newline=''`**: `csv`モジュールを使用する際、OSによる改行コードの自動変換を防ぐために必須の設定です（これを忘れると空行が入ることがあります）。
*   **メモリ消費について**: 上記コードは一度 `list(reader)` で全データをメモリに読み込んでいます。もし数GBあるような超巨大なCSVファイルを扱う場合は、`for row in reader:` を使って1行ずつ書き出すループ処理に変更してください。

### (補足) 巨大なファイルに対応させる場合
データ量が非常に多い場合は、以下のように書き出し部分をループにします。

```python
        with open(input_file, mode='r', encoding='cp932', newline='') as f_in, \
             open(output_file, mode='w', encoding='utf-8', newline='') as f_out:
            reader = csv.reader(f_in)
            writer = csv.writer(f_out)
            for row in reader:
                writer.writerow(row)
```
