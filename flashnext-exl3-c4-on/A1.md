## プロンプト

```
PythonでShift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数を書いてください。
存在しないファイルと文字化け(デコード失敗)のエラー処理も含めてください。
```

## 出力

以下は、Shift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数です。  
存在しないファイルと、Shift-JISとしてデコードできない場合のエラー処理を含めています。

```python
from pathlib import Path
import csv
from typing import Union


def convert_shift_jis_csv_to_utf8(
    src_path: Union[str, Path],
    dst_path: Union[str, Path],
    *,
    encoding: str = "shift_jis",
    dst_encoding: str = "utf-8",
) -> bool:
    """
    Shift-JISのCSVをUTF-8のCSVに変換する。

    成功: True
    失敗: False
    """
    src = Path(src_path)
    dst = Path(dst_path)

    try:
        # 出力先のフォルダが存在しない場合は作成
        dst.parent.mkdir(parents=True, exist_ok=True)

        # Shift-JISで読み込み
        with src.open("r", encoding=encoding, newline="", errors="strict") as fin:
            reader = csv.reader(fin)

            # UTF-8で書き込み
            with dst.open("w", encoding=dst_encoding, newline="", errors="strict") as fout:
                writer = csv.writer(fout)

                for row in reader:
                    writer.writerow(row)

        return True

    except FileNotFoundError:
        print(f"エラー: 入力ファイルが見つかりません: {src}")
        return False

    except UnicodeDecodeError as e:
        print(f"エラー: {encoding}としてデコードできませんでした: {src}")
        print(f"詳細: {e}")
        return False

    except OSError as e:
        print(f"エラー: ファイル入出力に失敗しました: {e}")
        return False
```

使用例:

```python
if __name__ == "__main__":
    ok = convert_shift_jis_csv_to_utf8("input.csv", "output.csv")

    if ok:
        print("変換完了")
    else:
        print("変換失敗")
```

ポイント:

- `encoding="shift_jis"` でShift-JISとして読み込みます。
- `dst_encoding="utf-8"` でUTF-8として書き込みます。
- `errors="strict"` を明示しているため、文字化け・デコード失敗時は `UnicodeDecodeError` が発生します。
- `newline=""` はCSVを正しく扱うために重要です。
- ExcelでUTF-8のCSVを開くときに文字化けする場合は、出力を `utf-8-sig` にするとよいことがあります。

```python
convert_shift_jis_csv_to_utf8(
    "input.csv",
    "output.csv",
    dst_encoding="utf-8-sig"
)
```

補足:  
WindowsのShift-JIS互換文字コードで保存されたCSVの場合、`shift_jis` ではなく `cp932` の方がうまくいくことがあります。

```python
convert_shift_jis_csv_to_utf8(
    "input.csv",
    "output.csv",
    encoding="cp932"
)
```
