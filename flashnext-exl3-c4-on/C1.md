## 2. 認証情報の設定

さくらのクラウド API を使う場合は、API トークンとゾーンが必要です。

```bash
export SAKURA_ACCESS_TOKEN="your-access-token"
```


## 5. サーバーを作成する

```python
server = client.servers.create(
    name="web-server",
    server_plan="2-4096",
    disks=[
        {
            "id": "disk-id",
        }
    ],
    interfaces=[
        {
            "switch": {
                "id": "switch-id",
            }
        }
    ],
)

print(server.id)
print(server.name)
```

※ `server_plan` や `disks`, `interfaces` の指定方法は、ライブラリのバージョンや API 仕様によって異なる場合があります。

## 14. 実用的な例：存在するサーバーだけを表示する

```python
from sakura_orm import Client

client = Client(
    access_token="your-access-token",
    zone="is1a",
)

servers = client.servers.list()

for server in servers:
    if server.status == "up":
        print(f"稼働中: {server.name} ({server.id})")
    else:
        print(f"停止中: {server.name} ({server.id})")
```

## 15. 実用的な例：指定名前のサーバーを作成する

```python
from sakura_orm import Client

client = Client(
    access_token="your-access-token",
    zone="is1a",
)

server_name = "web-server"

existing = client.servers.filter(name=server_name)

if existing:
    print("同名のサーバーが既に存在します。")
else:
    server = client.servers.create(
        name=server_name,
        server_plan="2-4096",
        disks=[
            {
                "id": "disk-id",
            }
        ],
        interfaces=[
            {
                "switch": {
                    "id": "switch-id",
                }
            }
        ],
    )

    print("サーバーを作成しました:", server.id)
```

## 16. もし `sakura-orm` が一般的な DB ORM 版だった場合

もし `sakura-orm` がさくらのクラウド API 用ではなく、一般的なデータベース ORM として提供されている場合は、以下のような使い方になることが多いです。

```python
from sakura_orm import Sakura, Model, fields

db = Sakura("sqlite:///sakura.db")


class User(Model):
    name = fields.CharField(max_length=100)
    email = fields.CharField(max_length=255, unique=True)
    age = fields.IntegerField(null=True)


db.create_tables([User])


# 作成
user = User.create(
    name="山田太郎",
    email="taro@example.com",
    age=30,
)

print(user.id)
print(user.name)


# 取得
user = User.objects.get(email="taro@example.com")
print(user.name)


# 更新
user.age = 31
user.save()


# 絞り込み
users = User.objects.filter(age__gte=30)

for user in users:
    print(user.name, user.age)


# 削除
User.objects.filter(name="山田太郎").delete()
```

## 17. 注意点

- `sakura-orm` はバージョンによって API が変わる可能性があります。
- `client.servers` ではなく `client.server` のように、リソース名が単数形の場合もあります。
- `create()` の引数名も、実際のライブラリ仕様に合わせてください。
- API トークンはコードに直接書かず、環境変数やシークレット管理を使うことをおすすめします。
- 本番環境でリソースを削除・作成する前に、テスト環境で動作確認してください。

## まとめ

`sakura-orm` の基本的な流れは、次のようになります。

```python
from sakura_orm import Client

client = Client(
    access_token="your-access-token",
    zone="is1a",
)

# 一覧取得
servers = client.servers.list()

# 取得
server = client.servers.get(id="123456789012")

# 作成
server = client.servers.create(name="web-server")

# 更新
server.name = "web-server-2"
server.update()

# 削除
server.delete()
```

まずは公式 README やサンプルコードで、実際のクラス名・メソッド名を確認してから使うのが安全です。
