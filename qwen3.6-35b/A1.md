以下は、Shift-JIS の CSV ファイルを読み込み、UTF-8 で保存し直す Python 関数の例です。存在しないファイルやデコードエラー（文字化け）に対するエラー処理も含まれています。

```python
import csv
import os

def convert_sjis_to_utf8(input_file, output_file):
    """
    Shift-JIS の CSV ファイルを読み込み、UTF-8 で保存し直す関数
    
    Args:
        input_file (str): 入力ファイルのパス（Shift-JIS）
        output_file (str): 出力ファイルのパス（UTF-8）
        
    Raises:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: デコードに失敗した場合（文字化け）
        Exception: その他の予期せぬエラー
    """
    # ファイルの存在確認
    if not os.path.exists(input_file):
        raise FileNotFoundError(f"入力ファイル '{input_file}' が見つかりません。")

    try:
        # Shift-JIS で読み込み
        with open(input_file, 'r', encoding='shift_jis') as f_in:
            reader = csv.reader(f_in)
            
            # UTF-8 で書き出し
            with open(output_file, 'w', encoding='utf-8', newline='') as f_out:
                writer = csv.writer(f_out)
                
                for row in reader:
                    writer.writerow(row)
                    
        print(f"変換完了: '{input_file}' -> '{output_file}'")
        
    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(
            f"デコードエラー: ファイル '{input_file}' の読み込み中に文字化けが発生しました。",
            str(e)
        ) from e
        
    except Exception as e:
        raise Exception(f"予期せぬエラーが発生しました: {str(e)}") from e

# 使用例
if __name__ == "__main__":
    input_path = "input.csv"   # Shift-JIS のCSVファイル
    output_path = "output_utf8.csv"  # UTF-8 で保存されるファイル
    
    try:
        convert_sjis_to_utf8(input_path, output_path)
    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError as e:
        print(f"デコードエラー: {e}")
    except Exception as e:
        print(f"予期せぬエラー: {e}")
```

### 主なポイント

1. **ファイルの存在確認**: `os.path.exists()` で入力ファイルが存在するか事前にチェックし、存在しない場合は `FileNotFoundError` を発生させます。
2. **Shift-JIS の読み込み**: `encoding='shift_jis'` を指定して CSV ファイルを読み込みます。
3. **UTF-8 での書き出し**: `encoding='utf-8'` を指定して、変換後のデータを UTF-8 で保存します。
4. **エラー処理**:
   - `UnicodeDecodeError`: デコード失敗（文字化け）をキャッチし、適切なメッセージを表示します。
   - `Exception`: その他の予期せぬエラーをキャッチします。
5. **CSV の扱い**: `csv` モジュールを使用して、行ごとのデータを正しく読み書きします。

### 使用方法

この関数を使用するには、以下の手順に従ってください：

1. Shift-JIS でエンコードされた CSV ファイル（例: `input.csv`）を作成または準備します。
2. 上記のコードを Python スクリプトとして保存し、実行します。
3. エラーが発生しない場合、UTF-8 でエンコードされた CSV ファイル（例: `output_utf8.csv`）が生成されます。

### 注意事項

- **改行コード**: Windows では `\r\n`、Linux/macOS では `\n` が一般的です。`newline=''` を指定することで、CSV モジュールが改行を適切に処理します。
- **エンコーディングの確認**: 入力ファイルが実際に Shift-JIS でエンコードされていることを確認してください。異なるエンコーディングの場合、エラーが発生する可能性があります。

この関数を使用することで、Shift-JIS の CSV ファイルを UTF-8 に変換し、文字化けやファイル不存在のエラーを適切に処理できます。
