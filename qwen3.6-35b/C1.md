### ✅ 代替案：一般的なPython ORMの使い方（SQLAlchemyを例に）

もしORMの基本的な使い方を学びたいのであれば、最も広く使われている **SQLAlchemy** の例を示します。これが「sakura-orm」の代わりに使える標準的な知識です。

#### インストール
```bash
pip install sqlalchemy
```

#### 基本コード例（モデル定義・CRUD操作）

```python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base, sessionmaker

# 1. データベース接続（SQLiteをメモリ上に作成）
engine = create_engine('sqlite:///:memory:', echo=True)
Base = declarative_base()

# 2. モデル定義（テーブルの構造）
class User(Base):
    __tablename__ = 'users'
    
    id = Column(Integer, primary_key=True)
    name = Column(String(50), nullable=False)
    email = Column(String(100), unique=True)

# テーブル作成
Base.metadata.create_all(engine)

# セッションの準備
Session = sessionmaker(bind=engine)
session = Session()

# --- CRUD操作例 ---

# CREATE: データ追加
new_user = User(name="Taro Yamada", email="taro@example.com")
session.add(new_user)
session.commit()  # 確定

# READ: データ取得
user = session.query(User).filter_by(name="Taro Yamada").first()
print(f"名前: {user.name}, メール: {user.email}")

# UPDATE: データ更新
user.email = "taro_new@example.com"
session.commit()

# DELETE: データ削除
session.delete(user)
session.commit()

# セッションクローズ
session.close()
```
