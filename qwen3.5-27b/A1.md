## 出力

ご要望に合わせて、Shift-JIS 形式の CSV ファイルを UTF-8 に変換して上書き（または別名で保存）する関数を作成しました。

この実装では以下の点を考慮しています：
1. **ファイル存在チェック**: `os.path.exists` で事前確認を行い、 FileNotFoundError を明確に扱います。
2. **デコードエラー処理**: Shift-JIS として読み込めない文字が含まれている場合（例: バイナリデータや破損した行）をキャッチし、詳細なエラーメッセージを表示します。
3. **BOM の扱い**: UTF-8 で保存する際、Windows Excel などで正しく表示されるよう `utf-8-sig` エンコーディングを使用しています（必要であれば標準の `utf-8` に変更可能です）。

### Python コード例

```python
import os
import csv
from typing import Optional, Union

def convert_csv_encoding(
    input_path: str, 
    output_path: Optional[str] = None,
    source_encoding: str = 'shift_jis',
    target_encoding: str = 'utf-8-sig'  # Excel で正しく表示されるよう BOM を含める場合が多いです。不要なら 'utf-8' に変更してください。
) -> bool:
    """
    Shift-JIS の CSV ファイルを UTF-8 (または指定されたエンコーディング) に変換して保存します。

    Args:
        input_path: 入力ファイルのパス（Shift-JIS）。
        output_path: 出力ファイルのパス。None の場合は、元のファイル名の後に '_utf8' を付けて上書きしない形で保存されます。
                     (例：data.csv -> data_utf8.csv)
        source_encoding: ソースエンコーディング（デフォルトは shift_jis）。
        target_encoding: ターゲットエンコーディング（デフォルトは utf-8-sig）。

    Returns:
        bool: 成功した場合は True、失敗した場合は False を返します。
    
    Raises:
        FileNotFoundError: ファイルが存在しない場合のエラーを明示的に扱います（ここではログ出力しFalseを返す設計にしています）。
        UnicodeDecodeError: デコードエラーが発生した場合の処理を行います。
    """

    # 1. 入力ファイルパスの確認と設定
    if not os.path.exists(input_path):
        print(f"【エラー】指定されたファイルが見つかりません：{input_path}")
        return False

    # 出力先が指定されていない場合、元のファイル名の前に '_utf8' を付与して保存します。
    # ※上書き（同じパスで保存）したい場合は output_path=input_path と引数に渡してください。
    if output_path is None:
        base_name = os.path.splitext(input_path)[0]
        ext = os.path.splitext(input_path)[1]
        output_path = f"{base_name}_utf8{ext}"

    try:
        # 2. Shift-JIS で読み込み、UTF-8 で書き出し
        with open(input_path, 'r', encoding=source_encoding, errors='strict') as src_file:
            reader = csv.reader(src_file)
            
            # データをメモリに一時保存（大規模ファイルの場合はストリーム処理が必要ですが、簡易関数としてリスト化します）
            rows = list(reader)

        with open(output_path, 'w', encoding=target_encoding, newline='') as dst_file:
            writer = csv.writer(dst_file)
            for row in rows:
                # 各セルの文字列が正常か確認しつつ書き出し（reader が成功していれば通常は問題ありません）
                writer.writerow(row)

        print(f"【成功】変換完了しました。")
        print(f"入力：{input_path}")
        print(f"出力：{output_path}")
        
        return True

    except FileNotFoundError:
        # os.path.exists で確認済みですが、処理中に削除されたなどの稀なケースのため残します
        print(f"【エラー】ファイルが見つかりませんでした：{input_path}")
        return False
    
    except UnicodeDecodeError as e:
        # Shift-JIS として解釈できない文字が含まれている場合のエラー処理
        line_num = getattr(e, 'line', None) or "不明な行番号"
        print(f"【エラー】ファイルのエンコーディングが正しくないか、破損している可能性があります。")
        print(f"詳細：{e.reason} (行: {line_num}, 位置: {getattr(e, 'start', 'N/A')})")
        return False
    
    except Exception as e:
        # その他の予期せぬエラー（ディスク満タン、権限不足など）
        print(f"【エラー】予期せぬエラーが発生しました：{e}")
        return False

# --- 使用例 ---
if __name__ == "__main__":
    input_file = "sample_shift_jis.csv" # テスト用のファイル名
    
    # ファイルが存在しない場合のテスト用ダミー作成（実際には不要ですが、動作確認のため）
    if not os.path.exists(input_file):
        with open(input_file, 'w', encoding='shift_jis') as f:
            f.write("名前,年齢\n田中太郎,30\n")

    # 変換実行
    success = convert_csv_encoding(
        input_path=input_file, 
        output_path="sample_utf8.csv" # 別名で保存する場合。None にすると自動命名されます。
    )

    if not success:
        print("処理が失敗しました。")
```

### ポイントと解説

1. **エラーハンドリングの設計**:
   - `try-except` ブロック内で、特に `UnicodeDecodeError` を個別にキャッチしています。これにより、「ファイルがない」と「文字化け（エンコーディング不整合）」のエラーを区別してメッセージを出せます。
   - `errors='strict'` オプションを指定することで、変換できない文字が見つかった瞬間に例外が発生し、処理が止まるようにしています（デフォルトですが明示的に記述しました）。

2. **出力ファイル名の自動生成**:
   - 引数で `output_path` を指定しない場合、元のファイル名に `_utf8` を付加して保存します。これにより、元データ（Shift-JIS）を誤って上書きしてしまうリスクを防ぎます。
   - もし「同じパスで上書きしたい」場合は、呼び出し時に `convert_csv_encoding(input_path, output_path=input_path)` と指定してください。

3. **`utf-8-sig` の使用**:
   - 出力エンコーディングをデフォルトで `'utf-8-sig'` にしています。これは UTF-8 の先頭に BOM（Byte Order Mark）を追加する形式です。Windows Excel で CSV を直接開いた際に、日本語が文字化けせずに正しく表示されるため推奨されます。
   - Web サーバーやプログラム間でのデータ受け渡しで BOM が不要な場合は、`target_encoding='utf-8'` に変更してください。

4. **大規模ファイルへの対応**:
   - 上記コードは簡易性を優先し `list(reader)` で一度メモリに読み込んでいます。非常に大きな CSV（数 GB など）を扱う必要がある場合は、行ごとに書き出すストリーム処理に変更する必要がありますが、一般的な業務用サイズであればこの実装で問題ありません。
