## sakura‑orm とは？

`sakura-orm` は「シンプルで直感的に使える Python ORM」です。  
SQLAlchemy のような重厚な機能は持たず、**モデル定義 → CRUD 操作**を最小限のコードで実現できる点が特徴です。

> **主な特徴**  
> * 1 行で DB 接続設定  
> * クラスベースでテーブル・カラムを宣言  
> * `create_table()` / `drop_table()` が自動生成  
> * `filter()`, `get()`, `update()`, `delete()` などのメソッドが用意  
> * SQLite, MySQL, PostgreSQL をサポート（設定で切り替え可）  

以下では、**SQLite** を使った最小構成から実際に CRUD 操作を行うまでをコード例付きで紹介します。

---

## 1. インストール

```bash
pip install sakura-orm
```

> **※注意**  
> * `sakura-orm` は純粋 Python で書かれているため、Python 3.8+ が必要です。  
> * SQLite 以外の DB を使う場合は対応するドライバ（例: `pymysql`, `psycopg2`）を別途インストールしてください。

---

## 2. 基本的な設定

```python
# db.py
from sakura.orm import Database, BaseModel, IntegerField, StringField

# SQLite を使う場合
db = Database(
    driver="sqlite",
    database="example.db",   # ファイル名（相対パス/絶対パス）
)

# MySQL / PostgreSQL なら
# db = Database(driver="mysql", host="localhost", user="root", password="pw", database="test")
```

> `Database` は接続情報を保持し、後でモデルから参照されます。  
> `BaseModel` を継承したクラスが ORM の対象になります。

---

## 3. モデル定義

```python
# models.py
from db import BaseModel, IntegerField, StringField

class User(BaseModel):
    __tablename__ = "users"          # テーブル名（省略可、デフォルトはクラス名の小文字）

    id      = IntegerField(primary_key=True, autoincrement=True)
    name    = StringField(max_length=50, nullable=False)
    email   = StringField(max_length=120, unique=True, nullable=False)

    # 追加でメソッドを定義したい場合は通常のクラスメソッドとして書く
    def __repr__(self):
        return f"<User id={self.id} name={self.name!r}>"
```

> **ポイント**  
> * `primary_key=True` を付けると自動で主キーになります。  
> * `autoincrement=True` は整数型に対してのみ有効です。  
> * `unique=True`, `nullable=False` などの制約も簡単に指定できます。

---

## 4. テーブル作成

```python
# create_tables.py
from db import db
from models import User

def main():
    # 既存テーブルがあれば削除（開発時のみ）
    User.drop_table()
    
    # 新規テーブルを作成
    User.create_table()

if __name__ == "__main__":
    main()
```

> `create_table()` はモデルに定義されたカラム情報から SQL を生成し、実行します。  
> 既存のテーブルがある場合はエラーになるので、開発時は `drop_table()` と組み合わせて使うと便利です。

## 5. CRUD 操作

### 5‑1. レコード挿入（Create）

```python
# insert_user.py
from models import User

def main():
    # インスタンス生成 → save() で INSERT
    user = User(name="太郎", email="taro@example.com")
    user.save()
    
    print("Inserted:", user)   # id が自動で付与される

if __name__ == "__main__":
    main()
```

> `save()` は **INSERT** と **UPDATE** を自動判定します。  
> 新規インスタンスの場合は INSERT、`id` が設定済みの既存レコードの場合は UPDATE になります。

### 5‑2. レコード取得（Read）

```python
# query_user.py
from models import User

def main():
    # 全件取得
    all_users = User.all()
    print("All users:", all_users)

    # 条件付き検索 (WHERE)
    user_by_email = User.filter(email="taro@example.com").first()
    print("Found by email:", user_by_email)

    # ID で取得
    user_by_id = User.get(1)   # primary key が 1 のレコード
    print("By id:", user_by_id)

if __name__ == "__main__":
    main()
```

> `filter()` はチェーン可能。  
> `first()` は最初の結果を返し、`all()` はリストで全件取得します。  
> `get(pk)` は主キー検索（例外が発生する場合もあります）。

### 5‑3. レコード更新（Update）

```python
# update_user.py
from models import User

def main():
    user = User.get(1)
    if user:
        user.name = "次郎"
        user.save()   # UPDATE が実行される
        print("Updated:", user)

if __name__ == "__main__":
    main()
```

> `save()` を呼ぶだけで自動的に UPDATE になります。  
> 変更が無い場合は何もしません。

### 5‑4. レコード削除（Delete）

```python
# delete_user.py
from models import User

def main():
    user = User.get(1)
    if user:
        user.delete()
        print("Deleted:", user)

if __name__ == "__main__":
    main()
```

> `delete()` はレコードを削除します。  
> 返り値は削除されたインスタンスです。

## 6. トランザクション管理

`sakura-orm` は内部で自動コミットを行いますが、複数操作をまとめて一括処理したい場合は `transaction()` コンテキストマネージャーを使えます。

```python
# transaction_example.py
from db import db
from models import User

def main():
    with db.transaction() as conn:
        # ここで行った操作は commit/rollback が自動で管理される
        u1 = User(name="山田", email="yamada@example.com")
        u1.save(conn)   # conn を渡すと同じトランザクション内で実行

        u2 = User(name="佐藤", email="sato@example.com")
        u2.save(conn)

    print("Transaction committed")

if __name__ == "__main__":
    main()
```

> `conn` は内部的に SQLite の `Connection` オブジェクトです。  
> 失敗した場合は自動で rollback されます。

## 7. マイグレーション（簡易版）

`sakura-orm` 自体には高度なマイグレーション機能はありませんが、**テーブル作成・削除をスクリプト化**しておけば手軽にバージョン管理できます。  
例: `migrations/001_create_users.py`

```python
from db import db
from models import User

def upgrade():
    User.create_table()

def downgrade():
    User.drop_table()
```

> 実際のプロジェクトでは Alembic などと組み合わせるか、独自にマイグレーションフレームワークを構築してください。

## 8. よくある質問

| 質問 | 回答 |
|------|------|
| **SQLite 以外の DB は使える？** | はい。`Database(driver="mysql", ...)` のように `driver` を指定すれば MySQL / PostgreSQL も利用可能です。ただし、ドライバ（例: `pymysql`, `psycopg2`）は別途インストールしてください。 |
| **複数テーブル間のリレーションを扱いたい** | 現在はシンプルな ORM のため外部キー制約は自動で作成されませんが、`ForeignKeyField` を使って手動で定義できます。詳細は公式ドキュメントをご覧ください。 |
| **クエリビルダーの高度な機能（JOIN, GROUP BY 等）はある？** | 基本的には `filter()` で WHERE 条件を指定する程度です。複雑な SQL が必要な場合は生の SQL を実行してください (`db.execute(sql, params)`)。 |
| **パフォーマンスが心配** | SQLite は小規模アプリに最適ですが、大量データ・高負荷の場合は PostgreSQL などを検討し、`batch_insert()` 等で一括挿入すると高速化できます。 |

---

## 9. まとめ

- **インストール → Database 設定 → モデル定義** の流れがシンプル  
- `create_table() / drop_table()` でテーブル管理を自動化  
- CRUD は `save()`, `filter()`, `get()`, `delete()` など直感的なメソッドで実装  
- SQLite がデフォルトだが、MySQL/PostgreSQL もサポート  

これらの基本操作を覚えておけば、**小規模・中規模プロジェクト**で手軽にデータベースと連携できます。ぜひ試してみてください！
