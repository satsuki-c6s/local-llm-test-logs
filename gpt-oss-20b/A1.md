## 出力

以下は、Shift‑JIS でエンコードされた CSV ファイルを読み込み、UTF‑8 に変換して別ファイルに保存する関数です。  
* **FileNotFoundError**（存在しないファイル）  
* **UnicodeDecodeError**（文字化け・デコード失敗）  

の2種類のエラーを捕捉し、分かりやすいメッセージで報告します。  
CSV の構造（引用符や区切り文字）は `csv` モジュールで読み書きすることで安全に保たれます。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

import csv
from pathlib import Path
from typing import Optional


def convert_shiftjis_to_utf8(
    src_path: str | Path,
    dst_path: str | Path,
    *,
    src_encoding: str = "shift_jis",
    dst_encoding: str = "utf-8",
    errors: str = "strict",          # デコード失敗時に例外を投げる
) -> Optional[str]:
    """
    Shift‑JIS でエンコードされた CSV ファイルを UTF‑8 に変換して保存する。

    Parameters
    ----------
    src_path : str | Path
        読み込む元ファイルのパス。
    dst_path : str | Path
        書き出す先ファイルのパス。既存の場合は上書きされる。
    src_encoding : str, default "shift_jis"
        元ファイルのエンコーディング（デフォルトは Shift‑JIS）。
    dst_encoding : str, default "utf-8"
        出力ファイルのエンコーディング（デフォルトは UTF‑8）。
    errors : str, default "strict"
        文字列変換時のエラー処理。`"strict"` を指定すると
        デコード失敗で UnicodeDecodeError が発生する。

    Returns
    -------
    Optional[str]
        成功した場合は None、失敗した場合はエラーメッセージを返す。
        (例外を投げたくない場合に便利)

    Raises
    ------
    FileNotFoundError
        src_path が存在しないとき。
    UnicodeDecodeError
        Shift‑JIS から UTF‑8 への変換中に文字化けが発生したとき。

    Notes
    -----
    * CSV の改行は OS に合わせて自動的に処理されます（`newline=''` を指定）。
    * 大きなファイルでもメモリをほとんど消費せずに変換できます。
    """
    src_path = Path(src_path)
    dst_path = Path(dst_path)

    try:
        # 1. Shift‑JIS で読み込み、csv.reader で行単位に分解
        with src_path.open("r", encoding=src_encoding, errors=errors) as f_in:
            reader = csv.reader(f_in)

            # 2. UTF‑8 で書き出し、csv.writer で再構築
            with dst_path.open("w", encoding=dst_encoding, newline="") as f_out:
                writer = csv.writer(f_out)
                for row in reader:
                    writer.writerow(row)

    except FileNotFoundError as e:
        msg = f"エラー: ファイル '{src_path}' が見つかりません。"
        print(msg)
        return msg

    except UnicodeDecodeError as e:
        msg = (
            f"エラー: Shift‑JIS から UTF‑8 への変換中に文字化けが発生しました。\n"
            f"詳細: {e}"
        )
        print(msg)
        return msg

    except Exception as e:
        # その他の予期せぬ例外
        msg = f"予期しないエラーが発生しました: {e}"
        print(msg)
        return msg

    # 成功時は None を返す（例外を投げたくない場合に便利）
    return None


# ------------------------------------------------------------------
# 使い方のサンプル
# ------------------------------------------------------------------
if __name__ == "__main__":
    import argparse

    parser = argparse.ArgumentParser(
        description="Shift‑JIS CSV → UTF‑8 CSV コンバータ"
    )
    parser.add_argument("src", help="入力ファイル（Shift‑JIS）")
    parser.add_argument("dst", help="出力ファイル（UTF‑8）")

    args = parser.parse_args()

    err = convert_shiftjis_to_utf8(args.src, args.dst)
    if err is None:
        print(f"変換完了: '{args.src}' → '{args.dst}'")
```

### 使い方

```bash
$ python sjis2utf8.py input_sjis.csv output_utf8.csv
変換完了: 'input_sjis.csv' → 'output_utf8.csv'
```

#### エラー例

* **ファイルが存在しない**  
  ```text
  エラー: ファイル 'nonexistent.csv' が見つかりません。
  ```

* **文字化け（デコード失敗）**  
  ```text
  エラー: Shift‑JIS から UTF‑8 への変換中に文字化けが発生しました。
  詳細: shift_jis codec can't decode byte 0xXX in position YY: illegal multibyte sequence
  ```

この関数は、Shift‑JIS の CSV を安全に UTF‑8 に落とし込むための最小限の実装です。  
必要に応じて `errors="replace"` や `errors="ignore"` を渡すことで、文字化けを許容した変換も可能です。
