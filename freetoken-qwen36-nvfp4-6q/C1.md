### ✅ 実際のPython ORMライブラリの例：SQLAlchemy

もしORMの基本的な使い方を学びたいのであれば、最も一般的で標準的な **SQLAlchemy** の例を示します。

#### インストール
```bash
pip install sqlalchemy
```

#### 基本的な使い方（コード例）

```python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base, sessionmaker

# 1. データベースエンジンを作成（SQLite例）
engine = create_engine('sqlite:///sakura.db', echo=True)

# 2. ベースクラスを定義
Base = declarative_base()

# 3. モデルを定義
class User(Base):
    __tablename__ = 'users'

    id = Column(Integer, primary_key=True)
    name = Column(String(50), nullable=False)
    email = Column(String(120), unique=True, nullable=False)

    def __repr__(self):
        return f"<User(name='{self.name}', email='{self.email}')>"

# 4. テーブルを作成
Base.metadata.create_all(engine)

# 5. セッションを作成
Session = sessionmaker(bind=engine)
session = Session()

# 6. データを追加
new_user = User(name='Sakura Tanaka', email='sakura@example.com')
session.add(new_user)
session.commit()

# 7. データを取得
users = session.query(User).all()
for user in users:
    print(user)

# 8. セッションを閉じる
session.close()
```
