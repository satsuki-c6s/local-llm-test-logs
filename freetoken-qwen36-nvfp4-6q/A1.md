## 出力

PythonでShift-JISのCSVファイルを読み込み、UTF-8（BOM付き）で保存し直す関数を作成します。

以下のポイントを含めています：
1. **ファイル存在チェック**: `os.path.exists` で確認
2. **デコードエラー処理**: `UnicodeDecodeError` をキャッチ
3. **エンコーディング指定**: 読み込みは `shift_jis`、書き込みは `utf-8`（必要に応じて `utf-8-sig` も可选）
4. **CSV形式の維持**: `csv` モジュールを使用して正しく読み書き

```python
import csv
import os
import sys

def convert_shiftjis_to_utf8(input_path: str, output_path: str, encoding_input: str = 'shift_jis', encoding_output: str = 'utf-8-sig') -> bool:
    """
    Shift-JISのCSVファイルを読み込み、UTF-8で保存し直す。

    Args:
        input_path (str): 入力ファイルのパス（Shift-JIS）
        output_path (str): 出力ファイルのパス（UTF-8）
        encoding_input (str): 入力ファイルのエンコーディング（デフォルト: 'shift_jis'）
        encoding_output (str): 出力ファイルのエンコーディング（デフォルト: 'utf-8-sig'）

    Returns:
        bool: 成功した場合はTrue、失敗した場合はFalse
    """
    # 1. 入力ファイルの存在確認
    if not os.path.exists(input_path):
        print(f"エラー: 入力ファイル '{input_path}' が見つかりません。")
        return False

    # 2. 出力ディレクトリの存在確認（存在しない場合は作成）
    output_dir = os.path.dirname(output_path)
    if output_dir and not os.path.exists(output_dir):
        try:
            os.makedirs(output_dir)
            print(f"出力ディレクトリ '{output_dir}' を作成しました。")
        except Exception as e:
            print(f"エラー: 出力ディレクトリの作成に失敗しました: {e}")
            return False

    try:
        # 3. 入力ファイルの読み込み（Shift-JIS）
        with open(input_path, 'r', encoding=encoding_input, errors='strict') as f_in:
            # csv.readerで読み込む
            reader = csv.reader(f_in)
            rows = list(reader)

        # 4. 出力ファイルへの書き込み（UTF-8）
        with open(output_path, 'w', encoding=encoding_output, newline='') as f_out:
            writer = csv.writer(f_out)
            writer.writerows(rows)

        print(f"成功: '{input_path}' を '{output_path}' に変換しました。")
        return True

    except UnicodeDecodeError as e:
        print(f"エラー: 文字化け（デコード失敗）が発生しました。")
        print(f"  詳細: {e}")
        print(f"  入力ファイル '{input_path}' のエンコーディングが '{encoding_input}' ではない可能性があります。")
        return False

    except Exception as e:
        print(f"エラー: 予期せぬエラーが発生しました。")
        print(f"  詳細: {e}")
        return False


# 使用例
if __name__ == "__main__":
    input_file = "input.csv"   # 変換元のShift-JIS CSVファイル
    output_file = "output.csv" # 変換後のUTF-8 CSVファイル

    success = convert_shiftjis_to_utf8(input_file, output_file)
    if success:
        print("処理が完了しました。")
    else:
        print("処理が失敗しました。")
```

### 補足説明

1. **`encoding_output='utf-8-sig'`**:
   - Excelなどで開く場合、BOM（Byte Order Mark）付きの `utf-8-sig` を推奨します。BOMがないとExcelがShift-JISとして解釈してしまうことがあります。
   - 必要に応じて `'utf-8'`（BOMなし）に変更してください。

2. **`errors='strict'`**:
   - デコード失敗時に明確なエラーを発生させるため、`errors='strict'` を指定しています。これにより、`UnicodeDecodeError` が確実にキャッチされます。

3. **`newline=''`**:
   - CSVファイルの書き込み時に `newline=''` を指定することで、改行コードの扱いがプラットフォームに依存せず、正しく処理されます（Python公式ドキュメント推奨）。

4. **エラーハンドリング**:
   - `UnicodeDecodeError`: 文字コードが正しくない場合
   - `Exception`: その他の予期せぬエラー（ファイルアクセス権限など）

この関数を呼び出す前に、`input.csv` が実際に存在し、Shift-JISでエンコードされていることを確認してください。
