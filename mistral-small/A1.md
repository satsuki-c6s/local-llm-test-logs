## 出力

以下は、Shift-JISでエンコードされたCSVファイルを読み込み、UTF-8で保存するPython関数です。この関数には、存在しないファイルと文字化け（デコード失敗）のエラー処理も含まれています。

```python
import csv
import os

def convert_csv_encoding(input_file, output_file):
    try:
        # 入力ファイルが存在するか確認
        if not os.path.exists(input_file):
            print(f"Error: The file '{input_file}' does not exist.")
            return

        with open(input_file, mode='r', encoding='shift_jis') as infile:
            reader = csv.reader(infile)
            data = list(reader)

        # 出力ファイルをUTF-8で保存
        with open(output_file, mode='w', newline='', encoding='utf-8') as outfile:
            writer = csv.writer(outfile)
            writer.writerows(data)

        print(f"Successfully converted '{input_file}' to '{output_file}'")

    except UnicodeDecodeError:
        print(f"Error: Decoding error occurred while reading the file '{input_file}'. It might be corrupted or not encoded in Shift-JIS.")
    except Exception as e:
        print(f"An unexpected error occurred: {e}")

# 使用例
input_csv = 'input.csv'  # 入力ファイルのパス
output_csv = 'output.csv'  # 出力ファイルのパス
convert_csv_encoding(input_csv, output_csv)
```

この関数は以下のように動作します：

1. `input_file`が存在するか確認し、存在しない場合はエラーを表示して終了します。
2. Shift-JISでエンコードされたCSVファイルを読み込みます。
3. 読み込んだデータをUTF-8で新しいファイルに保存します。
4. デコード失敗（文字化け）が発生した場合や他の例外が発生した場合は、適切なエラーメッセージを表示します。

この関数を使用する際には、`input_csv`と`output_csv`に適切なファイルパスを指定してください。
