#### 2. コード例
以下に「sakura-orm」の基本的な使い方を示します。ここでは、簡単なテーブルを作成し、それを操作するシンプルな例を作成します。

```python
# 1. sakuraura-ormをインポート
from sakuraura import db

# データベース接続情報（例としてローカルホストのSQLiteを使用）
DATABASE_URL = "sqlite:///example.db"

# テーブルの作成
def create_tables():
    db.create_all(DATABASE_URL)
    print("Tables created successfully!")

# テーブル操作の例
def insert_data():
    # サンプルデータを挿入するテーブル（SampleTable）を作成
    sample_table = db.Table("SampleTable")
    sample_table.create()

    # 新しいレコードを挿入
    new_record = SampleRecord(name="Alice", age=30, city="Tokyo")
    sample_table.insert(new_record)

    print("Data inserted successfully!")

# サンプルデータクラスとテーブル定義
class SampleRecord:
    id = db.Column(db.Integer(), primary_key=True)
    name = db.Column(db.String(50), unique=True)
    age = db.Column(db.Integer)
    city = db.Column(db.String())

# テーブル操作関数をインポートして実行
def main():
    create_tables()
    insert_data()

if __name__ == "__main__":
    main()
```

### コード解説
1. インポート: `db`モジュールはORMのデータベース操作に使用されます。また、SQLiteデータベース接続情報として`DATABASE_URL`を定義しています。
2. テーブル作成（create_tables関数）: `create_all`メソッドを使ってデータベース全体を再生成します。この例ではサンプルテーブル「SampleTable」を作成しています。
3. データ挿入（insert_data関数）: `SampleRecord`クラスを用いて、新しいレコードをデータベースに挿入する例です。ここでは仮のデータとして「Alice」という名前と年齢、都市を持つレコードを挿入します。
4. メイン処理（main関数）: 上記のコード全体を一つの関数にまとめ、実行しています。まず`create_tables`を呼び出してテーブルを作成し、その後`insert_data`を呼び出してデータを挿入します。
