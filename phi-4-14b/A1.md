## 出力

PythonでShift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数を作成するには、`csv`モジュールと`codecs`モジュールを使用します。また、存在しないファイルや文字化け（デコードエラー）の処理も含めます。

以下はそのための関数です：

```python
import csv
import codecs
import os

def convert_sjis_csv_to_utf8(input_file_path, output_file_path):
    # ファイルが存在するか確認
    if not os.path.exists(input_file_path):
        print(f"Error: The file '{input_file_path}' does not exist.")
        return
    
    try:
        # Shift-JISでファイルを読み込む
        with codecs.open(input_file_path, 'r', encoding='shift_jis') as sjis_file:
            reader = csv.reader(sjis_file)
            
            # UTF-8で出力するためのファイルを開く
            with codecs.open(output_file_path, 'w', encoding='utf_8_sig') as utf8_file:
                writer = csv.writer(utf8_file)
                
                for row in reader:
                    try:
                        # 各行をUTF-8に変換して書き込む
                        writer.writerow(row)
                    except UnicodeEncodeError as e:
                        print(f"Unicode encode error at line {reader.line_num}: {e}")
    
    except UnicodeDecodeError as e:
        print(f"Unicode decode error: {e}")

# 使用例
convert_sjis_csv_to_utf8('input.csv', 'output.csv')
```

### 説明

1. **ファイル存在確認**: `os.path.exists`を使用して、入力ファイルが存在するか確認します。存在しない場合はエラーメッセージを表示し関数を終了します。

2. **Shift-JISでの読み込み**:
   - `codecs.open`を使用して、入力ファイルをShift-JISで開きます。
   - `csv.reader`を使ってCSVデータを行ごとに読み取ります。

3. **UTF-8での保存**:
   - 出力ファイルは`codecs.open`を使用して、UTF-8（BOM付き）で開きます。
   - `csv.writer`を使ってデータを行ごとに書き込みます。

4. **エラーハンドリング**:
   - `UnicodeDecodeError`: Shift-JISのファイルが正しく読めない場合に発生します。この例外をキャッチしてメッセージを表示します。
   - `UnicodeEncodeError`: データをUTF-8でエンコードする際に問題がある場合に発生します。行番号と共にエラーメッセージを出力します。

この関数は、指定されたShift-JISのCSVファイルを読み込んでUTF-8形式で保存し直すことができます。また、存在しないファイルや文字化けに対するエラーハンドリングも含まれています。
