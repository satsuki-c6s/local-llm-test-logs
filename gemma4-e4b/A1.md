## PythonでShift-JIS CSVを読み込み、UTF-8で書き出す関数

以下のPythonコードは、指定されたパスのShift-JISエンコーディングのCSVファイルを読み込み、内容を保持したままUTF-8エンコーディングで新しいファイルに保存する関数です。

エラー処理として、**ファイルが存在しない場合**と、**デコード（文字化け）が失敗した場合**の両方に対応しています。

```python
import csv
import os

def convert_sjis_to_utf8_csv(input_filepath: str, output_filepath: str) -> bool:
    """
    Shift-JISエンコーディングのCSVファイルを読み込み、UTF-8エンコーディングで新しいファイルに保存する。

    Args:
        input_filepath (str): 入力ファイルのパス（Shift-JIS）。
        output_filepath (str): 出力ファイルのパス（UTF-8）。

    Returns:
        bool: 処理が成功した場合はTrue、失敗した場合はFalse。
    """
    print(f"--- 開始 ---")
    print(f"入力ファイル: {input_filepath}")
    print(f"出力ファイル: {output_filepath}")

    # 1. ファイルの存在チェック
    if not os.path.exists(input_filepath):
        print(f"[エラー] 入力ファイルが見つかりません: {input_filepath}")
        return False

    data = []
    try:
        # 2. Shift-JISでファイルを読み込む (encoding='shift_jis')
        with open(input_filepath, mode='r', encoding='shift_jis', newline='') as infile:
            # csv.readerを使って、CSVの構造を維持したままデータをリストとして取得
            csv_reader = csv.reader(infile)
            for row in csv_reader:
                data.append(row)

    except UnicodeDecodeError as e:
        # 3. デコード失敗（文字化け）の処理
        print("\n[致命的エラー] ファイルのデコードに失敗しました。")
        print("これは、ファイルがShift-JISではないか、一部データが破損している可能性があります。")
        print(f"詳細: {e}")
        return False
    except Exception as e:
        # その他の予期せぬエラー処理
        print(f"\n[致命的エラー] ファイル読み込み中に予期せぬエラーが発生しました: {e}")
        return False

    if not data:
        print("[警告] ファイルは正常に開けましたが、データが空です。")
        # 空ファイルの場合でも、念のため出力処理を試みるか、ここで終了するか選択可能
        # 今回は成功とみなし、空のUTF-8ファイルを出力します。

    try:
        # 4. UTF-8で新しいファイルに書き出す (encoding='utf-8')
        with open(output_filepath, mode='w', encoding='utf-8', newline='') as outfile:
            csv_writer = csv.writer(outfile)
            csv_writer.writerows(data)

        print("\n=========================================")
        print("[成功] 処理が完了しました。")
        print(f"データは正常に読み込まれ、UTF-8形式で保存されました。")
        print("=========================================")
        return True

    except Exception as e:
        # 書き込み時のエラー処理
        print(f"\n[致命的エラー] ファイルの書き出し中にエラーが発生しました: {e}")
        return False
```

### コードの解説とポイント

1. **`import csv` と `import os`**:
   * `csv`: CSV形式の読み書きを簡単に行うための標準ライブラリです。
   * `os`: ファイルパスの存在確認（`os.path.exists`）に使用します。

2. **ファイル存在チェック (`os.path.exists`)**:
   * 関数冒頭で、まず入力ファイルが存在するかを確認し、存在しなければエラーメッセージを出して処理を中断します。

3. **読み込み処理 (Shift-JIS)**:
   ```python
   with open(input_filepath, mode='r', encoding='shift_jis', newline='') as infile:
       csv_reader = csv.reader(infile)
       # ... データ読み取り ...
   ```
   * **`encoding='shift_jis'`**: これが最も重要です。Pythonに「このファイルはShift-JISで書かれている」と明示的に伝えています。
   * **`try...except UnicodeDecodeError`**: Shift-JISとして解釈できないバイト列（例えば、別のエンコーディングのデータや破損したデータ）に遭遇した場合、`UnicodeDecodeError`が発生します。これをキャッチすることで、「文字化け」または「デコード失敗」として処理を中断し、ユーザーに通知できます。

4. **書き込み処理 (UTF-8)**:
   ```python
   with open(output_filepath, mode='w', encoding='utf-8', newline='') as outfile:
       csv_writer = csv.writer(outfile)
       csv_writer.writerows(data)
   ```
   * **`encoding='utf-8'`**: 出力するファイルは、現代の標準であるUTF-8形式で指定しています。
   * `csv.writer` を使用することで、データがカンマ区切り（CSV）の構造を保ったまま書き込まれます。

5. **エラー処理のフロー**:
   * 存在しない $\rightarrow$ `os.path.exists` で捕捉 $\rightarrow$ Falseを返す。
   * デコード失敗 $\rightarrow$ `UnicodeDecodeError` で捕捉 $\rightarrow$ Falseを返す。
   * 書き込み失敗 $\rightarrow$ `Exception` で捕捉 $\rightarrow$ Falseを返す。

この構造により、堅牢性が高まり、どの段階で問題が発生したかを明確にユーザーに伝えることができます。
