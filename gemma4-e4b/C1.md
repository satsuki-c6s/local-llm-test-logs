### 💡 一般的なPython ORMの基本的な使い方（参考）

もし「sakura-orm」が一般的なPythonのORMライブラリ（例：SQLAlchemyやPeeweeなど）と同じような構造を持っていると仮定して、**概念的なサンプルコード**を提示します。

ほとんどのORMは以下のステップを踏みます。

1. **モデルの定義:** データベースのテーブルに対応するPythonクラスを定義します。
2. **セッション/エンジン（接続）の確立:** データベースへの接続を設定します。
3. **操作の実行:** クラスを通じてCRUD（作成、読み取り、更新、削除）操作を行います。

#### 【概念的なサンプルコード例】

```python
# ★★★ 注意: これは「sakura-orm」固有の実装ではなく、一般的なORMの動作を模倣したものです ★★★

from sakura_orm import Model, Session # 仮定のインポート

# 1. モデルの定義 (データベースのテーブル構造を定義)
class User(Model):
    __tablename__ = 'users'  # テーブル名
    id = Integer(primary_key=True)
    username = String(unique=True, nullable=False) # 文字列型、ユニーク必須
    email = String(nullable=True)
    age = Integer(default=0)

# 2. セッション（接続）の確立 (データベースエンジンとの接続準備)
try:
    session = Session.create_engine("sqlite:///my_database.db")
    # テーブルが存在しない場合は作成する処理（マイグレーションに相当）
    session.create_all([User]) 

    print("--- 1. 新規データの追加 (CREATE) ---")
    # オブジェクトのインスタンスを作成し、セッションに追加してコミットする
    new_user = User(username="alice", email="alice@example.com", age=30)
    session.add(new_user)
    session.commit() # データベースに書き込む

    print("--- 2. データの一覧取得 (READ - 全件) ---")
    # クエリを実行して全ユーザーを取得する
    all_users = session.query(User).all()
    for user in all_users:
        print(f"ID: {user.id}, 名前: {user.username}")

    print("\n--- 3. 特定のデータ検索 (READ - 条件指定) ---")
    # WHERE句のような条件で検索する
    alice = session.query(User).filter(User.username == "alice").first()
    if alice:
        print(f"見つかったユーザー: {alice.username}, 年齢: {alice.age}")

    print("\n--- 4. データの更新 (UPDATE) ---")
    # 取得したオブジェクトの属性を変更し、コミットするだけで反映されることが多い
    if alice:
        alice.age = 31 # 値の変更
        session.commit()
        print(f"年齢を更新しました。新しい年齢: {User.query(User.id == alice.id).first().age}")

    print("\n--- 5. データの削除 (DELETE) ---")
    # オブジェクトをセッションから削除し、コミットする
    session.delete(alice)
    session.commit()
    print("ユーザー 'alice' を削除しました。")

except Exception as e:
    print(f"エラーが発生しました: {e}")
finally:
    # 接続のクローズ処理（重要）
    if 'session' in locals():
        session.close()
```
