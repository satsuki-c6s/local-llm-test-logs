## 出力

Pythonライブラリ「`sakura-orm`」は、SQLiteやMySQLなどのデータベース操作を簡単に行うための軽量なORM（Object-Relational Mapping）ツールです。

以下に基本的な使い方をコード例付きで解説します。

### 1. インストール

まず、ライブラリをインストールします。

```bash
pip install sakura-orm
```

---

### 2. 基本的な流れ

`sakura-orm`の基本的な使用フローは以下の通りです。

1.  **エンジンの作成**: データベース接続設定を行います。
2.  **モデル（テーブル）の定義**: テーブルの構造をクラスで定義します。
3.  **マイグレーション（テーブル作成）**: 定義した内容に基づいてテーブルをデータベースに作成します。
4.  **CRUD操作**: データの追加、検索、更新、削除を行います。

---

### 3. コード例

以下は、簡単な「ユーザーテーブル」を扱う完全なスクリプトです。

```python
from sakura_orm import SakuraORM, Model, Column, Integer, String

# 1. エンジンの作成 (SQLiteの場合)
# file_pathにデータベースファイルが作成されます
db = SakuraORM.create_engine("sqlite:///test.db")

# 2. モデル（テーブル定義）の作成
class User(Model):
    # テーブル名を明示的に指定しない場合、クラス名 'User' が自動的にテーブル名になります
    id = Column(Integer, primary_key=True)  # 主キー
    name = Column(String(50), nullable=False) # 名前 (必須)
    age = Column(Integer)                     # 年齢

# 3. テーブルの作成（マイグレーション）
# Model.metadata.create_all(engine) を呼び出すと、定義に基づいたテーブルが作られます
db.create_all()

print("テーブル 'users' が作成されました。")

# 4. CRUD操作

# 【Create】データの挿入
user1 = User(name="山田太郎", age=25)
user2 = User(name="佐藤花子", age=30)

# セッションを使って保存
db.session.add(user1)
db.session.add(user2)
db.session.commit() # コミットしないとデータは保存されません

print(f"ユーザー {user1.name} を挿入しました。")

# 【Read】データの検索
# すべて取得
all_users = User.query.all()
print("全ユーザー:", all_users)

# 条件で絞り込み (年齢が25歳以上)
older_users = User.query.filter(User.age >= 25).all()
print("25歳以上のユーザー:", older_users)

# IDで検索
user_by_id = User.query.get(1) # id=1 のレコードを取得
print(f"id=1 のユーザー: {user_by_id.name}")

# 【Update】データの更新
# オブジェクトを取得してプロパティを変更し、commitする
if user_by_id:
    user_by_id.age = 26
    db.session.commit()
    print(f"id=1 の年齢を {user_by_id.age} に更新しました。")

# 【Delete】データの削除
# オブジェクトを取得して削除し、commitする
if user_by_id:
    db.session.delete(user_by_id)
    db.session.commit()
    print(f"id=1 のユーザーを削除しました。")
```

### 4. 主な機能の解説

#### エンジンの設定
データベースの種類によって接続文字列（DSN）を変えます。

*   **SQLite**: `sqlite:///ファイル名.db`
*   **MySQL**: `mysql+pymysql://ユーザー名:パスワード@ホスト名/データベース名`

#### モデル定義 (`Column`)
テーブルのカラムを定義します。
*   `Integer`, `String`, `Float` などの型が使えます。
*   `primary_key=True` で主キー設定可能。
*   `nullable=False` でNULL不可設定可能。

#### クエリビルダー (`User.query`)
SQL文を意識せずにデータ操作ができます。
*   `.all()`: 全件取得
*   `.filter(条件)`: 条件検索
*   `.get(id)`: 主キーでの1件取得

#### セッション (`db.session`)
トランザクション管理を行います。`add()`, `commit()`, `rollback()`, `delete()` メソッドを使用します。

### 注意点・ Tips

1.  **マイグレーション**: 本格的な開発では、テーブルの構造変更（カラム追加など）に対応するために、`alembic` などのマイグレーションツールと組み合わせることが推奨されます。`sakura-orm`単体でも `create_all()` で基本的なテーブル作成は可能ですが、スキーマ変更履歴の管理には別途ツールが必要です。
2.  **関連付け**: 他のテーブルとのリレーション（外部キー制約など）については、公式ドキュメントで `Relationship` 機能が確認できます。

このように、`sakura-orm`はSQLを書かずにPythonのコードだけでデータベース操作ができるため、初心者から中級者まで幅広く使いやすいライブラリです。
