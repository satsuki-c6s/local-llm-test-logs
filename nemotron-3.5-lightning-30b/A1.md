## 出力

以下は、Shift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数です。

`try-except`ブロックを使用して、ファイルが存在しない場合や文字化け（デコード失敗）が発生した場合に適切なエラー処理を行うように設計されています。

```python
import csv

def convert_csv_encoding(input_path, output_path):
    """
    Shift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数。
    
    Args:
        input_path (str): 入力ファイルのパス（Shift-JIS）
        output_path (str): 出力ファイルのパス（UTF-8）
        
    Returns:
        bool: 成功した場合True、失敗した場合False
    """
    try:
        # ファイルを開いて読み込む
        with open(input_path, 'r', encoding='shift_jis') as infile:
            reader = csv.reader(infile)
            
            # 読み込んだデータをリストに格納
            data = list(reader)

    except FileNotFoundError:
        print(f"エラー: 指定されたファイルが見つかりません: {input_path}")
        return False

    except UnicodeDecodeError as e:
        # Shift-JISでデコードできない場合（文字化けなど）の処理
        print(f"エラー: ファイルの文字コードがShift-JISでは読み込めませんでした (UnicodeDecodeError): {e}")
        return False

    except Exception as e:
        # その他の予期せぬエラー
        print(f"エラー: 予期せぬエラーが発生しました: {e}")
        return False

    try:
        # UTF-8で書き込む
        with open(output_path, 'w', encoding='utf-8', newline='') as outfile:
            writer = csv.writer(outfile)
            
            # データを書き込む
            for row in data:
                writer.writerow(row)

        print(f"成功: {input_path} を {output_path} へUTF-8で保存しました。")
        return True

    except Exception as e:
        print(f"エラー: ファイルの書き込み中にエラーが発生しました: {e}")
        return False


# --- 使用例 ---
if __name__ == "__main__":
    # 入力ファイルと出力ファイルのパスを指定
    input_file = "data_shift_jis.csv"
    output_file = "data_utf8.csv"

    # 関数を実行
    success = convert_csv_encoding(input_file, output_file)
    
    if not success:
        print("変換に失敗しました。")
```

### 解説

1.  **読み込み処理 (`open(..., encoding='shift_jis')`)**:
    *   `try`ブロック内でCSVファイルを開き、Shift-JISとしてデコードしようとします。
2.  **エラー処理**:
    *   `FileNotFoundError`: 指定されたパスのファイルが存在しない場合にキャッチされます。
    *   `UnicodeDecodeError`: ファイルの中身がShift-JISで表現できない文字（マルチバイト文字の欠落や別のエンコーディング）を含んでいる場合に発生します。この場合、その旨を出力して処理を中断します。
    *   `Exception`: その他の予期せぬエラー（パーミッション不足など）のための汎用的なキャッチです。
3.  **書き込み処理 (`open(..., encoding='utf-8')`)**:
    *   読み込みに成功したデータを、UTF-8エンコーディングで新しいファイルに書き込みます。`newline=''` を指定することで、CSVモジュールが正しく行末を処理できるようにしています。

この関数を実行すると、指定されたShift-JISのCSVファイルがUTF-8形式の新しいファイルに変換されます。
