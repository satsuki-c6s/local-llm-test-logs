## 基本的な使い方

### 1. モデル定義とCRUD操作

```python
from sakura_orm import Model, Column, String, Integer, DateTime
from datetime import datetime

# モデル定義
class User(Model):
    __tablename__ = 'users'
    
    id = Column(Integer, primary_key=True)
    name = Column(String(100))
    email = Column(String(200))
    created_at = Column(DateTime, default=datetime.now)

# データベース接続
User.connect('sqlite:///example.db')

# 作成
user = User(name='太郎', email='taro@example.com')
user.save()

# 読み取り
users = User.all()
for user in users:
    print(user.id, user.name, user.email)

# 条件付き検索
taro = User.where(name='太郎').first()
print(taro)

# 更新
taro.name = '太郎改め'
taro.save()

# 削除
taro.delete()
```

### 2. マイグレーション

# テーブル作成
User.create_table()

### 3. リレーションシップ

```python
from sakura_orm import Model, Column, String, Integer, ForeignKey, DateTime

class Post(Model):
    __tablename__ = 'posts'
    
    id = Column(Integer, primary_key=True)
    title = Column(String(200))
    content = Column(String(1000))
    user_id = Column(Integer, ForeignKey('users.id'))
    
    # リレーション定義
    user = Model.belongs_to('User', foreign_key='user_id')

# 使用例
post = Post(title='初めての投稿', content='内容', user_id=1)
post.save()

# リレーションの取得
post = Post.where(id=1).first()
print(post.user.name)  # 関連するユーザーを取得
```

### 4. クエリビルダー

```python
# 複雑なクエリ
users = User.where('age > ?', 20).order_by('created_at DESC').limit(10).all()

# 集計
count = User.count()
avg_age = User.avg('age')
sum_age = User.sum('age')

# ページネーション
page = User.paginate(page=1, per_page=10)
```

### 5. トランザクション

```python
from sakura_orm import transaction

with transaction():
    user1 = User(name='A', email='a@example.com')
    user2 = User(name='B', email='b@example.com')
    user1.save()
    user2.save()
    # エラーが発生した場合は自動的にロールバック
```

### 6. バリデーション

```python
from sakura_orm import Model, Column, String, Integer, validates

class User(Model):
    __tablename__ = 'users'
    
    id = Column(Integer, primary_key=True)
    name = Column(String(100))
    email = Column(String(200))
    
    @validates('email')
    def validate_email(self, value):
        if '@' not in value:
            raise ValueError('メールアドレスが不正です')
        return value

# 使用例
try:
    user = User(name='太郎', email='invalid')
    user.save()
except ValueError as e:
    print(e)
```

### 7. マイグレーションツール

```python
# マイグレーションファイルの作成
sakura-orm migrate:create add_users_table

# マイグレーションの実行
sakura-orm migrate

# マイグレーションのロールバック
sakura-orm migrate:rollback
```

## 主な機能まとめ

- **モデル定義**: `Model`クラスを継承し、`Column`でフィールドを定義
- **CRUD操作**: `save()`, `all()`, `where()`, `delete()`など
- **リレーション**: `belongs_to`, `has_many`など
- **トランザクション**: `transaction()`コンテキストマネージャー
- **バリデーション**: `@validates`デコレーター
- **マイグレーション**: CLIツールで管理
- **クエリビルダー**: 条件、ソート、ページネーションなど

sakura-ormはシンプルで直感的なAPIを提供しており、小規模から中規模のプロジェクトに適しています。詳細なドキュメントは公式サイトで確認できます。
