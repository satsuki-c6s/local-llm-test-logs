# ローカルLLM 6問テスト — 生ログ

YouTube「さつきのOSS研究室」ローカルAI検証シリーズで使った、**採点前の生の出力**です。
動画で語っている実測値はすべてここから拾っています。

## 実行条件 — **6問シリーズを Ollama 単機で回した回だけ**の共通条件

**この表が当てはまるのは `digest` が記録されている回だけです。** このリポジトリには
条件の違う回も入っています: vLLM で回した特別編、家庭内4台クラスタの回、
コード生成シリーズ、KV キャッシュを f16 に落として回した回。
**各回の実際の条件は必ず `<モデル名>/REPORT.md` の「実行条件」表を見てください**
(そちらはその回の記録から生成しており、記録に無い条件は書きません)。
どの回がどの環境かは `LEADERBOARD.md` の実行環境列で分かります。

| 項目 | 値 |
|---|---|
| ランタイム | Ollama (モデル digest を記録して固定) |
| 量子化 | Q4_K_M 統一 (無ければ最も近いもの。実使用量子化は各回の動画で明示) |
| temperature / top_p | 0.2 / 0.9 |
| seed | 42 |
| 試行回数 | **1回のみ。リトライなし** |
| max_tokens / context | 4096 / 8192 |
| システムプロンプト | なし (モデル既定のチャットテンプレートのみ) |
| 計測機 | RTX 5090 32GB |
| 記録 | 実測 tok/s / VRAM 使用量 / モデル digest / 実行日時 |

- thinking 対応モデルは思考を無効化し、混入した場合は `</think>` 以前を除去して**本文のみ**を採点対象にしています
- VRAM の表示は `nvidia-smi` の MiB を 1000 で割った値です (厳密な単位換算ではありません。
  シリーズ全回で同じ表記に揃えるためこうしています)
- tok/s は1リクエストの初期化コストを含むため、**問題間で順位を比較しないでください**。
  短い出力ほど低く出ます

## 総合判定

- **採用**: A1・B1 が○以上、かつ C1 が×でない
- **条件付き採用**: A/B どちらかに△があるが、用途を限定すれば使える
- **見送り**: C1 が× (捏造) または A1・B1 が両方△以下

判定基準はテスト実行**前**に固定しています。結果を見てから基準を動かすことはしません。

## フォルダの読み方

`<モデル名>/A1.md` … 各問のプロンプトと、モデルの出力そのまま。
冒頭に実行日時・digest・tok/s・VRAM・壁時計時間が入っています。
`_summary.json` は同じ内容の機械可読版です。

問題は6問。A = 標準タスク (コード生成・要約)、B = 日本語運用 (敬語・営業日計算)、
C = 罠 (存在しないライブラリ・禁止語つき字数指定)。

## コード生成シリーズ (フォルダ名が `*-codegen` のもの)

実アプリ3課題 (ToDoアプリ / ブロック崩し / 軌道シミュレーター) を**一発勝負・単一HTML
ファイル縛り・外部ライブラリとCDN禁止**で生成させ、無修正のままブラウザで起動して
実操作で判定するシリーズです。`T1〜T3.md` が各課題のプロンプトと応答全文、
`T1〜T3.html` が応答から機械抽出した生成コード (**無修正**) です。
判定基準は実行前に固定しています。
実行条件は回によって違います (Ollama 単機の回と、家庭内クラスタを OpenAI 互換 API 経由で
回した回があり、パラメータ名も上限値も別物です)。**各回の `REPORT.md` を見てください。**

## 注意
