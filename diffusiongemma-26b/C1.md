### 2. 基本的な使い方の例

以下のコードでは、SQLiteを使用して「ユーザー管理」テーブルを作成し、データを操作する一連の流れを示しています。

```python
from sakura_orm import Database, Model, Field

# 1. データベースの設定
# SQLiteファイル 'example.db'を作成して接続します
db = Database('example.db')

# 2. モデル（テーブル構造）の定義
class User(Model):
    __tablename__ = 'users'  # テーブル名

    id = Field(int, primary_key=True)
    name = Field(str)
    age = Field(int)
    email = Field(str, unique=True)

# テーブルの作成（初回実行時）
db.create_all()

# --- 3. データの作成 (Create) ---
user1 = User(name="田中", age=25, email="tanaka@example.com")
user1.save()

user2 = User(name="佐藤", age=30, email="sato@example.com")
user2.save()

print("データの登録が完了しました。")

# --- 4. データの取得 (Read) ---
# IDを指定して取得
user = User.get(id=1)
if user:
    print(f"取得したユーザー: {user.name} ({user.age}歳)")

# すべてのレコードを全
all_users = User.all()
print("全ユーザーリスト:")
for u in all_users:
    print(f"- {u.name}: {u.email}")

# 条件を指定して検索（例：28歳以上）
older_users = User.filter(age__gte=28).all()
print("28歳以上のユーザー:")
for u in older_users:
    print(f"- {u.name}")

# --- 5. データの更新 (Update) ---
user_to_update = User.get(id=1)
if user_to_update:
    user_to_update.age = 26
    user_to_update.save()
    print("田中さんの年齢を更新しました。")

# --- 6. データの削除 (Delete) ---
user_to_delete = User.get(id=2)
if user_to_delete:
    user_to_delete.delete()
    print("佐藤さんのレコードを削除しました。")
```

---

### 主な機能の解説

#### `Database` クラス
- データベースへの接続を管理します。SQLite以外に、MySQLやPostgreSQLなどにも対応している場合があります。
- `create_all()`: 定義したモデルに基づいてデータベース内にテーブルを自動生成します。

#### `Model` と `Field` クラス
- `Model`を継承することで、そのクラスがDBテーブルに対応します。
- `Field`でカラムの型や制約（`primary_key`, `unique`など）を指定します。

#### よく使うメソッド
- `.save()`: 新規データの挿入（INSERT）または既存データの更新（UPDATE）を行います。
- `.get(**kwargs)`: 主キーなどを指定して1件のデータを取得します。
- `.all()`: 条件に合う全データをリストで返します。
- `.filter(**kwargs)`: データを絞り込みます。
    - `age__gte=20`（以上）、`age__lt=30`（未満）のようなアンダースコアを使った比較子が使えることが多いです。
- `.delete()`: そのインスタンスのレコードを削除します。

### 注意点
`sakura-orm`は非常に軽量な設計であるため、大規模なアプリケーションや、非常に複雑な結合（JOIN）を多用するようなシステムでは、`SQLAlchemy` や `Django ORM` を検討することをお勧めします。小規模なツールやプロトタイプ作成には非常に便利です。
