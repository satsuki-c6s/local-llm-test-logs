Pythonの標準ライブラリ`csv`モジュールを使用して、Shift-JISのCSVをUTF-8に変換して保存する関数を紹介します。

このコードでは、ファイルが存在しない場合の`FileNotFoundError`と、エンコーコードが正しくない場合の`DecodeError`のハンドリングを行っています。

```python
import csv
import os

def convert_sjis_csv_to_utf8(input_file, output_file):
    """
    Shift-JISのCSVファイルを読み込み、UTF-8で保存し直す
    
    Args:
        input_file (str): 入力ファイルパス
        output_file (str): 出力ファイルパス
    """
    try:
        # Shift-JIS(cp932)で読み込みモードで開く
        # Windows特有の文字を考慮してencoding='cp932'を推奨します
        with open(input_file, mode='r', encoding='shift_jis', newline='') as f:
            reader = csv.reader(f)
            
            # UTF-8で書き込みモードで開く
            # utf_sigにすることで、Excelで開いた時の文字化けを防げます
            with open(output_file, mode='w', encoding='utf-8-sig', newline='') as out:
                writer = csv.writer(out)
                
                for row in reader:
                    writer.writerow(row)
                
        print(f"変換に成功しました: {input_file} -> {output_file}")

    except FileNotFoundError:
        print(f"エラー: ファイル '{input_file}' が見つかりません。")
    except UnicodeDecodeError:
        print(f"エラー: '{input_file}' はShift-JISとして読み込めませんでした（文字コーディングが異なる可能性があります）。")
    except Exception as e:
        print(f"予期しないエラーが発生しました: {e}")

# --- 実行例 ---
if __name__ == "__main__":
    input_csv = "data_sjis.csv"   # 変換したいファイル名
    output_csv = "data_utf8.csv" # 変換後のファイル名
    
    convert_sjis_csv_to_utf8(input_csv, output_csv)
```

### ポイントの解説

1.  **`encoding='shift_jis'` または `'cp932'`**:
    *   一般的にShift-JISといで動作しますが、Windows環境で作成されたファイル（特殊文字：①や〜など）が含まれる場合は、`cp932`を指定する方がエラーが起きにくくなります。もしエラーが出る場合は、`cp932`に書き換えてみてください。
2.  **`encoding='utf-8-sig'`**:
    *   単なる `utf-8` ではなく `utf-8-sig` とすることで、ファイルの先頭にBOM（Byte Order Mark）が付与されます。これにより、**変換後のCSVをExcelでダブルクリック開いた時に文字化けするのを防ぐ**ことができます。
3.  **`newline=''`**:
    *   `csv`モジュールを使用する場合、この引数を指定しないとOS環境によって改行が不自然になる（空行が増えるなど）のを防ぐため、推奨されています。
4.  **例外処理**:
    *   `FileNotFoundError`: 指定したパスにファイルがない場合にキャッチします。
    *   `UnicodeDecodeError`: ファイルがShift-JISではなかった（UTF-8だった場合など）にキャッチします。
