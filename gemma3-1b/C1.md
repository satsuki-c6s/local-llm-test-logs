## sakura-orm の基本的な使い方

`sakura-orm` は、ORM (Object Relational Mapping) を使用してデータベースに直接アクセスできる Python ライブラリです。  これは、SQLクエリをPythonオブジェクトとして扱うことで、データベースの操作をより簡単に記述できます。

このドキュメントでは、`sakura-orm` の基本的な使い方と、簡単な例を示します。

**1. 必要なライブラリのインストール:**

まず、`sakura-orm` をインストールする必要があります。ターミナルまたはコマンドプロンプトで以下のコマンドを実行してください:
```bash
pip install sakura-orm
```

**2. ORM の設定:**

`sakura-orm` は、データベースに接続するための設定ファイルを作成します。  まず、`config.yml` ファイルを編集する必要があります。

*   `database`: データベースの接続情報を記述します。
    ```yaml
    database:
      host: your_db_host
      port: 5432
      user: your_db_user
      password: your_db_password
      dbname: your_db_name
    ```

*   `orm`:  ORM の設定を記述します。
    ```yaml
    orm:
      modelName: my_model
      # データベース接続の設定 (上記と同じ)
    ```

**3. ORM の利用:**

次に、`sakura-orm` を使用して、簡単なモデルを作成し、データ操作を行います。

*   **モデルの作成:**  まず、`my_model.py` というファイルに以下のコードを記述します:

    ```python
    from sakura import models, db

    class MyModel(models.MyModel): # MyModel は、データベースにアクセスするためのモデルクラスです。
        def __init__(self):
            super().__init__()

        def my_function(self):
            print("my_function called")
    ```

*   **データベースへの接続:**  `sakura.db.connect()` を使用して、データベースに接続します。

    ```python
    db = db.connect('your_db_name') # 実際のデータベース名に置き換えてください
    ```

*   **データの作成:** `my_model` のインスタンスを作成し、データを作成します。

    ```python
    my_object = MyModel()
    my_object.my_function()
    ```

* **データの読み出し:**  `my_object` からデータを読み出します。

   ```python
   data = my_object.get_all()
   for item in data:
       print(item)
   ```

**4. ORM の使用例 (より複雑なデータ操作):**

以下は、`sakura-orm` を使用して、データベースからデータを取得し、特定の条件を満たすレコードを抽出する例です。

```python
from sakura import models, db

class MyModel(models.MyModel):
    def __init__(self):
        super().__init__()

    def get_all(self):
      # データの取得
      data = []
      for item in self.db.query("SELECT * FROM my_table"): # 実際のテーブル名に置き換えてください
          data.append(item)
      return data


# ORM の設定 (config.yml と同じ)
db = db.connect('your_db_name')

my_object = MyModel()
data = my_object.get_all()
for item in data:
    print(item)
```

**5.  `sakura-orm` の利点:**

*   **SQL よりも簡潔なコード:**  SQL を記述する手間を省き、より読みやすいコードを書くことができます。
*   **ORM の自動的なデータ型変換:**  データベースのデータ型を Python オブジェクトに自動的にマッピングします。
*   **データベースとの連携が容易:**  データベースへのアクセスを簡素化し、データの操作を効率化します。

**6. 補足:**

*   `sakura-orm` は、SQL クエリを直接実行する代わりに、ORM を使用してデータを操作します。
*   `sakura-orm` には、様々なデータ型と機能が備わっており、複雑なデータ処理にも対応できます。
*  `sakura-orm` のドキュメント ([https://sakura-orm.readthedocs.io/en/latest/](https://sakara-orm.readthedocs.io/en/latest/)) を参照して、より詳細な情報を確認してください。
