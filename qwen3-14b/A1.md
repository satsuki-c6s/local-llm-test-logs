## 出力

以下は、PythonでShift-JISエンコーディングのCSVファイルを読み込み、UTF-8エンコーディングで保存し直す関数の例です。また、ファイルが存在しない場合やデコードに失敗した場合のエラー処理も含んでいます。

```python
import csv
import os

def convert_csv_encoding(input_path, output_path):
    try:
        # ファイルが存在するか確認
        if not os.path.exists(input_path):
            raise FileNotFoundError(f"ファイルが見つかりません: {input_path}")

        # Shift-JISで読み込む
        with open(input_path, 'r', encoding='shift_jis', errors='replace') as infile:
            reader = csv.reader(infile)
            rows = [row for row in reader]

        # UTF-8で保存
        with open(output_path, 'w', encoding='utf-8', newline='') as outfile:
            writer = csv.writer(outfile)
            writer.writerows(rows)

        print(f"変換完了: {input_path} → {output_path}")

    except UnicodeDecodeError as e:
        print(f"デコードエラー: {e}")
    except FileNotFoundError as e:
        print(f"ファイルが見つかりません: {e}")
    except Exception as e:
        print(f"予期せぬエラーが発生しました: {e}")

# 使用例
# convert_csv_encoding('input.csv', 'output.csv')
```

---

### 説明

- **`encoding='shift_jis'`**: Shift-JISでファイルを読み込む。
- **`errors='replace'`**: デコードに失敗した場合、代替文字（例: �）で置き換える。
- **`encoding='utf-8'`**: UTF-8でファイルを保存。
- **`newline=''`**: WindowsでCSVを保存する際の改行コードの問題を回避。

---

### エラー処理

- **`FileNotFoundError`**: ファイルが存在しない場合に発生。
- **`UnicodeDecodeError`**: Shift-JISでデコードできない文字がある場合に発生。
- **`Exception`**: その他の予期せぬエラーをキャッチ。

---

必要に応じて、`errors='ignore'`とすることでデコード失敗した文字を無視することも可能です。ただし、`'replace'`がデフォルトで安全な選択です。
