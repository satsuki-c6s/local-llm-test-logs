## 出力

`sakura-orm` は、Python でデータベース操作を行うための ORM（Object-Relational Mapping）ライブラリです。ただし、このライブラリは一般的に知られている ORM（例: SQLAlchemy, Django ORM）ほど普及していないため、公式ドキュメントやコミュニティ情報が限られている可能性があります。

ただし、以下のような一般的な ORM の使い方を参考に、`sakura-orm` の基本的な使い方をコード例付きで説明します。ただし、このライブラリが実際に存在するか、または具体的な API が異なる可能性があるため、あくまで「一般的な ORM の使い方」をベースにしています。

## 📌 1. インストール

まず、`sakura-orm` をインストールします（存在する場合）。

```bash
pip install sakura-orm
```

---

## 📌 2. データベース設定

`sakura-orm` では、データベース接続情報を設定する必要があります。

```python
from sakura.orm import configure

configure(
    database='sqlite:///example.db',  # 例: SQLite データベース
    echo=True  # SQL 文を出力するかどうか
)
```

---

## 📌 3. モデルの定義

モデルクラスを定義します。これは、データベースのテーブルと対応します。

```python
from sakura.orm import Model, Column, Integer, String

class User(Model):
    __tablename__ = 'users'

    id = Column(Integer, primary_key=True)
    name = Column(String(50))
    email = Column(String(100), unique=True)
```

---

## 📌 4. データベースの初期化

モデルを登録し、データベースを作成します。

```python
from sakura.orm import create_all

create_all()
```

---

## 📌 5. データの挿入

```python
user = User(name='Alice', email='alice@example.com')
user.save()
```

---

## 📌 6. データの取得

```python
# 全てのユーザーを取得
users = User.query.all()
for user in users:
    print(user.name, user.email)

# ID が 1 のユーザーを取得
user = User.query.get(1)
print(user.name)
```

---

## 📌 7. データの更新

```python
user = User.query.get(1)
user.name = 'Bob'
user.save()
```

---

## 📌 8. データの削除

```python
user = User.query.get(1)
user.delete()
```

---

## 📌 9. クエリのフィルタリング

```python
# email が 'alice@example.com' のユーザーを取得
user = User.query.filter(User.email == 'alice@example.com').first()
print(user.name)
```

## 📌 10. データベースセッションの管理

`sakura-orm` では、セッションの管理が自動的に行われている可能性がありますが、必要に応じて明示的に管理することも可能です。

```python
from sakura.orm import session

# セッションを明示的に使用
with session() as s:
    user = User(name='Charlie', email='charlie@example.com')
    s.add(user)
    s.commit()
```
