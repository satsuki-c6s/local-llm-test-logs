## 3. 基本的なコード例

### 3.1. データモデルの定義

```python
from sakura_orm import Base, Field, Model

class UserModel(Base):
    __tablename__ = 'users'
    
    id = Field(primary_key=True)
    username = Field(unique=True)
    email = Field()
    created_at = Field(default_factory=datetime.datetime.utcnow)
```

### 3.2. データの保存と取得

```python
from sakura_orm import Session

# データの保存
with Session() as session:
    user = UserModel(username='test', email='test@example.com')
    session.add(user)
    session.commit()

# データの取得
with Session() as session:
    user = session.query(UserModel).first()
    print(user.username)
```

### 3.3. ORMの使用例

```python
from sakura_orm import Base, Field, Model
from datetime import datetime

class ProductModel(Base):
    __tablename__ = 'products'
    
    id = Field(primary_key=True)
    name = Field()
    price = Field()
    created_at = Field(default_factory=datetime.datetime.utcnow)

# ORMによるデータ操作
with Session() as session:
    # 新規作成
    product = ProductModel(name='Book', price=100.0)
    session.add(product)
    session.commit()
    
    # 更新
    product.price = 150.0
    session.commit()
    
    # 取得
    products = session.query(ProductModel).all()
    for p in products:
        print(f"{p.name}: {p.price}")
```

## 4. 重要なポイント

1. **データベースの設定**: ORMはデータベースに直接アクセスしないため、データベースの設定は別のライブラリ（SQLAlchemyなど）で行う必要があります。

2. **セッション管理**: ORMはセッションを自動的に管理しますが、長いセッションを保持する必要があります。

3. **依存関係**: ORMは依存関係を自動的に管理しますが、必要に応じて手動で設定することもあります。

4. **データベースの初期化**: ORMはデータベースの初期化を自動的に行いません。データベースの作成は別の処理で行う必要があります。
