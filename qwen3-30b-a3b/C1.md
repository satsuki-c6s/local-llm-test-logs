### 正しいORMライブラリの例（SQLAlchemyを用いた基本的な使い方）
実際のORMライブラリとして広く使われている**SQLAlchemy**の基本的な使い方をコード例で説明します。

#### 1. インストール
```bash
pip install sqlalchemy
```

#### 2. 基本的なコード例
```python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker

# データベース接続の設定（SQLiteを使用）
engine = create_engine('sqlite:///example.db', echo=True)
Base = declarative_base()

# モデルの定義（例: Userテーブル）
class User(Base):
    __tablename__ = 'users'
    
    id = Column(Integer, primary_key=True)
    name = Column(String)
    age = Column(Integer)

# テーブルの作成
Base.metadata.create_all(engine)

# セッションの作成
Session = sessionmaker(bind=engine)
session = Session()

# データの挿入
new_user = User(name='Alice', age=30)
session.add(new_user)
session.commit()

# データの取得
users = session.query(User).all()
for user in users:
    print(f"ID: {user.id}, Name: {user.name}, Age: {user.age}")

# クエリ例（年齢が25以上のユーザーを取得）
older_users = session.query(User).filter(User.age > 25).all()
print("Older users:", [(u.name, u.age) for u in older_users])

# セッションの終了
session.close()
```
