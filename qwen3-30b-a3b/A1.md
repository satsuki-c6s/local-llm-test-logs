## 出力

以下は、Shift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数です。存在しないファイルとデコード失敗のエラー処理を含んでいます。

```python
import os

def convert_csv_encoding(input_path, output_path):
    """
    Shift-JISでエンコードされたCSVファイルをUTF-8に変換して保存します。
    
    引数:
    input_path (str): Shift-JISでエンコードされた入力CSVファイルのパス
    output_path (str): UTF-8で保存する出力CSVファイルのパス
    
    例外:
    FileNotFoundError: 入力ファイルが存在しない場合
    ValueError: デコード失敗（Shift-JISでないファイルが指定された場合）
    """
    # 入力ファイルの存在チェック
    if not os.path.exists(input_path):
        raise FileNotFoundError(f"入力ファイルが存在しません: {input_path}")
    
    try:
        # Shift-JISでファイルを読み込み
        with open(input_path, 'r', encoding='shift_jis') as infile:
            content = infile.read()
    except UnicodeDecodeError:
        # デコード失敗時のエラー処理
        raise ValueError("デコード失敗: ファイルがShift-JISエンコーディングではありません。")
    
    # UTF-8で出力ファイルを保存
    with open(output_path, 'w', encoding='utf-8') as outfile:
        outfile.write(content)
```

### 主な処理内容
1. **入力ファイル存在チェック**  
   `os.path.exists()` で入力ファイルの存在を確認。存在しない場合は `FileNotFoundError` を発生。

2. **Shift-JISデコード処理**  
   `encoding='shift_jis'` でファイルを読み込み。デコード失敗時は `UnicodeDecodeError` が発生し、`ValueError` に変換して再発生。

3. **UTF-8出力**  
   `encoding='utf-8'` で出力ファイルを保存。

### 使い方
```python
try:
    convert_csv_encoding("input.csv", "output.csv")
    print("変換が完了しました。")
except FileNotFoundError as e:
    print(f"エラー: {e}")
except ValueError as e:
    print(f"エラー: {e}")
```

### エラーハンドリングの詳細
| エラー種別 | 発生条件 | 処理内容 |
|------------|----------|----------|
| `FileNotFoundError` | 入力ファイルが存在しない | `入力ファイルが存在しません` とエラーメッセージを表示 |
| `ValueError` | Shift-JISでデコードできないファイル | `デコード失敗: ファイルがShift-JISエンコーディングではありません` とエラーメッセージを表示 |

> **注意**:  
> - 出力ディレクトリの存在チェックは含まれません（問題の要件に準拠）。  
> - CSVの構造解析は行わず、単純なエンコーディング変換のみを実施します。  
> - Shift-JIS以外のエンコーディング（例: EUC-JP, CP932）で保存されたファイルはデコード失敗します。
