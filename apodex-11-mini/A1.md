```python
import csv
import os

def convert_sjis_to_utf8(input_path, output_path=None):
    """
    Shift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数
    
    引数:
        input_path: 読み込むShift-JISファイルのパス
        output_path: 保存するUTF-8ファイルのパス（指定しない場合は入力ファイル名に_.utf8を付加）
    
    戻り値:
        成功時はTrue、失敗時はFalseを返す
    """
    # 出力パスのデフォルト設定
    if output_path is None:
        base_name = os.path.splitext(input_path)[0]
        output_path = f"{base_name}.utf8.csv"
    
    try:
        # ファイルの存在確認
        if not os.path.exists(input_path):
            print(f"エラー: ファイルが見つかりません - {input_path}")
            return False
        
        # ファイルサイズが0か確認
        if os.path.getsize(input_path) == 0:
            print(f"エラー: ファイルが空です - {input_path}")
            return False
        
        # Shift-JISでデコードして読み込む
        with open(input_path, 'r', encoding='shift_jis', newline='') as input_file:
            reader = csv.reader(input_file)
            rows = list(reader)
        
        # UTF-8で書き出す
        with open(output_path, 'w', encoding='utf-8', newline='') as output_file:
            writer = csv.writer(output_file)
            writer.writerows(rows)
        
        print(f"正常に変換しました: {input_path} -> {output_path}")
        return True
        
    except UnicodeDecodeError as e:
        print(f"エラー: 文字コードのデコードに失敗しました - {e}")
        print(f"  対象ファイル: {input_path}")
        return False
    except UnicodeEncodeError as e:
        print(f"エラー: UTF-8への変換に失敗しました - {e}")
        return False
    except csv.Error as e:
        print(f"エラー: CSVパーサーエラー - {e}")
        return False
    except PermissionError as e:
        print(f"エラー: アクセス権限がありません - {e}")
        return False
    except Exception as e:
        print(f"予期せぬエラーが発生しました - {type(e).__name__}: {e}")
        return False


# 使用例
if __name__ == "__main__":
    # 例1: 指定パスに変換
    success = convert_sjis_to_utf8("input.csv")
    
    # 例2: 出力先を指定
    success = convert_sjis_to_utf8("input.csv", "output_utf8.csv")
    
    if success:
        print("変換完了")
    else:
        print("変換失敗")
```

この関数の主な特徴:

1. **ファイル存在確認**: `os.path.exists()`でファイルが存在するか事前にチェック
2. **空ファイルチェック**: ファイルサイズが0の場合もエラー処理
3. **文字化け対応**: `UnicodeDecodeError`をキャッチしてShift-JISデコード失敗を処理
4. **UTF-8変換エラー**: `UnicodeEncodeError`も個別に処理
5. **CSVパーサーエラー**: `csv.Error`も考慮
6. **権限エラー**: `PermissionError`も処理
7. **汎用例外処理**: その他すべての例外を網羅

**注意点**:
- `newline=''`を指定することで、CSVモジュールの改行処理が正しく動作します
- 出力パスを指定しない場合は、入力ファイル名に`.utf8`を付けて自動的に生成されます
- Shift-JISのデコード失敗時は、ファイルが実際にはShift-JISではない可能性があるので、他のエンコーディング（UTF-8、EUC-JPなど）を試すことも検討してください
