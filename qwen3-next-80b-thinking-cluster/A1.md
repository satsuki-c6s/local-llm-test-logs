## 出力 (本文そのまま)

```python
def convert_shift_jis_to_utf8(input_path, output_path):
    try:
        with open(input_path, 'r', encoding='shift_jis') as f_in:
            data = f_in.read()
        with open(output_path, 'w', encoding='utf-8') as f_out:
            f_out.write(data)
    except FileNotFoundError:
        print(f"エラー: ファイル {input_path} が存在しません。")
    except UnicodeDecodeError:
        print(f"エラー: {input_path} を Shift-JIS としてデコードできませんでした。エンコーディングを確認してください。")
```

この関数は以下の機能を備えています：
1. Shift-JIS エンコーディングの CSV ファイルを読み込み、UTF-8 で保存し直します
2. 入力ファイルが存在しない場合、`FileNotFoundError` をキャッチしてエラーメッセージを表示
3. Shift-JIS のデコードに失敗した場合（文字化けの原因）、`UnicodeDecodeError` をキャッチしてエラーメッセージを表示

使用例：
```python
convert_shift_jis_to_utf8('input.csv', 'output.csv')
```

- 入力ファイルが存在しない場合：`エラー: ファイル input.csv が存在しません。`
- Shift-JIS 以外のエンコーディングのファイルを指定した場合：`エラー: input.csv を Shift-JIS としてデコードできませんでした。エンコーディングを確認してください。`
