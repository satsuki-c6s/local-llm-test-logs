### 📌 代替例：**SQLAlchemy** の基本的な使い方
以下は、**SQLAlchemy**（実際の主流ORM）の基本的な使用例です。SQLiteデータベースを使用し、テーブル作成・CRUD操作を実装します。

#### 1. インストール
```bash
pip install sqlalchemy
```

#### 2. コード例
```python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker

# 1. データベース接続設定（SQLiteを例に）
engine = create_engine('sqlite:///example.db', echo=True)
Base = declarative_base()

# 2. モデル定義（Userテーブル）
class User(Base):
    __tablename__ = 'users'
    id = Column(Integer, primary_key=True)
    name = Column(String(50))
    age = Column(Integer)

# 3. テーブル作成
Base.metadata.create_all(engine)

# 4. セッション作成
Session = sessionmaker(bind=engine)
session = Session()

# 5. データ挿入（CREATE）
new_user = User(name='Alice', age=30)
session.add(new_user)
session.commit()

# 6. データ取得（READ）
users = session.query(User).all()
for user in users:
    print(f"ID: {user.id}, Name: {user.name}, Age: {user.age}")

# 7. データ更新（UPDATE）
alice = session.query(User).filter_by(name='Alice').first()
alice.age = 31
session.commit()

# 8. データ削除（DELETE）
session.delete(alice)
session.commit()
```

#### 出力例
```
ID: 1, Name: Alice, Age: 30
```

### 💡 その他のORMライブラリの特徴
| ライブラリ       | 特徴                                                                 |
|------------------|----------------------------------------------------------------------|
| **SQLAlchemy**   | 柔軟性が高く、大規模プロジェクトに適した「フル機能ORM」               |
| **Peewee**       | 軽量でシンプル、小型プロジェクト向け                                  |
| **Django ORM**   | Djangoフレームワークと連携、Webアプリ開発に最適                       |
| **Tortoise ORM** | asyncio対応、FastAPIなど非同期フレームワークと相性が良い              |
