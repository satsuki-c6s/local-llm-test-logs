## 出力

`sakura-orm` は、SakuraDB（クラウド型 SQL データベース）に同期して動作する Python ライブラリです。このライブラリの基本利用方法は大きく分けて 2 つあります：

1. **直接 SakuraDB に接続しデータ操作を行う**
   （最も一般的な使い方）
2. **Python の `sqlite3` や `psycopg2` と連携して、SakuraDB をバックエンドとして使う**（データベース管理や既存のシステムとの統合時など）

ここでは「1 つ目の方法：直接 SakuraDB に接続し操作を行う」をメインに解説します。コード例は Python 3.8+ の環境で動作するように記述しています。

---

### 基本利用手順とコード例

#### 1. サークル DB クライアントのインストール
まず、必要な依存パッケージをインストールしてください（`pip install sakura-orm` で済みます）。

```bash
pip install sakura-orm
```

#### 2. コードの実装

以下のコードは、「ユーザー情報を保存・取得する」ことを例にしています。

**注意点**: `sakura-db-client` を直接使う場合、通常は Python の標準ライブラリである `sqlalchemy` または `psycopg2` で SQL クエリを生成し、その結果を `sakura-orm` が処理します。**ただし、非常に単純な「保存・取得」のケースでは、`sakura-db-client` を直接使うことも可能ですが、より標準的なパターンとして SQLAlchemy と連携する方法を示します**。

#### 方法 A: サークル DB クライアント（direct connection）を使う場合
この方法は `sqlalchemy` の使用を省略し、SakuraDB に直結して操作する簡易版です。

```python
import sakura_db_client as dbclient
from sqlalchemy import create_engine, Column, Integer, String, DateTime
from datetime import date

# 1. クライアントの初期化 (ユーザー名とパスワードは環境変数や設定ファイルから取得)
db = dbclient.SakuraDBClient(
    username="your_username", 
    password="your_password" # ここに実際の認証情報を入力してください
)

def create_table():
    """テーブルを定義して作成する"""
    
    class User(db.User):
        id_column = Column(Integer, primary_key=True)
        name_column = Column(String(50))
        
    db.create_tables([User]) # テーブルを作成
    
    print("ユーザーテーブルが作成されました。")

def insert_user(user_data: dict):
    """新しいユーザーを保存する"""
    
    user_obj = User(**user_data)  # データ構造に合わせて引数を変換します
    db.add(user_obj)             # クライアントに追加
    
    print(f"ユーザー '{user_data['name']}' が保存されました。")

def get_user_by_id(id: int):
    """指定された ID のユーザーを取得する"""
    
    user = User.query.get(id)  # SQLAlchemy で取得（直接クライアントを使う場合）
    if not user:
        return None
    
    print(f"ID {id} のユーザー名は '{user.name}' です。")

def delete_user(user_id):
    """指定された ID のユーザーを削除する"""
    
    db.delete(User, id=user_id)  # クライアントから削除
    
    print(f"ユーザー (ID: {user_id}) が削除されました。")

# --- メインロジックの実行例 ---

if __name__ == "__main__":
    create_table()
    
    insert_user({"id": "1", "name": "Alice"})  # ID は整数で指定する必要がある場合が多い
    
    user = get_user_by_id(2)                  # Alice の情報を取得（ID: 2）
    
    delete_user(3)                            # ID: 3 のユーザーを削除

# クライアントの終了時に自動的に接続が切断されます。
db.close()
```

#### 方法 B: SQLAlchemy と連携する標準的なパターン（推奨）
SakuraDB をバックエンドとして使いたい場合、`sqlalchemy` でクエリを作成し、その結果を `sakura-orm` のメソッドで処理するのが一般的です。これにより、既存の Python アプリケーションとの整合性が保てます。

```python
import sqlalchemy as sa
from sakura_db_client import SakuraDBClient, User

# 1. クライアント初期化（同様に認証情報が必要）
db = dbclient.SakuraDBClient(
    username="your_username", 
    password="your_password"
)

def create_table():
    """テーブル定義と作成"""
    
    class User(User): # SakuraDB のユーザーモデルを参照
        id_column = sa.Column(sa.Integer, primary_key=True)
        name_column = sa.Column(sa.String(50))
        
    db.create_tables([User])
    print("データベース構造が準備できました。")

def insert_user(user_data: dict):
    """新しいユーザーデータを保存"""
    
    # sqlalchemy でクエリ生成（INSERT）
    stmt = User.insert().values(**user_data)
    result = db.execute(stmt)  # クライアントに実行
    
    if result.rowcount > 0:
        print(f"新規ユーザー '{user_data['name']}' が保存されました。")

def get_user_by_id(id):
    """指定された ID の情報を取得"""
    
    stmt = User.query.get(id)
    return db.execute(stmt).fetchone() # クエリ結果を fetchone で取得
    
# --- 実行例 ---

if __name__ == "__main__":
    create_table()
    
    insert_user({"id": "1", "name": "Bob"})
    
    user = get_user_by_id(2)      # Bob の情報を取得（ID: 2）
    print(f"ユーザー名：{user['name']}")

db.close()
```

### まとめと注意点

| ポイント | 解説 |
| :--- | :--- |
| **認証情報** | `sakura-db-client` を直接使う場合、必ず正しく入力する（環境変数や設定ファイルから読み込むのが推奨）。 |
| **接続管理** | クライアントは自動的に終了します。長時間実行中は `db.close()` 後に再度開く必要はありませんが、リソースを節約するため適切に閉じるべきです。 |
| **エラーハンドリング** | サークル DB は高可用性ですが、ネットワーク障害や認証失敗が発生すると例外（`ConnectionError`, `AuthenticationError`）が出ます。適切な try-except ブロックで処理してください。 |

このように使い分けることで、SakuraDB の強みを活かした柔軟な Python アプリケーション構築が可能です。
