# mesh-llm 特別編 — 家庭内4台クラスタの実測記録

YouTube「さつきのOSS研究室」mesh-llm 特別編で使った実測値の公開記録です。
測定日: 2026-08-06。判定条件は測定前に文書で固定しています (事前登録)。

## 構成

| GPU | VRAM | 役割 |
|---|---|---|
| RTX 5090 | 32GB | ホスト |
| RTX 5080 | 16GB | ワーカー |
| RTX 5080 | 16GB | ワーカー |
| RTX 5060 Ti | 16GB | ワーカー |

mesh-llm 0.74.0 (Linux 版 cuda-13 バンドル)。家庭内LAN、OpenAI互換API 経由で測定。
指標: レスポンスの predicted_per_second (生成トークン/秒)。max_tokens 300〜400、逐次実行。

## 生成速度 (すべて自前実測)

### 単機 RTX 5090 — Qwen3-32B (Q4_K_XL, 20GB)
- n=3: 63.70 / 63.59 / 63.53 tok/s

### 同モデルをあえて2台分散 (VRAM上限 12GB/14GB の参考構成)
- n=1: 8.77 tok/s — 単機に載るモデルの分散は約 1/7 に落ちる

### DeepSeek-R1-Distill-Llama-70B (Q4_K_XL, 45.2GB / 80層)
- 構成A (3台、5090 が約半分を担当): 17.37 tok/s (n=1)
  - 稼働時VRAM: 26,210 / 11,315 / 14,361 MiB
- 構成B (4台、5090 の担当が少なく最弱GPUに厚い): 11.44 / 10.75 / 8.51 tok/s (n=3)
  - 稼働時VRAM: 7,128 / 10,445 / 15,168 / 15,853 MiB
- 層の割り当ては再結成のたびに変わり、最も遅い段に律速される。良い割り当てを
  引くまで組み直す行為はせず、実測をそのまま記録している

### gpt-oss-120b (Q4_K_XL, 62.6GB / 36層 = 15+8+8+8)
- n=4: 35.26 / 34.64 / 32.26 / 31.63 tok/s
- 稼働時VRAM: 26,681 / 13,456 / 12,811 / 12,779 MiB = 合計 65.7GB
- コーディング確認: linked list 反転・素数判定とも実装正答 (finish_reason=stop)

## 注記

- 数値は n=1〜4 の小標本。動画では幅を併記し、平均単独で提示しない
- 2台分散 8.77 は人工的な VRAM 上限をかけた参考値で、32B の標準構成ではない
- ワーカー1台の NIC は 1GbE (他は 5GbE)。トークン生成の通信は数KB/トークンで
  帯域影響は無視できる範囲 (長文プロンプトの一括処理と初回モデル配布のみ影響しうる)
