### 2. 基本的な使い方

#### ① モデルの定義

```python
from sakura_orm import Database, Model, Field, Integer, String, DateTime

# データベース接続
db = Database("sqlite:///example.db")

# モデルの定義
class User(Model):
    id = Field(Integer, primary_key=True)
    name = Field(String(100))
    email = Field(String(255), unique=True)
    created_at = Field(DateTime, default="now")

    class Meta:
        db = db
        table_name = "users"
```

#### ② マイグレーション（テーブル作成）

```python
# モデルのテーブルを作成
db.create_all([User])
```

#### ③ データの追加

```python
# ユーザー追加
user = User(name="Alice", email="alice@example.com")
db.session.add(user)
db.session.commit()
```

#### ④ データの取得

```python
# 全件取得
users = db.session.query(User).all()
for user in users:
    print(user.id, user.name, user.email)

# 条件付き取得
alice = db.session.query(User).filter(User.name == "Alice").first()
print(alice.email)

# 件数取得
count = db.session.query(User).count()
print(f"ユーザー数: {count}")
```

#### ⑤ 更新

```python
user = db.session.query(User).filter(User.id == 1).first()
user.name = "Alice Updated"
db.session.commit()
```

#### ⑥ 削除

```python
user = db.session.query(User).filter(User.id == 1).first()
db.session.delete(user)
db.session.commit()
```
