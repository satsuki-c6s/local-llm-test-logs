## 出力

以下に、Shift-JIS の CSV ファイルを UTF-8 で再保存する Python 関数を実装します。
存在しないファイルや、Shift-JIS デコードエラー（例：`UnicodeDecodeError`）への対応を含みます。

```python
import os

def shift_jis_to_utf8_csv(input_path: str, output_path: str) -> None:
    """
    Shift-JIS の CSV ファイルを読み込み、UTF-8 で保存し直す関数。
    
    引数:
        input_path (str): 読み込むファイルパス（Shift-JIS）
        output_path (str): 書き出すファイルパス（UTF-8）
        
    例外:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: Shift-JIS デコードが失敗した場合
        IOError: ファイルの読み書きエラーが発生した場合
    """
    
    # 1. ファイル存在確認
    if not os.path.exists(input_path):
        raise FileNotFoundError(f"入力ファイル '{input_path}' が存在しません。")

    try:
        # 2. Shift-JIS で読み込み（strict モードでデコードエラーを発生させる）
        with open(input_path, 'r', encoding='shift-jis') as f_in:
            content = f_in.read()
            
        # 3. UTF-8 で書き出し
        with open(output_path, 'w', encoding='utf-8') as f_out:
            f_out.write(content)
            
    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(
            e.encoding, 
            e.object, 
            e.start, 
            e.end, 
            f"Shift-JIS デコードエラー: {e}"
        ) from e
    except IOError as e:
        raise IOError(f"ファイル処理中にエラーが発生しました: {e}") from e

# --- 使用例（テスト用）---
if __name__ == "__main__":
    # テスト用のShift-JIS CSVを作成（実際のテストには実ファイルが必要）
    test_input = "test_shift_jis.csv"
    test_output = "output_utf8.csv"
    
    try:
        # 1. 正常なシナリオ
        print("【試行1】正常なシナリオ...")
        shift_jis_to_utf8_csv(test_input, test_output)
        print(f"成功: {test_output} が作成されました。")
        
        # 2. ファイル不存在のエラー処理テスト
        print("\n【試行2】ファイル不存在のエラー処理...")
        shift_jis_to_utf8_csv("non_existent_file.csv", test_output)
    except FileNotFoundError as e:
        print(f"FileNotFoundError: {e}")
        
    except UnicodeDecodeError as e:
        print(f"UnicodeDecodeError: {e}")
        
    except IOError as e:
        print(f"IOError: {e}")
```

### 主なポイント

1. **`os.path.exists()` で存在チェック**  
   ファイルが存在しない場合に `FileNotFoundError` を明示的に発生させます。

2. **`encoding='shift-jis'` で読み込み**  
   Python の `open()` でエンコーディングを指定し、Shift-JIS としてデコードします。デコードエラーが発生すると `UnicodeDecodeError` が自動で発生しますが、それをキャッチして再throwすることで、より明確なエラーメッセージを提供できます。

3. **`encoding='utf-8'` で書き出し**  
   読み込んだ内容を UTF-8 エンコーディングで出力ファイルに書き込みます。

4. **例外の伝播（`from e`）**  
   `raise ... from e` を使用することで、元のエラー情報を保持したまま新しいエラーを発生させます。これによりデバッグが容易になります。
