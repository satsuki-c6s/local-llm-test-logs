## 出力 (本文そのまま)

以下は、Shift-JISのCSVファイルを読み込んでUTF-8で保存するPython関数です。ファイルが存在しない場合や文字化け（デコード失敗）した場合のエラー処理も含まれています。

```python
def convert_csv_shift_jis_to_utf8(input_file_path, output_file_path, add_bom=False):
    """
    Shift-JISでエンコードされたCSVファイルを読み込んでUTF-8で保存します。
    
    Args:
        input_file_path (str): 入力ファイルのパス。
        output_file_path (str): 出力ファイルのパス。
        add_bom (bool, optional): 出力ファイルにBOMを追加するかどうか。デフォルトはFalse。
    
    Returns:
        tuple: (成功した場合True, エラーメッセージのない場合None) 他の場合Falseとエラーメッセージ。
    """
    try:
        # Shift-JISでファイルを読み込む
        with open(input_file_path, 'r', encoding='shift-jis') as file:
            content = file.read()
    except FileNotFoundError:
        return False, f"入力ファイル '{input_file_path}' は存在しません。"
    except UnicodeDecodeError:
        return False, f"入力ファイル '{input_file_path}' のデコードに失敗しました。"
    except Exception as e:
        return False, f"予期せぬエラーが発生しました: {str(e)}"
    
    # UTF-8で保存する
    try:
        with open(output_file_path, 'w', encoding='utf-8') as file:
            if add_bom:
                file.write('\ufeff')  # BOMを追加
            file.write(content)
    except Exception as e:
        return False, f"出力ファイル '{output_file_path}' の保存に失敗しました: {str(e)}"
    
    return True, None

# 使用例
success, error_message = convert_csv_shift_jis_to_utf8('input.csv', 'output.csv', add_bom=True)
if success:
    print("正常に変換されました。")
else:
    print(f"エラー: {error_message}")
```

### 機能説明：
1. **Shift-JISのファイル読み込み**:
   - `input_file_path`で指定されたファイルをShift-JISで読み込みます。
   - ファイルが存在しない場合、`FileNotFoundError`が発生し、該当のエラーメッセージを返します。
   - デコードに失敗した場合、`UnicodeDecodeError`が発生し、該当のエラーメッセージを返します。

2. **UTF-8での保存**:
   - 読み込んだ内容を`output_file_path`で指定されたパスにUTF-8で保存します。
   - `add_bom`が`True`の場合、UTF-8 BOMをファイルの先頭に追加します。
   - ファイルの保存に失敗した場合、該当のエラーメッセージを返します。

3. **戻り値**:
   - 正常に処理された場合、`True`と`None`を返します。
   - エラーが発生した場合、`False`とエラーメッセージを返します。

### 使用例：
上記のコード例では、`input.csv`というShift-JISのCSVファイルを読み込んで、`output.csv`としてUTF-8で保存しています。`add_bom`を`True`に設定しているため、UTF-8 BOMが追加されます。
