## 出力 (本文そのまま)

「sakura-orm」は、Python用の軽量なORM（Object-Relational Mapping）ライブラリです。MySQL、PostgreSQL、SQLiteに対応しており、簡単なORM機能を提供します。以下に基本的な使い方をコード例付きで説明します。

### 1. インストール
まず、pipを使用して「sakura-orm」をインストールします。

```bash
pip install sakura-orm
```

### 2. 基本的な使い方
以下に、基本的なCRUD（Create, Read, Update, Delete）操作の例を示します。

#### 2.1 データベース接続
データベースに接続するために、`Database` クラスを使用します。

```python
from sakura.orm import Database

# データベース接続設定
db = Database(
    dialect='mysql',  # 使用するデータベース (mysql, postgresql, sqlite)
    host='localhost',
    port=3306,
    user='root',
    password='password',
    database='mydatabase'
)
```

#### 2.2 モデルの定義
データベースのテーブルを表すモデルを定義します。

```python
from sakura.orm import Model, fields

class User(Model):
    __tablename__ = 'users'

    id = fields.Integer(primary=True)
    name = fields.String(255)
    email = fields.String(255, unique=True)
```

#### 2.3 レコードの作成 (Create)
`create()` メソッドを使用してレコードを作成します。

```python
# ユーザーを作成する
user = User(name='John Doe', email='john@example.com')
db.insert(user)
```

#### 2.4 レコードの取得 (Read)
`find()` メソッドを使用してレコードを取得します。

```python
# 全てのユーザーを取得する
users = db.find(User)

# 特定のユーザーを取得する
user = db.find_one(User, where='email = "john@example.com"')
```

#### 2.5 レコードの更新 (Update)
`update()` メソッドを使用してレコードを更新します。

```python
# ユーザーの情報を更新する
user.name = 'Jane Doe'
db.update(user)
```

#### 2.6 レコードの削除 (Delete)
`delete()` メソッドを使用してレコードを削除します。

```python
# ユーザーを削除する
db.delete(user)
```

### 3. まとめ
「sakura-orm」は、シンプルで軽量なORMライブラリです。基本的なCRUD操作が簡単に実行でき、MySQL、PostgreSQL、SQLiteに対応しています。モデル定義やクエリの作成が容易で、小規模なプロジェクトや学習に適したライブラリです。

以上が「sakura-orm」の基本的な使い方です。
