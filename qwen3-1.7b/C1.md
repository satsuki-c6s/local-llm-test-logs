## 出力

「sakura-orm」は、Pythonでデータベース操作を行うためのライブラリです。このライブラリは、SQLを直接実行するのではなく、ORM（Object-Relational Mapping）のアプローチを採用しており、モデル（モデル）とデータベースの関係を抽象化して操作します。

## 📝 2. モデルの定義（例）

```python
from sakura.orm import Model, Column, Integer, String

class User(Model):
    id = Column(Integer, primary_key=True)
    name = Column(String(50))
    email = Column(String(100))

    def __str__(self):
        return f"User({self.id}, {self.name}, {self.email})"
```

- モデルを定義
- データベースを接続
- データを挿入、取得、更新、削除

- モデルのクエリ
