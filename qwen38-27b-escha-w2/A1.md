## 出力

```python
import os
import csv


def convert_shiftjis_to_utf8(input_path: str, output_path: str) -> None:
    """
    Shift-JISエンコードされたCSVファイルを読み込み、UTF-8で保存する。

    Args:
        input_path: 入力ファイルのパス（Shift-JISエンコード）
        output_path: 出力ファイルのパス（UTF-8エンコード）

    Raises:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: 文字化け（デコード失敗）が発生した場合
    """
    # ファイル存在チェック
    if not os.path.exists(input_path):
        raise FileNotFoundError(f"ファイルが存在しません: {input_path}")

    # Shift-JISで読み込み
    try:
        with open(input_path, 'r', encoding='shift_jis') as f:
            reader = csv.reader(f)
            rows = list(reader)
    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(
            e.encoding, e.object, e.start, e.end,
            f"Shift-JISデコード失敗: {input_path}"
        )

    # UTF-8で書き込み
    with open(output_path, 'w', encoding='utf-8', newline='') as f:
        writer = csv.writer(f)
        writer.writerows(rows)
```

### 使い方例

```python
try:
    convert_shiftjis_to_utf8("input.csv", "output.csv")
    print("変換完了")
except FileNotFoundError as e:
    print(f"エラー: {e}")
except UnicodeDecodeError as e:
    print(f"文字化けエラー: {e}")
```

### 主なポイント

| 項目 | 説明 |
|------|------|
| **ファイル存在チェック** | `os.path.exists` で事前チェックし、`FileNotFoundError` を明示的に raise |
| **デコードエラー処理** | `UnicodeDecodeError` を捕捉し、より明確なエラーメッセージで再 raise |
| **CSV処理** | `csv.reader` / `csv.writer` を使用し、カンマ区切りや引用符の処理を適切に扱う |
| **エンコーディング** | 読み込みは `shift_jis`、書き込みは `utf-8` |
| **`newline=''`** | CSV書き込み時の改行コード問題を回避 |

### 補足

- 入力ファイルがBOM付きUTF-8や他のエンコーディングである場合、`UnicodeDecodeError` が発生します。
- 大量のファイルを一括変換する場合は、この関数をループで呼び出すか、`glob` でファイルリストを取得して処理してください。
- 出力ファイルのディレクトリが存在しない場合は、事前に `os.makedirs` でディレクトリを作成してください。
