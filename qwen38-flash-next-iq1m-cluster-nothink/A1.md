## 出力

以下は、Shift-JISのCSVファイルを読み込み、UTF-8で保存し直す関数です。エラー処理（ファイル不存在、デコード失敗）を含んでいます。

```python
import csv
import os
from pathlib import Path


def convert_sjis_csv_to_utf8(input_path: str, output_path: str) -> None:
    """
    Shift-JISでエンコードされたCSVファイルを読み込み、UTF-8で保存し直す。

    Args:
        input_path: 入力ファイルのパス（Shift-JISエンコード）
        output_path: 出力ファイルのパス（UTF-8エンコード）

    Raises:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: Shift-JISでデコードできない場合
        IOError: ファイルの読み書きに失敗した場合
    """
    # 入力ファイルの存在チェック
    if not os.path.exists(input_path):
        raise FileNotFoundError(f"入力ファイルが見つかりません: {input_path}")

    # 出力ディレクトリの作成（必要に応じて）
    output_dir = os.path.dirname(output_path)
    if output_dir:
        os.makedirs(output_dir, exist_ok=True)

    try:
        # Shift-JISで読み込み
        with open(input_path, mode='r', encoding='shift-jis', newline='') as infile:
            reader = csv.reader(infile)
            rows = list(reader)

        # UTF-8で書き込み
        with open(output_path, mode='w', encoding='utf-8', newline='') as outfile:
            writer = csv.writer(outfile)
            writer.writerows(rows)

    except FileNotFoundError as e:
        raise FileNotFoundError(f"ファイルが見つかりません: {e}") from e
    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(
            encoding=e.encoding,
            object=e.object,
            start=e.start,
            end=e.end,
            reason=f"Shift-JISデコード失敗: {e.reason}"
        ) from e
    except IOError as e:
        raise IOError(f"ファイルの読み書きに失敗しました: {e}") from e


# 使用例
if __name__ == "__main__":
    input_file = "input_sjis.csv"
    output_file = "output_utf8.csv"

    try:
        convert_sjis_csv_to_utf8(input_file, output_file)
        print(f"変換完了: {input_file} -> {output_file}")
    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError as e:
        print(f"デコードエラー: {e}")
    except IOError as e:
        print(f"I/Oエラー: {e}")
```

### 主なポイント

1. **ファイル存在チェック**: `os.path.exists()` で入力ファイルの存在を確認し、`FileNotFoundError` を明示的に発生させます。

2. **デコードエラー処理**: `UnicodeDecodeError` をキャッチして、元の例外情報を保持しつつ再スローします。

3. **`newline=''` の指定**: CSVモジュールの仕様上、`newline=''` を指定することで、改行コードの扱いを正しく制御します。

4. **出力ディレクトリ作成**: 出力先のディレクトリが存在しない場合は `os.makedirs()` で作成します。

5. **例外チェーン**: `from e` を使用して、元の例外情報を保持しつつ、より具体的なエラーメッセージを提供します。
