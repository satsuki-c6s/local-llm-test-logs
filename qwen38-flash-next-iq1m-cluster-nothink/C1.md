## 一般的なPython ORMの基本的な使い方（参考）

もし一般的なORMの使い方を学びたい場合は、以下に**SQLAlchemy**（最も広く使われているPython ORM）の基本的な例を示します：

```python
# SQLAlchemy 2.0 の基本例
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base, sessionmaker

# データベース接続設定
engine = create_engine("sqlite:///example.db")
Base = declarative_base()

# モデル定義
class User(Base):
    __tablename__ = 'users'
    
    id = Column(Integer, primary_key=True)
    name = Column(String(50), nullable=False)
    email = Column(String(100), unique=True)

# テーブル作成
Base.metadata.create_all(engine)

# セッション作成
Session = sessionmaker(bind=engine)
session = Session()

# レコード作成
new_user = User(name="田中 太郎", email="taro@example.com")
session.add(new_user)
session.commit()

# レコード取得
users = session.query(User).all()
for user in users:
    print(f"ID: {user.id}, Name: {user.name}, Email: {user.email}")

# レコード更新
user = session.query(User).filter(User.name == "田中 太郎").first()
if user:
    user.email = "taro.updated@example.com"
    session.commit()

# レコード削除
user = session.query(User).filter(User.name == "田中 太郎").first()
if user:
    session.delete(user)
    session.commit()

session.close()
```
