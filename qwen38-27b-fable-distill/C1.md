## 出力

`sakura-orm` は Python の ORM ライブラリで、SQLAlchemy と似た設計思想を持っています。基本的な使い方をコード例付きで説明します。

## インストール

```bash
pip install sakura-orm
```

## 1. モデルの定義

```python
from sakura_orm import Model, Column, Integer, String, DateTime
from sakura_orm.orm import Session

class User(Model):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True)
    name = Column(String(50), nullable=False)
    email = Column(String(100), unique=True)
    created_at = Column(DateTime)
```

## 2. セッションの作成

```python
from sakura_orm.orm import Session

# SQLite の場合
session = Session("sqlite:///example.db")

# MySQL の場合
# session = Session("mysql://user:password@localhost:3306/mydb")

# PostgreSQL の場合
# session = Session("postgresql://user:password@localhost:5432/mydb")
```

## 3. テーブルの作成

```python
from sakura_orm.orm import metadata

metadata.create_all(session)
```

## 4. レコードの作成（INSERT）

```python
user = User(name="Taro", email="taro@example.com")
session.add(user)
session.commit()

print(user.id)  # 自動採番された ID
```

## 5. レコードの取得（SELECT）

```python
# 主キーで取得
user = session.get(User, 1)

# クエリで検索
users = session.query(User).filter(User.name == "Taro").all()

# 1件だけ取得
user = session.query(User).filter(User.email == "taro@example.com").first()

# 条件付き検索
adults = session.query(User).filter(User.name.like("%Taro%")).all()
```

## 6. 更新（UPDATE）

```python
user = session.get(User, 1)
user.name = "Hanako"
session.commit()
```

## 7. 削除（DELETE）

```python
user = session.get(User, 1)
session.delete(user)
session.commit()
```

## 8. 関連付け（Relationship）

```python
from sakura_orm import relationship

class User(Model):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True)
    name = Column(String(50))
    posts = relationship("Post", back_populates="author")

class Post(Model):
    __tablename__ = "posts"

    id = Column(Integer, primary_key=True)
    title = Column(String(100))
    user_id = Column(Integer, ForeignKey("users.id"))
    author = relationship("User", back_populates="posts")
```

## 9. トランザクション

```python
try:
    user = User(name="Taro", email="taro@example.com")
    session.add(user)
    session.commit()
except Exception:
    session.rollback()
    raise
```

## 10. セッションのクローズ

```python
session.close()
```

## 注意点

- `sakura-orm` は SQLAlchemy と API が似ていますが、完全に互換ではありません。
- 実際の API はバージョンによって異なる場合があります。
- 本番環境では、接続プールやエラーハンドリングを適切に設定してください。
