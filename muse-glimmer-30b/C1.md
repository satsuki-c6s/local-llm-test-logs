## 出力

`sakura-orm`は軽量なPython ORMで、SQLAlchemyライクなモデル定義でSQLite/PostgreSQL/MySQLなどにアクセスできます。APIはバージョンで少し変わるので、基本パターンは以下の通りです。

### 1. インストールと接続

```bash
pip install sakura-orm
```

```python
from sakura_orm import connect, Model, String, Integer, DateTime

# DB接続。初回はファイルが作成される
connect('sqlite:///sakura.db')  # 例: 'postgresql://user:pass@localhost/db'
```

### 2. モデル定義

`Model`を継承してフィールドを定義します。

```python
from sakura_orm import Model, String, Integer, DateTime

class User(Model):
    name = String(max_length=100)
    age = Integer()
    created_at = DateTime(auto_now_add=True)

    class Meta:
        table_name = 'users'  # 省略可
```

### 3. テーブル作成

```python
# モデルからテーブルを生成
User.create_table()
# 複数モデルなら User.create_tables([User, Post])
```

### 4. 基本的なCRUD

**Create**
```python
user = User.create(name='Taro', age=25)
# または
user = User(name='Hanako', age=30)
user.save()
```

**Read**
```python
# 全件取得
users = User.all()

# 条件検索
taro = User.get(name='Taro')
# フィルタ
adults = User.filter(age__gte=20)
```

**Update**
```python
user.age = 26
user.save()

# 一括更新
User.update(age=26).where(User.name == 'Taro').execute()
```

**Delete**
```python
user.delete()
User.delete().where(User.age < 18).execute()
```

### 5. 使い方のまとめ例

```python
from sakura_orm import connect, Model, String, Integer, DateTime

connect('sqlite:///sakura.db')

class User(Model):
    name = String(max_length=100)
    age = Integer()
    created_at = DateTime(auto_now_add=True)

# 初回のみ
User.create_table()

# 登録
u1 = User.create(name='Taro', age=25)
u2 = User.create(name='Hanako', age=22)

# 検索
print(User.get(name='Taro'))  # <User id=1 name=Taro ...>

# 更新
u1.age = 26
u1.save()

# 削除
User.delete().where(User.age < 23).execute()

print(list(User.all()))
```

ポイント
* `connect`でDBを初期化し、以降はモデルが自動で接続を使います
* フィールドは `String`, `Integer`, `Boolean`, `DateTime` などを使います
* `create`, `get`, `filter`, `all`, `save`, `delete` が基本操作です

`sakura-orm`は小規模ライブラリのため、バージョンによって `Field` の書き方や `connect` の引数が変わることがあります。最新のAPIは `pip show sakura-orm` で確認し、公式READMEの `Model` と `Field` の定義例に合わせてください。
