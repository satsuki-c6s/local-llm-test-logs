## プロンプト

```
PythonでShift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数を書いてください。
存在しないファイルと文字化け(デコード失敗)のエラー処理も含めてください。
```

## 出力

Shift-JISのCSVをUTF-8に変換する場合は `encoding` を指定して読み書きするだけでOKです。存在しないファイルとデコード失敗は例外で捕捉します。

```python
import csv
from pathlib import Path

def convert_shiftjis_csv_to_utf8(input_path: str | Path, output_path: str | Path) -> bool:
    input_path = Path(input_path)
    output_path = Path(output_path)

    try:
        # Shift-JISで読み込み
        with open(input_path, 'r', encoding='shift_jis', newline='') as fin:
            reader = csv.reader(fin)

            # UTF-8で書き込み
            with open(output_path, 'w', encoding='utf-8', newline='') as fout:
                writer = csv.writer(fout)
                for row in reader:
                    writer.writerow(row)

        print(f"変換完了: {input_path} -> {output_path}")
        return True

    except FileNotFoundError:
        print(f"エラー: ファイルが見つかりません: {input_path}")
        return False

    except UnicodeDecodeError as e:
        # Shift-JISとしてデコードできない場合
        print(f"エラー: Shift-JISのデコードに失敗しました。文字化けの可能性があります。")
        print(f"詳細: {e}")
        return False

    except PermissionError:
        print(f"エラー: ファイルにアクセスできません。権限を確認してください: {input_path}")
        return False

    except Exception as e:
        print(f"エラー: 予期しないエラーが発生しました: {e}")
        return False


# 使用例
if __name__ == "__main__":
    convert_shiftjis_csv_to_utf8("input_sjis.csv", "output_utf8.csv")
```

### ポイント
* `open(..., encoding='shift_jis', newline='')` でShift-JISを正しく読み込み、CSVの改行を壊さない
* `csv.reader` / `csv.writer` をストリームで使うので大きなファイルでもメモリに載らない
* `FileNotFoundError` で存在しないファイル、`UnicodeDecodeError` でデコード失敗を個別に処理
* WindowsのShift-JISは `cp932` が実質的な標準です。必要なら `encoding='cp932'` に変更してください

必要なら `errors='replace'` を付けてデコード失敗時に置換文字にすることもできますが、今回はエラーとして検知する形にしています。
