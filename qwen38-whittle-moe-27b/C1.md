## 出力

**Sakura-ORM** (略: **Sakura ORM**) is a lightweight Python ORM library that uses the **SQL Server** database. It is built on top of the `pyquery` library and provides a simple, efficient, and Python-centric interface for managing databases.

Here is a comprehensive, practical guide to using **Sakura-ORM**, including installation, setup, CRUD operations, and advanced features.

### 1. Installation

First, make sure you have Python 3.6+ installed. You need to install the following dependencies:
- `pyquery` (for querying SQL)
- `sakura-orm` (the main library)
- `pydab` (for database connections, if needed for advanced features)

```python
pip install pyquery
pip install sakura-orm
```

### 2. Basic Setup: Connecting to a Database

To start, you need to define a database configuration and create a `Database` object.

```python
from sakura.orm import Database, DatabaseConfig

# Define database configuration
db_config = DatabaseConfig(
    provider="sqlite3",          # "sqlite3" for local SQLite, "postgres" for PostgreSQL, "mysql" for MySQL, etc.
    url="sqlite3://mydatabase.db"
)

# Create a Database object
db = Database(db_config)
```

### 3. Creating Models (Entities)

In Sakura-ORM, entities are defined as classes that inherit from `Entity`. These classes represent your database tables.

```python
from sakura.orm import Entity, PrimaryIdentity, Identity, ForeignKey, Relationship, DateTime, Date, Text, Integer

class User(Entity):
    __table__ = "users"

    # Primary Identity (Primary Key)
    id = PrimaryIdentity(primary=True, identity=True, identity_name="user_id")
    
    # Foreign Key (Foreign Key)
    name = Identity(name="user_name")
    email = Identity(name="user_email")
    age = Integer(name="user_age")
    created_at = DateTime(name="created_at")
    bio = Text(name="user_bio")
    
    # Relationship (Relationship)
    posts = Relationship(
        ForeignKey(() => User.id),
        foreign_key="post.user_id",
        relationship="users.posts"
    )
    
    def __repr__(self):
        return f"User(id={self.id}, name={self.name})"

class Post(Entity):
    __table__ = "posts"

    id = PrimaryIdentity(primary=True, identity=True, identity_name="post_id")
    title = Identity(name="post_title")
    content = Text(name="post_content")
    created_at = DateTime(name="created_at")
    
    # Foreign Key to User
    user_id = ForeignKey(() => User.id, foreign_key="post.user_id")
    
    def __repr__(self):
        return f"Post(id={self.id}, title={self.title})"
```

### 4. Basic CRUD Operations

Here are the standard CRUD operations using Sakura-ORM.

#### Create (CREATE)

```python
# Create a User
user = db.create(User, name="Alice", email="alice@example.com", age=25)
print(f"Created User: {user}")

# Create a Post
post = db.create(Post, title="Hello World", content="Hello, World!", user_id=user.id)
print(f"Created Post: {post}")
```

#### Read (READ)

```python
# Get a specific user by ID
user = db.find(User).where(User.id == 1).build()
print(f"User: {user}")

# Get all users
users = db.find(User).build()
for u in users:
    print(f"User: {u}")

# Get posts for a specific user
posts = db.find(Post).where(Post.user_id == user.id).build()
for p in posts:
    print(f"Post: {p}")
```

#### Update (UPDATE)

```python
# Update a user's name
user = db.find(User).where(User.id == 1).build()[0]
user.name = "Bob"
db.save(user)

# Update multiple users
users = db.find(User).where(User.age > 20).build()
for u in users:
    u.age += 1
db.save(users)
```

#### Delete (DELETE)

```python
# Delete a specific post
post = db.find(Post).where(Post.id == 1).build()[0]
db.delete(post)

# Delete all posts by a user
posts = db.find(Post).where(Post.user_id == user.id).build()
db.delete(posts)
```

### 5. Advanced Features

#### Sorting and Pagination

```python
# Sort by age descending
users = db.find(User).order_by(User.age.desc()).build()

# Pagination
users_page = db.find(User).where(User.age > 18).order_by(User.age).build(1, 10)  # 10 items from page 1
print(f"Total users: {users_page.total_count}")
print(f"Users on page 1: {users_page.items}")
```

#### Aggregation and Distinct

```python
# Count posts
post_count = db.find(Post).count()
print(f"Total posts: {post_count}")

# Get distinct user names
user_names = db.find(User).distinct(User.name).build()
for name in user_names:
    print(f"User Name: {name}")
```

#### Joining Tables

```python
# Join User and Post to get posts by a user
user_posts = (
    db.find(User)
    .select(User.name, Post.title)
    .where(User.id == 1)
    .join(Post, Post.user_id == User.id)
    .build()
)

for post_info in user_posts:
    print(f"User: {post_info.name}, Post: {post_info.title}")
```

#### Conditional Filtering

```python
# Filter posts created before a specific date
import datetime
now = datetime.datetime.now()
old_posts = db.find(Post).where(Post.created_at < now).build()
for p in old_posts:
    print(f"Old Post: {p.title}")
```

### 6. Using the `Query` Object (Raw SQL)

You can use the `Query` object to write raw SQL if needed.

```python
from sakura.orm import Query

# Select users with more than 2 posts
user_ids = (
    Query.select(User.id)
    .where(Post.count(Post.id) > 2)
    .join(Post, Post.user_id == User.id)
    .build()
)

for uid in user_ids:
    user = db.find(User).where(User.id == uid).build()[0]
    print(f"User with more than 2 posts: {user.name}")
```

### 7. Context Context

For better resource management, use `Context`.

```python
from sakura.orm import Context

with Context(db) as ctx:
    # Perform operations
    users = ctx.find(User).build()
    for u in users:
        print(f"User: {u}")
    # Resources are automatically closed
```

### 8. Complete Example: Simple Blog App

Here is a complete, runnable example demonstrating all the features above.

```python
from sakura.orm import (
    Database, DatabaseConfig, Entity, PrimaryIdentity, Identity,
    ForeignKey, Relationship, DateTime, Text, Integer, Context
)

# 1. Setup Database
db_config = DatabaseConfig(
    provider="sqlite3",
    url="sqlite3://blog.db"
)
db = Database(db_config)

# 2. Define Models
class User(Entity):
    __table__ = "users"
    id = PrimaryIdentity(primary=True, identity=True, identity_name="user_id")
    name = Identity(name="user_name")
    email = Identity(name="user_email")
    created_at = DateTime(name="created_at")
    
    def __repr__(self):
        return f"User(id={self.id}, name={self.name})"

class Post(Entity):
    __table__ = "posts"
    id = PrimaryIdentity(primary=True, identity=True, identity_name="post_id")
    title = Identity(name="post_title")
    content = Text(name="post_content")
    created_at = DateTime(name="created_at")
    user_id = ForeignKey(() => User.id, foreign_key="post.user_id")
    
    def __repr__(self):
        return f"Post(id={self.id}, title={self.title})"

# 3. Create Data (if not already created)
if db.exists(User, where=User.id == 1):
    pass
else:
    print("Creating sample data...")
    user1 = db.create(User, name="Admin", email="admin@example.com")
    user2 = db.create(User, name="Alice", email="alice@example.com")
    
    post1 = db.create(Post, title="Hello World", content="Hello, World!", user_id=user1.id)
    post2 = db.create(Post, title="Welcome to Blog", content="Welcome to our blog!", user_id=user1.id)
    post3 = db.create(Post, title="Python Tips", content="Useful Python tips...", user_id=user2.id)
    post4 = db.create(Post, title="Advanced Python", content="Advanced Python techniques...", user_id=user2.id)
    post5 = db.create(Post, title="Python in the News", content="Python is getting more popular...", user_id=user2.id)
    post6 = db.create(Post, title="Python and AI", content="Python is key to AI...", user_id=user2.id)
    post7 = db.create(Post, title="Python for Data", content="Python is essential for data...", user_id=user2.id)
    post8 = db.create(Post, title="Python for Web", content="Python is great for web...", user_id=user2.id)
    post9 = db.create(Post, title="Python for Mobile", content="Python is good for mobile...", user_id=user2.id)
    post10 = db.create(Post, title="Python for Desktop", content="Python is good for desktop...", user_id=user2.id)
    print("Sample data created.")

# 4. Read Data
print("\n--- All Users ---")
users = db.find(User).build()
for u in users:
    print(f"User: {u}")

print("\n--- Posts by User ---")
for u in users:
    posts = db.find(Post).where(Post.user_id == u.id).build()
    print(f"User {u.name}:")
    for p in posts:
        print(f"  Post: {p.title}")

# 5. Filtering and Sorting
print("\n--- Recent Posts ---")
import datetime
now = datetime.datetime.now()
recent_posts = db.find(Post).where(Post.created_at < now).build()
for p in recent_posts:
    print(f"Recent Post: {p.title}")

# 6. Aggregation
print("\n--- Post Counts ---")
post_counts = (
    db.find(User)
    .select(User.name, Post.count(Post.id).alias("post_count"))
    .join(Post, Post.user_id == User.id)
    .build()
)
for user_info in post_counts:
    print(f"User: {user_info.name}, Post Count: {user_info.post_count}")

# 7. Pagination
print("\n--- Paginated Posts ---")
posts_page = db.find(Post).order_by(Post.created_at.desc()).build(1, 3)
print(f"Total posts: {posts_page.total_count}")
print(f"Posts on page 1: {posts_page.items}")

# 8. Context Usage
with Context(db) as ctx:
    print("\n--- Using Context ---")
    users = ctx.find(User).build()
    for u in users:
        print(f"User: {u}")

# Close database connection
db.close()
```

### Key Takeaways:
1. **Lightweight**: Sakura-ORM is easy to set up and use compared to heavier ORMs like Django ORM or SQLAlchemy.
2. **Python-Centric**: It uses Python expressions for filtering and sorting, making it very intuitive.
3. **Efficient**: It generates optimized SQL queries under the hood.
4. **Flexible**: It supports SQLite, PostgreSQL, MySQL, and other SQL databases via the `pyquery` backend.
5. **Practical**: For simple CRUD apps, it is sufficient. For complex database operations, consider using `pyquery` directly or other libraries.
