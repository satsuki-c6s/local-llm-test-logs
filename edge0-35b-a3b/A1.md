```python
import csv
import os


def convert_shift_jis_to_utf8(input_file: str, output_file: str) -> None:
    """
    Shift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数。

    引数:
        input_file: Shift-JISのCSVファイルのパス
        output_file: UTF-8で保存するCSVファイルのパス

    エラー処理:
        - 存在しないファイルの場合、FileNotFoundErrorを投げます。
        - 文字化け（デコード失敗）の場合、UnicodeDecodeErrorを投げます。
    """
    # 入力ファイルの存在確認
    if not os.path.exists(input_file):
        raise FileNotFoundError(f"入力ファイル '{input_file}' が存在しません。")

    # 読み込みと書き込み
    with open(input_file, 'r', encoding='shift_jis') as infile:
        reader = csv.reader(infile)
        with open(output_file, 'w', encoding='utf-8') as outfile:
            writer = csv.writer(outfile)
            for row in reader:
                writer.writerow(row)


# 使用例
if __name__ == '__main__':
    try:
        convert_shift_jis_to_utf8('input_shift_jis.csv', 'output_utf8.csv')
        print("ファイルの変換が完了しました。")
    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError as e:
        print(f"文字化けエラー: {e}")
```

### 解説：
1. **ファイルの存在確認**: `os.path.exists()` で入力ファイルが存在するかを確認し、存在しない場合は `FileNotFoundError` を投げます。
2. **読み込み**: `encoding='shift_jis'` でShift-JISのCSVファイルを読み込みます。
3. **書き込み**: `encoding='utf-8'` でUTF-8のCSVファイルに書き込みます。
4. **文字化けエラー処理**: デコードに失敗した場合、`UnicodeDecodeError` が投げられます。これをキャプチャしてエラーメッセージを表示します。

この関数は、Shift-JISのCSVファイルを読み込んでUTF-8で保存し直す処理を安全に行います。
