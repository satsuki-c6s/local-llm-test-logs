# Sakura ORM の基本的な使い方

Sakura ORM は、Python で SQLAlchemy 2.0 互換の ORM を提供するライブラリです。SQLAlchemy 2.0 に対応しており、`async` 対応も可能です。

## インストール

```bash
pip install sakura-orm
```

## 基本的な使い方

### 1. モデルの定義

```python
from sakura import Model, Field
from typing import Optional
from datetime import datetime

class User(Model):
    id = Field("id", primary_key=True)
    name = Field("name", string=True)
    email = Field("email", string=True)
    age = Field("age", integer=True)
    created_at = Field("created_at", datetime=True)
    is_active = Field("is_active", boolean=True, default=True)

    class Meta:
        table_name = "users"
```

### 2. データベース接続

```python
from sakura import Database

db = Database("sqlite:///example.db")
db.connect()
```

### 3. テーブルの作成

```python
db.create_tables([User])
```

### 4. データの挿入

```python
user = User(name="Alice", email="alice@example.com", age=30)
db.insert(user)
```

### 5. データの取得

```python
# 単一レコード取得
user = db.get(User, 1)

# 複数レコード取得
users = db.query(User)

# 条件付き取得
users = db.query(User).filter(User.age > 25)

# 検索
users = db.query(User).filter(User.name == "Alice")
```

### 6. データの更新

```python
user = db.get(User, 1)
user.age = 31
user.is_active = False
db.update(user)
```

### 7. データの削除

```python
db.delete(user)
```

### 8. 検索・ソート・ページネーション

```python
# 検索
users = db.query(User).filter(User.name.like("%Alice%"))

# ソート
users = db.query(User).order_by(User.age.desc())

# ページネーション
users = db.query(User).paginate(page=1, per_page=10)
```

### 9. 非同期対応（async）

```python
from sakura import AsyncDatabase

async_db = AsyncDatabase("sqlite:///example.db")
async_db.connect()

async def main():
    async with async_db:
        user = await async_db.get(User, 1)
        await async_db.insert(User(name="Bob", email="bob@example.com", age=25))
        await async_db.commit()

# 実行
import asyncio
asyncio.run(main())
```

### 10. 追加の便利な機能

```python
# 複数レコードの挿入
users = [User(name=f"User{i}", email=f"user{i}@example.com", age=20+i) for i in range(1, 11)]
db.insert(users)

# 更新のバッチ処理
users = db.query(User).filter(User.age > 25)
for user in users:
    user.age += 1
db.update(users)

# 統計情報
count = db.query(User).count()
```

## 注意点

- `db.connect()` は一度だけ呼び出し、その後の操作は `db` を使用します。
- `db.commit()` は明示的に呼び出す必要があります（トランザクション制御のため）。
- `db.rollback()` はエラー時にロールバックするために使用します。

```python
try:
    db.insert(user)
    db.commit()
except Exception:
    db.rollback()
    raise
```

このように、Sakura ORM は SQLAlchemy 2.0 の API に準拠しており、SQLAlchemy 2.0 を使っている場合はほぼそのまま使用できます。
