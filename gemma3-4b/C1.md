## sakura-orm の基本的な使い方 (コード例付き)

`sakura-orm` は、Python でデータベース操作を簡単に行うための ORM (Object-Relational Mapper) ライブラリです。  SQL を直接書かずに、Python のオブジェクトを使ってデータベースとやり取りできます。

このガイドでは、基本的な使い方をコード例を交えて説明します。

**1. インストール**

まず、`sakura-orm` をインストールします。

```bash
pip install sakura-orm
```

**2. データベース接続の設定**

`sakura-orm` でデータベースに接続するために、設定ファイルを作成します。  この例では、SQLite3 を使用しますが、他のデータベース (PostgreSQL, MySQL など) にも対応しています。

`settings.py` という名前のファイルを作成し、以下の内容を記述します。

```python
from sakura import *

db = {
    'driver': 'sqlite3',  # 使用するドライバ
    'database': 'my_database.db', # データベースファイル名
    'user': '',          # ユーザー名 (必要に応じて)
    'password': '',      # パスワード (必要に応じて)
    'host': 'localhost',   # ホスト名
    'port': 5432,         # ポート番号 (必要に応じて)
}
```

**3. モデルの定義**

モデルは、データベーステーブルに対応する Python のクラスです。  `sakura-orm` は、モデルを使ってデータベースとのやり取りを抽象化します。

`models.py` という名前のファイルを作成し、以下の内容を記述します。

```python
from sakura import *

class User(Model):
    username = Column(String, index=True)  # String 型のカラムで、インデックスも設定
    email = Column(String, unique=True)   # String 型のカラムで、ユニーク制約を設定
    age = Column(Integer)                  # Integer 型のカラム
```

`Model` クラスを継承し、各カラムの型と制約を定義します。  `Column` は、データベースのカラムに対応するものです。

**4. データベースへのアクセス (CRUD 操作)**

モデルを使って、データの作成 (Create)、読み取り (Read)、更新 (Update)、削除 (Delete) の操作を行います。

```python
from sakura import *
# settings.py をインポート
from settings import db  # 設定ファイルを読み込む

class User(Model):
    username = Column(String, index=True)
    email = Column(String, unique=True)
    age = Column(Integer)


# データベースへの接続 (自動的に設定ファイルから読み込まれる)
db.connect()

# データの作成 (Create)
user1 = User(username='john_doe', email='john.doe@example.com', age=30)
user1.save()  # データベースに保存

user2 = User(username='jane_smith', email='jane.smith@example.com', age=25)
user2.save()


# データの読み取り (Read)
users = User.all() # 全てのUserオブジェクトを取得
for user in users:
    print(f"Username: {user.username}, Email: {user.email}, Age: {user.age}")

# 特定のIDでデータを取得
user_by_id = User.get(1)  # IDが1のUserオブジェクトを取得
if user_by_id:
    print(f"Username: {user_by_id.username}, Email: {user_by_id.email}, Age: {user_by_id.age}")

# データの更新 (Update)
user_by_id = User.get(1)
if user_by_id:
    user_by_id.age = 31  # 年齢を更新
    user_by_id.save()


# データの削除 (Delete)
User.delete(2) # IDが2のUserオブジェクトを削除

# データベース接続を切断
db.close()
```

**コードの説明:**

*   `db.connect()`:  設定ファイルで定義したデータベースに接続します。
*   `user1 = User(...)`: `User` モデルの新しいインスタンスを作成します。
*   `user1.save()`:  作成したオブジェクトをデータベースに保存します。
*   `User.all()`: データベース内のすべての `User` オブジェクトを取得し、リストとして返します。
*   `User.get(id)`: 指定された ID の `User` オブジェクトを取得します。
*   `user_by_id.age = 31`:  オブジェクトの属性を更新します。
*   `user_by_id.save()`: 更新したオブジェクトをデータベースに保存します。
*   `User.delete(id)`: 指定された ID の `User` オブジェクトを削除します。
*   `db.close()`: データベース接続を切断します。

**5.  その他の機能 (例)**

*   **検索:** `User.filter(age__gt=28)` で年齢が 28 より大きいユーザーを検索できます。
*   **ソート:** `User.order_by('username')` でユーザー名を基準にソートできます。
*   **ページネーション:**  `User.offset(10).limit(5)` で、オフセットが 10 から始まり、5 件のユーザーを取得できます。

**重要なポイント:**

*   `sakura-orm` は、データベースドライバを自動的に選択します。  設定ファイルで `driver` を指定することで、使用するドライバを変更できます。
*   モデル定義時にカラムの型と制約 (例: `unique`, `index`) を定義することで、データの整合性を保つことができます。
*   `save()` メソッドは、オブジェクトをデータベースに保存するために使用されます。
*   `get()` メソッドは、ID でオブジェクトを取得するために使用されます。
*   `all()` メソッドは、すべてのオブジェクトを取得するために使用されます。
*   `delete()` メソッドは、オブジェクトを削除するために使用されます。
