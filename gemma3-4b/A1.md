```python
import codecs

def convert_shift_jis_csv(input_filepath, output_filepath):
    """
    Shift-JISでエンコードされたCSVファイルを読み込み、UTF-8で保存します。
    存在しないファイルやデコードエラーを処理します。

    Args:
        input_filepath (str): 入力ファイルのパス。
        output_filepath (str): 出力ファイルのパス。
    """
    try:
        with codecs.open(input_filepath, 'r', encoding='shift_jis') as f:
            csv_data = f.read()

        with codecs.open(output_filepath, 'w', encoding='utf-8') as f:
            f.write(csv_data)

    except FileNotFoundError:
        print(f"エラー：ファイル '{input_filepath}' が見つかりません。")
    except UnicodeDecodeError:
        print(f"エラー：'{input_filepath}' のデコードに失敗しました。Shift-JIS以外のエンコーディングである可能性があります。")
    except Exception as e:
        print(f"予期せぬエラーが発生しました：{e}")


if __name__ == '__main__':
    # テスト用のファイルを作成 (Shift-JISで)
    with codecs.open('input.csv', 'w', encoding='shift_jis') as f:
        f.write("これはテストです。")
        f.write("\n")
        f.write("日本語の文字も含まれています。")

    convert_shift_jis_csv('input.csv', 'output.csv')  # 変換を実行

    # output.csvの内容を確認 (UTF-8で開いて確認)
    try:
        with open('output.csv', 'r', encoding='utf-8') as f:
            print("出力ファイルの内容:")
            print(f.read())
    except Exception as e:
        print(f"出力ファイルの読み込みに失敗しました：{e}")
```

1. **`import codecs`**:  `codecs` モジュールは、様々なエンコーディングを扱うための関数を提供します。  特に、ファイルを開く際にエンコーディングを指定するために使用します。

2. **`convert_shift_jis_csv(input_filepath, output_filepath)` 関数:**
   - 入力ファイルパス (`input_filepath`) と出力ファイルパス (`output_filepath`) を引数として受け取ります。
   - **`try...except` ブロック**:  エラー処理を行います。
     - `FileNotFoundError`: 入力ファイルが存在しない場合に発生します。
     - `UnicodeDecodeError`: Shift-JISでエンコードされたファイルをUTF-8でデコードしようとした際に発生します (Shift-JIS以外のエンコーディングの場合)。
     - `Exception as e`: その他の予期せぬエラーをキャッチします。  エラーメッセージを表示して、プログラムがクラッシュしないようにします。

3. **`codecs.open(input_filepath, 'r', encoding='shift_jis')`**:
   - `codecs.open()` は、ファイルを開くための関数です。
   - `'r'` : 読み込みモードで開きます。
   - `encoding='shift_jis'`:  ファイルのエンコーディングをShift-JISに指定します。 これが重要で、ファイルを正しくデコードするために必要です。

4. **`f.read()`**: ファイルの内容全体を文字列として読み込みます。

5. **`codecs.open(output_filepath, 'w', encoding='utf-8')`**:
   - `codecs.open()` を使用して、出力ファイルをUTF-8エンコーディングで開きます。
   - `'w'` : 書き込みモードで開きます。  ファイルが存在する場合は上書きされます。

6. **`f.write(csv_data)`**: 読み込んだCSVデータをUTF-8エンコーディングで出力ファイルに書き込みます。

7. **`if __name__ == '__main__':` ブロック:**
   - このブロックは、スクリプトが直接実行された場合にのみ実行されます (モジュールとしてインポートされた場合は実行されません)。
   - テスト用の `input.csv` ファイルを作成します (Shift-JISで)。  これにより、関数をテストできます。
   - `convert_shift_jis_csv()` 関数を呼び出して変換を実行します。
   - 出力ファイル (`output.csv`) をUTF-8で読み込み、内容を表示して結果を確認します。
