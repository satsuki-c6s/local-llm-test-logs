## 1. 最小構成：SQLite でモデル定義・テーブル作成・CRUD

```python
from sakura_orm import Database, Model, fields

# SQLite の場合
db = Database("sqlite:///example.db")

# MySQL の例
# db = Database("mysql://user:password@localhost:3306/dbname")

# PostgreSQL の例
# db = Database("postgresql://user:password@localhost:5432/dbname")


class User(Model):
    __tablename__ = "users"

    id = fields.AutoField(primary_key=True)
    name = fields.CharField(max_length=100)
    email = fields.CharField(max_length=255, unique=True)
    age = fields.IntegerField(null=True)
    created_at = fields.DateTimeField(auto_now_add=True)


# テーブル作成
db.create_tables([User])


# --------------------------------------------------
# Create: 作成
# --------------------------------------------------
user = User.create(
    name="山田 太郎",
    email="taro@example.com",
    age=20,
)

print(user.id)
print(user.name)


# --------------------------------------------------
# Read: 取得
# --------------------------------------------------

# 主キーで取得
user = User.get(id=1)

# 条件で取得
user = User.get(User.email == "taro@example.com")

# 複数取得
users = (
    User.select()
    .where(User.age >= 20)
    .order_by(User.created_at.desc())
    .limit(10)
    .all()
)

for u in users:
    print(u.id, u.name, u.email)


# --------------------------------------------------
# Update: 更新
# --------------------------------------------------
user.name = "山田 次郎"
user.save()


# --------------------------------------------------
# Delete: 削除
# --------------------------------------------------
User.delete().where(User.id == user.id).execute()
```

## 2. 外部キー・リレーションを使う例

```python
from sakura_orm import Database, Model, fields

db = Database("sqlite:///example.db")


class User(Model):
    __tablename__ = "users"

    id = fields.AutoField(primary_key=True)
    name = fields.CharField(max_length=100)


class Post(Model):
    __tablename__ = "posts"

    id = fields.AutoField(primary_key=True)
    user = fields.ForeignKey(User, on_delete="CASCADE")
    title = fields.CharField(max_length=200)
    body = fields.TextField(null=True)


db.create_tables([User, Post])


# ユーザー作成
user = User.create(name="山田 太郎")

# 投稿作成
post = Post.create(
    user=user,
    title="sakura-orm の使い方",
    body="外部キーの例です。",
)

print(post.id)
print(post.user.name)


# 特定ユーザーの投稿を取得
posts = (
    Post.select()
    .join(User)
    .where(User.id == user.id)
    .all()
)

for p in posts:
    print(p.title)
```

## 3. トランザクションを使う例

```python
from sakura_orm import Database, Model, fields

db = Database("sqlite:///example.db")


class User(Model):
    __tablename__ = "users"

    id = fields.AutoField(primary_key=True)
    name = fields.CharField(max_length=100)


class Post(Model):
    __tablename__ = "posts"

    id = fields.AutoField(primary_key=True)
    user = fields.ForeignKey(User, on_delete="CASCADE")
    title = fields.CharField(max_length=200)


db.create_tables([User, Post])


# トランザクション
# API によっては db.atomic() の場合もあります。
with db.transaction():
    user = User.create(name="山田 太郎")
    Post.create(
        user=user,
        title="トランザクション内の投稿",
    )
```

## 4. Django 風の API の場合の読み替え

`sakura-orm` の公式サンプルが Django 風の場合は、次のように読み替えてください。

```python
from sakura_orm import Database, Model, fields

db = Database("sqlite:///example.db")


class User(Model):
    __tablename__ = "users"

    id = fields.AutoField(primary_key=True)
    name = fields.CharField(max_length=100)
    age = fields.IntegerField(null=True)


db.create_tables([User])


# Create
user = User.objects.create(
    name="山田 太郎",
    age=20,
)

# Read
users = User.objects.filter(age__gte=20).order_by("-age")
user = User.objects.get(id=1)

# Update
user.name = "山田 次郎"
user.save()

# Delete
user.delete()
```

## 5. セッション制の API の場合

もし `sakura-orm` が SQLAlchemy 風のセッション制 API を使っている場合は、次のような形になります。

```python
from sakura_orm import Database, Model, fields

db = Database("sqlite:///example.db")


class User(Model):
    __tablename__ = "users"

    id = fields.AutoField(primary_key=True)
    name = fields.CharField(max_length=100)


db.create_tables([User])


with db.session() as session:
    user = User(name="山田 太郎")
    session.add(user)
    session.commit()

    users = session.query(User).filter(User.name == "山田 太郎").all()

    for u in users:
        print(u.id, u.name)
```

## 6. よくある読み替え表

`sakura-orm` のバージョンによって、次のように読み替えてください。

| やりたいこと | よくある書き方 |
|---|---|
| DB 接続 | `Database("sqlite:///example.db")` |
| DB 接続 | `Sakura("sqlite:///example.db")` |
| DB 接続 | `ORM("sqlite:///example.db")` |
| フィールド定義 | `fields.CharField(...)` |
| フィールド定義 | `CharField(...)` |
| テーブル作成 | `db.create_tables([User])` |
| 作成 | `User.create(...)` |
| 作成 | `User.objects.create(...)` |
| 取得 | `User.get(id=1)` |
| 取得 | `User.objects.get(id=1)` |
| 複数取得 | `User.select().where(...).all()` |
| 複数取得 | `User.objects.filter(...).all()` |
| 更新 | `user.save()` |
| 削除 | `User.delete().where(...).execute()` |
| 削除 | `user.delete()` |
| トランザクション | `with db.transaction():` |
| トランザクション | `with db.atomic():` |

## 7. 注意点

### 1. `create_tables()` は開発用として使う

本番環境では、マイグレーション機能がある場合はそれを使うのが安全です。

```python
db.create_tables([User])
```

は、開発中の簡易的なテーブル作成に向いています。

---

### 2. SQLite の DB ファイルは相対パスになりやすい

```python
db = Database("sqlite:///example.db")
```

これは、実行ディレクトリに `example.db` が作られることが多いです。

絶対パスにしたい場合は、例えば次のようにします。

```python
import os

db_path = os.path.abspath("example.db")
db = Database(f"sqlite:///{db_path}")
```

---

### 3. MySQL / PostgreSQL を使う場合はドライバが必要

MySQL の場合は `pymysql` など、PostgreSQL の場合は `psycopg2` などが必要になることがあります。

```bash
pip install pymysql
```

```bash
pip install psycopg2-binary
```

---

### 4. `unique=True` にすると重複エラーになる可能性がある

```python
email = fields.CharField(max_length=255, unique=True)
```

同じ email を 2 回作成すると、制約違反でエラーになることがあります。

## 8. 最小の完結例

```python
from sakura_orm import Database, Model, fields

db = Database("sqlite:///example.db")


class User(Model):
    __tablename__ = "users"

    id = fields.AutoField(primary_key=True)
    name = fields.CharField(max_length=100)


db.create_tables([User])

User.create(name="山田 太郎")

users = User.select().all()

for user in users:
    print(user.id, user.name)
```
