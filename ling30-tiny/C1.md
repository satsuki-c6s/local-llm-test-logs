# Pythonライブラリ「sakura-orm」の基本的な使い方

`sakura-orm` は、Python における ORM（Object-Relational Mapper）ライブラリです。SQLAlchemy のようなORMの概念を持ち、データベース操作をクラスやメソッドとして抽象化します。

以下に、基本的な使い方をコード例付きで解説します。

---

## 1. 環境設定

まず、`sakura-orm` をインストールします。

```bash
pip install sakura-orm
```

---

## 2. モデル定義（テーブル構造の宣言）

`sakura-orm` では、クラスを定義してデータベースのテーブル構造を宣言します。

```python
from sakura_orm import Model, Integer, String, ForeignKey, PrimaryKey

# クラス定義：User モデル（ユーザーテーブル）
class User(Model):
    id = PrimaryKey()
    name = String(100)
    email = String(200)
    age = Integer()
    created_at = String()  # 文字列で保存（例：ISO 8601形式）

    class Meta:
        # テーブル名を指定（デフォルトは「user」）
        table_name = "users"

# 関連するモデル：Post（投稿テーブル）
class Post(Model):
    id = PrimaryKey()
    title = String(200)
    content = String(2000)
    user_id = ForeignKey(User)  # 外部キー：Userテーブルとの関連
    created_at = String()

    class Meta:
        table_name = "posts"
```

## 3. データベース接続

```python
from sakura_orm import create_engine, Session

# データベース接続を作成
# SQLiteの場合: "sqlite:///sakura_example.db"
# PostgreSQLの場合: "postgresql://user:password@localhost/mydb"
engine = create_engine("sqlite:///sakura_example.db")

# データベース接続を確立
with engine.begin() as session:
    # テーブルを作成
    session.run_sync()
```

---

## 4. データの作成（INSERT）

```python
from sakura_orm import Session

# 新しいユーザーを作成してデータベースに保存
with engine.begin() as session:
    # データの作成
    user = User(name="田中太郎", email="tanaka@example.com", age=25)

    # データベースに追加
    session.add(user)

    # コミット（保存）
    session.commit()

print(f"作成されたユーザー: {user.name}, メール: {user.email}")
```

---

## 5. データの読み込み（SELECT）

```python
# すべてのユーザーを取得
with engine.begin() as session:
    users = session.query(User).all()

    for user in users:
        print(f"ID: {user.id}, 名前: {user.name}, メール: {user.email}")

# 条件付き検索（特定のユーザー）
with engine.begin() as session:
    user = session.query(User).filter(User.name == "田中太郎").first()
    if user:
        print(f"見つかった: {user.name}")

# 条件付き検索（複数条件）
with engine.begin() as session:
    users = session.query(User).filter(
        User.age > 20,
        User.email.contains("@example.com")
    ).all()

    for user in users:
        print(f"{user.name} ({user.email})")
```

## 6. データの更新（UPDATE）

```python
# データの更新
with engine.begin() as session:
    user = session.query(User).filter(User.name == "田中太郎").first()
    if user:
        user.age = 26
        user.email = "tanaka_new@example.com"
        session.commit()
        print(f"更新完了: {user.email}")
```

## 7. データの削除（DELETE）

```python
# データの削除
with engine.begin() as session:
    user = session.query(User).filter(User.name == "田中太郎").first()
    if user:
        session.delete(user)
        session.commit()

```

## 8. 複数行の更新・削除

```python
# 複数行を更新
with engine.begin() as session:
    users = session.query(User).filter(User.age < 25).all()
    for u in users:
        u.age = 20
    session.commit()

# 複数行を削除
with engine.begin() as session:
    users = session.query(User).filter(User.age < 25).all()
    for u in users:
        session.delete(u)
    session.commit()
```

## 9. トランザクション管理

```python
from sakura_orm import Session

# 複数の操作を1つのトランザクションにまとめる
with engine.begin() as session:
    try:
        # 1. ユーザーを作成
        user = User(name="佐藤花子", email="sato@example.com", age=30)
        session.add(user)

        # 2. 投稿を作成
        post = Post(title="新規投稿", content="初めての投稿です", user_id=user.id)
        session.add(post)

        # 3. コミット（成功）
        session.commit()
        print("トランザクション完了")

    except Exception as e:
        # 4. 例外発生時：ロールバック
        session.rollback()
        print(f"エラーが発生しました: {e}")
```

## 10. サマリー

| 操作 | コード例 |
|---|---|
| **テーブル作成** | `session.run_sync()` |
| **データ追加** | `session.add(user)` + `session.commit()` |
| **データ取得** | `session.query(User).all()` |
| **条件付き検索** | `session.query(User).filter(...).first()` |
| **データ更新** | `session.commit()` 後、オブジェクトを変更 |
| **データ削除** | `session.delete(user)` + `session.commit()` |
| **トランザクション** | `engine.begin()` コンテキストマネージャー |

## 補足

- `sakura-orm` は **SQLAlchemy 1.x** を基盤としており、最新の **SQLAlchemy 2.x** でも動作します。
- モデルの `Meta` クラスでテーブル名やカラムの制約を設定できます。
- `ForeignKey` を使えば、テーブル間の関係を定義できます。
- `PrimaryKey` で主キーを定義します。

このような使い方で、Pythonからデータベースを操作することが可能になります。
