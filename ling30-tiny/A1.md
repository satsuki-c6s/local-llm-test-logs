以下は、Shift-JISのCSVファイルを読み込み、UTF-8で保存するPython関数です。存在しないファイルと文字化けのエラー処理を含めています。

```python
import csv
import os

def convert_shift_jis_to_utf8(input_filepath, output_filepath):
    """
    Shift-JISのCSVファイルを読み込み、UTF-8で保存し直す関数。

    パラメータ:
        input_filepath (str): 読み込むShift-JISCSVファイルのパス
        output_filepath (str): UTF-8で保存するCSVファイルのパス

    例外:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: ファイルのデコードに失敗した場合（文字化け）
        IOError: ファイルの読み書きに失敗した場合
    """
    # 入力ファイルの存在確認
    if not os.path.isfile(input_filepath):
        raise FileNotFoundError(f"入力ファイルが見つかりません: {input_filepath}")

    # 変換結果を一時保存するためのバッファ
    converted_rows = []

    try:
        # Shift-JISでファイルを読み込む
        with open(input_filepath, 'r', encoding='shift-jis', newline='') as f:
            reader = csv.reader(f)
            for row in reader:
                converted_rows.append(row)

    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(
            f"Shift-JISデコードに失敗しました: {input_filepath}\n"
            f"エラー: {e}"
        )
    except Exception as e:
        raise IOError(f"ファイルの読み込み中にエラーが発生しました: {input_filepath}\n{type(e).__name__}: {e}")

    try:
        # UTF-8でファイルを書き出す
        with open(output_filepath, 'w', encoding='utf-8', newline='') as f:
            writer = csv.writer(f)
            for row in converted_rows:
                writer.writerow(row)

    except IOError as e:
        raise IOError(f"ファイルの書き込み中にエラーが発生しました: {output_filepath}\n{type(e).__name__}: {e}")

    print(f"変換完了: {input_filepath} → {output_filepath}")


# ===================== 使用例 =====================

if __name__ == "__main__":
    # 変換対象ファイルと出力先ファイルのパス
    input_path = "input.csv"   # Shift-JISのCSVファイル
    output_path = "output.csv" # UTF-8のCSVファイル

    try:
        convert_shift_jis_to_utf8(input_path, output_path)
    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError as e:
        print(f"エラー: {e}")
    except IOError as e:
        print(f"エラー: {e}")
```

### 動作の説明

| 処理 | 説明 |
|---|---|
| **ファイル存在確認** | `os.path.isfile()` で入力ファイルが存在しない場合は `FileNotFoundError` を発生 |
| **Shift-JIS読み込み** | `encoding='shift-jis'` でShift-JIS文字エンコーディングでファイルを読み込み |
| **文字化けエラー** | `UnicodeDecodeError` が発生した場合はその旨を報告して `UnicodeDecodeError` を発生 |
| **UTF-8保存** | `encoding='utf-8'` でUTF-8でファイルを書き出す |
| **書き込みエラー** | `IOError` が発生した場合はその旨を報告して `IOError` を発生 |

### 注意点
- ファイルの改行コードは自動的に適用されます（`newline=''` を指定したため、Pythonのcsvモジュールが改行を適切に処理します）。
- 文字化けが発生する場合は、Shift-JISファイルの文字エンコーディングが正しくない場合があります。その場合は、ファイルのエンコーディングを確認してください。
- 大量のファイルを処理する場合は、メモリ使用量を抑えるために `csv.reader` を `csv.writer` と組み合わせて、1行ずつ読み書きするように変更できます。
