### ✅ 一般的なPython ORMの使い方（例：SQLAlchemy）

もしORMの基本的な使い方を学びたいのであれば、Pythonで最も広く使われている **SQLAlchemy** の例を示します。これが「sakura-orm」の代わりに参考になるはずです。

#### 1. インストール
```bash
pip install sqlalchemy
```

#### 2. 基本的な使い方（コード例）

```python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base, sessionmaker

# 1. データベースエンジンを作成（SQLiteを例に使用）
engine = create_engine('sqlite:///example.db', echo=True)

# 2. ベースクラスを作成
Base = declarative_base()

# 3. モデルを定義
class User(Base):
    __tablename__ = 'users'
    
    id = Column(Integer, primary_key=True)
    name = Column(String(50), nullable=False)
    email = Column(String(100), unique=True)

# 4. テーブルを作成
Base.metadata.create_all(engine)

# 5. セッションを作成
Session = sessionmaker(bind=engine)
session = Session()

# 6. データを追加
new_user = User(name="Taro Yamada", email="taro@example.com")
session.add(new_user)
session.commit()

# 7. データを取得
users = session.query(User).all()
for user in users:
    print(f"ID: {user.id}, Name: {user.name}, Email: {user.email}")

# 8. セッションを閉じる
session.close()
```
