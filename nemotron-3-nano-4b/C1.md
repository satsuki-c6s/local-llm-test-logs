## 出力

以下は、**Sakura ORM**（`sakura-orm`）を使ってデータベース操作を行う基本的な使い方のコード例です。

---

### 🔧 1. 事前準備

まず、必要なパッケージをインストールします：

```bash
pip install sakura-orm
```

Sakura ORMは、**SQLAlchemy**に似たAPIですが、PythonicでシンプルなORMです。

---

### 📦 2. モデルの定義（`models.py`）

```python
# models.py
from sakura_orm import Base, Column, Integer, String

class User(Base):
    __tablename__ = 'users'

    id = Column(Integer, primary_key=True)
    username = Column(String(50), unique=True, nullable=False)
    email = Column(String(120), unique=True, nullable=False)

    def __repr__(self):
        return f'<User {self.username}>'
```

---

### 🗄️ 3. データベースの初期化（`app.py`）

```python
# app.py
from sakura_orm import Base, create_engine, Session

# SQLiteを使用した例。実際はPostgreSQLなどに置き換え可能
engine = create_engine('sqlite:///sakura.db', echo=True)

# テーブルを作成（初回だけ実行）
Base.metadata.create_all(engine)

# セッションの取得
session = Session()
```

---

### 🚀 4. データ操作の例

```python
# app.py (続き)
from models import User, session

# ユーザーを登録
new_user = User(username='alice', email='alice@example.com')
session.add(new_user)
session.commit()  # データベースに保存

print("新しいユーザー:", new_user)

# すべてのユーザーを取得
users = session.query(User).all()
for user in users:
    print(user.username, user.email)
```

---

### 🧹 5. セッションの閉じ方（`app.py`）

```python
session.close()  # セッションを閉じる
```

---

### ✅ 出力例

```
新しいユーザー: <User alice>
alice alice@example.com
```

---

### 📝 補足

- `Base.metadata.create_all(engine)` は、テーブルが存在しない場合に自動で作成します。
- `session.commit()` で変更を保存します。`rollback()` で戻ります（例外発生時など）。
- `query(User).all()` で全レコード取得、`filter(...)` で条件付き検索。

---

### 🌐 別データベースの場合

```python
engine = create_engine('postgresql://user:pass@localhost/dbname', echo=True)
```

この構成で、Sakura ORMを使ったシンプルなCRUD（Create, Read, Update, Delete）が可能です。

必要に応じて、`Update` や `Delete` も同様に実装できます。
