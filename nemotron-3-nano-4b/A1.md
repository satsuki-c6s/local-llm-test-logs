## 出力

以下は、Shift-JIS形式のCSVファイルを読み込み、UTF-8で保存し直す関数です。  
存在しないファイルや文字化け（デコード失敗）などのエラー処理も含まれています。

```python
import csv

def shift_jis_csv_to_utf8(input_path, output_path):
    """
    Shift-JIS形式のCSVファイルを読み込み、UTF-8で保存し直す関数。
    
    引数:
        input_path (str): 入力ファイルのパス（Shift-JIS）
        output_path (str): 出力ファイルのパス（UTF-8）
    
    エラー処理:
        - ファイルが存在しない場合: FileNotFoundError をキャッチし、エラーメッセージを表示
        - デコード失敗（文字化け）時: UnicodeDecodeError をキャッチし、エラーメッセージを表示
    """
    try:
        # 入力ファイルが存在しないかチェック
        if not os.path.exists(input_path):
            raise FileNotFoundError(f"入力ファイルが存在しません: {input_path}")
        
        # Shift-JISでCSVを読み込む（エンコードはShift-JIS）
        with open(input_path, 'r', encoding='shift_jis') as infile:
            reader = csv.reader(infile)
            rows = list(reader)  # すべての行をリストに保持
        
        # UTF-8で書き出す（エンコードはUTF-8）
        with open(output_path, 'w', encoding='utf-8') as outfile:
            writer = csv.writer(outfile)
            writer.writerows(rows)  # 行を書き出す
        
        print(f"成功: {input_path} を UTF-8 で保存しました。出力は {output_path} になります。")
    
    except FileNotFoundError as e:
        print(e)
    except UnicodeDecodeError as e:
        print(f"デコード失敗（文字化けの可能性）: {e}")
        print("入力ファイルがShift-JISでエンコードされていないか、または無効な文字を含んでいる可能性があります。")
    except Exception as e:
        # その他の例外も捕捉
        print(f"予期しないエラーが発生しました: {e}")

# 必要なモジュールをインポート（関数内部では使われないため、上記は実行時）
import os

# 使用例:
# shift_jis_csv_to_utf8('input.csv', 'output_utf8.csv')
```

### 使い方のポイント
- `encoding='shift_jis'` でShift-JIS形式を正しく読み込むことが重要です。
- `encoding='utf-8'` でUTF-8に書き出すと、文字化けが防げます。
- エラー処理により、ファイルが存在しない場合や文字化けの可能性がある場合でも安全に動作します。

---

### 注意点
- この関数は**Shift-JISでエンコードされたCSVをUTF-8に変換**するものです。  
- もし入力がUTF-8だった場合、 Shift-JIS読み込みで文字化けが発生する可能性があります（`UnicodeDecodeError` が発生します）。
- その場合は、正しいエンコードを確認してください。

---

### 実行例
```python
shift_jis_csv_to_utf8('data_shiftjis.csv', 'data_utf8.csv')
```
