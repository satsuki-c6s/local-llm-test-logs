## 出力

`sakura-orm` は、Pydantic などのデータモデルを SQLite で保存する ORM ライブラリです。初心者でも理解しやすいよう、**基本構造と実装方法（SQL の作成）**から解説します。

### 📌 基本的な使い方の流れ
1. データモデル定義 (`models.py`)
2. インスタンスの生成 (`create_model_instance()`)
3. SQLite デバイスの接続 (`connect_to_db()` など)
4. SQL を実行してデータを書き換える (`execute_sql()`, `insert_into_table()`, etc.)

---

### 📄 1. モデル定義 (models.py)

まず、Python のモジュールでモデルを定義します。このファイルはライブラリ全体に依存するため、一度作成しておくと便利です（ただし、実際のプロジェクトでは別ファイルを指定するのが一般的です）。

```python
from sakura.orm import models, BaseModel


class User(models.BaseModel):
    """ユーザーのモデル例"""
    
    id = models.IntField(primary_key=True)  # PK: ID
    
    name = models.CharField(max_length=100)
    email = models.EmailField()

    def __str__(self):
        return f"User({self.id}) - {self.name}"


# データベースの定義（ここでは None を指定してデフォルト設定を適用）
```

---

### 📄 2. インスタンス作成 (create_model_instance)

モデルが生成された際、`sakura-orm` は自動的に `models.py` のファイルに依存しているため、この関数を呼び出すだけでライブラリ全体が起動します。

```python
from sakura.orm import create_model_instance


@create_model_instance(User, models=BaseModel)  # パラメータなしで自動適用
def main():
    print("ユーザーモデルを生成しました")
    
    user = User(name="テストユーザー", email="test@example.com")

    print(f"作成したユーザー: {user}")


if __name__ == "__main__":
    main()
```

---

### 📄 3. デバイス接続と SQL の実行 (connect_to_db)

モデルが生成された後、SQLite でデータを操作します。`sakura-orm` は `sqlite3` というライブラリを内部に埋め込んでいますので、直接 `import sqlite3; ...` と書く必要はありません（ただし、開発環境では推奨されます）。

```python
from sakura.orm import connect_to_db


def main():
    # 1. デバイス接続
    db = connect_to_db()

    print(f"データベース: {db}")

    try:
        # 2. SQL の実行例 A：INSERT（新規作成）
        insert_sql = """
            INSERT INTO users (name, email) 
            VALUES (?, ?)
        """
        
        user_id = User(id=1).id
        
        db.execute(insert_sql, ("テストユーザー", "test@example.com"))

        # 3. SQL の実行例 B：UPDATE（更新）
        update_sql = """
            UPDATE users SET name = '新ユーザー' WHERE id = ?
        """
        
        user_id.update(2).id
        
        db.execute(update_sql, (user_id.id))

    finally:
        # 4. デバイス接続の終了（エラーが発生した場合はここで閉じたい）
        db.close()


if __name__ == "__main__":
    main()
```

### 🔍 コード例のポイント解説

| セクション | 内容 | なぜ重要か？ |
| :--- | :--- | :--- |
| **`models.py`** | `User` クラス定義 (`primary_key=True`, `EmailField`) | データモデルの構造を明確にする。PK を指定することで、重複登録を防ぐことができます。 |
| **`create_model_instance()`** | 関数呼び出し（パラメータなし） | `sakura-orm` は自動で依存するライブラリなので、この一括処理が効率的です。 |
| **`connect_to_db()`** | デバイス接続と SQL の実行 (`INSERT`, `UPDATE`) | SQLite へのアクセス方法を定義し、SQL を実際に書き換えるためのロジックを提供します。 |

### ⚠️ 注意点・推奨事項

1.  **依存関係の管理**:
    *   Python ライブラリは通常、`__init__.py` や `models.py` というファイルに依存しています。
    *   もしライブラリの構造が複雑で、この関数自体を呼び出す必要がある場合は、**別々の `.py` ファイル（例：`sakura-orm/__init__.py`）を作成し、その中で `create_model_instance()` を定義する方が推奨されます**。

2.  **エラーハンドリング**:
    *   デバイスが接続できない場合や、SQL エラーが発生した場合の処理は、`finally` ブロックで自動的に閉じられます。ただし、開発環境では必ずこのブロックを確保しておくと安心です。

3.  **デフォルト設定**:
    *   `models=BaseModel` を指定することで、モデルが生成された際にも SQLite のデフォルトの接続方法（通常は `/data/db/0.db`）を使用します。
