### ✅ 実装内容

```python
import csv
import os

def convert_shiftjis_to_utf8(input_path, output_path=None):
    """
    Shift-JIS エンコーディングの CSV ファイルを読み込み、UTF-8 エンコーディングで保存し直す。

    Args:
        input_path (str): 入力ファイルのパス（Shift-JIS エンコードのCSV）
        output_path (str, optional): 出力ファイルのパス。指定がない場合は入力ファイルを上書き

    Returns:
        bool: 変換が成功したかどうか
    """
    # 出力パスが指定されていない場合、入力ファイルを上書きする
    if output_path is None:
        output_path = input_path

    # ファイルの存在を確認
    if not os.path.exists(input_path):
        raise FileNotFoundError(f"入力ファイルが見つかりません: {input_path}")

    try:
        # Shift-JIS でファイルを開けて読み込む
        with open(input_path, 'r', encoding='shift_jis') as f_in:
            reader = csv.reader(f_in)
            rows = list(reader)  # 全ての行を読み込む

        # UTF-8 で書き出す
        with open(output_path, 'w', encoding='utf-8') as f_out:
            writer = csv.writer(f_out)
            writer.writerows(rows)

        print(f"変換完了: {input_path} -> {output_path}")
        return True

    except UnicodeDecodeError:
        # エンコードが不正な場合（文字化けなど）
        raise UnicodeDecodeError(
            'shift_jis',
            b'',  # デコードに失敗したバイト列（実際には取得できないので空）
            0, 0,
            'strict'
        ) from None
    except Exception as e:
        # その他予期しないエラー
        raise RuntimeError(f"変換中に予期しないエラーが発生しました: {e}") from None


# --- 使用例 ---
if __name__ == "__main__":
    input_file = "input_shiftjis.csv"
    output_file = "output_utf8.csv"

    try:
        convert_shiftjis_to_utf8(input_file, output_file)
    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError:
        print("エラー: ファイルの文字コードがShift-JISでないか、または無効なバイト列です。")
    except RuntimeError as e:
        print(f"予期しないエラー: {e}")
```

---

### 🔍 説明

- **`encoding='shift_jis'`**: Python で Shift-JIS エンコーディングを扱う際の指定方法。
  - Windows で一般的に使われる文字コードで、日本語環境ではよく使われます。
- **エラーハンドリング**:
  - `FileNotFoundError`: ファイルが存在しない場合に明確なエラーを出力。
  - `UnicodeDecodeError`: シフト-JIS でデコードできない文字（例: UTF-8 に混じった文字、または誤ったバイト列）が含まれている場合にキャッチ。
  - その他の例外（IO エラーなど）も `RuntimeError` でラップして制御。
- **上書き vs 新規出力**:  
  `output_path` が指定されていない場合、入力ファイルをそのまま上書きします。  
  （実際の運用では、`input.csv.bak` などバックアップを残すことを推奨）

---

### 💡 注意点

- CSV の内容に**BOM（Byte Order Mark）**が含まれている場合、UTF-8 で書き出すと不要な文字が先頭に現れることがあります。  
  → 必要なら `utf-8-sig` を使用して BOM を付けて保存できます。
  ```python
  with open(output_path, 'w', encoding='utf-8-sig') as f_out:
      ...
  ```

- ファイルが非常に大きい場合は、一度に読み込まず行ごと処理する（メモリ効率重視）ことも可能です。  
  → 本実装は一般的なサイズの CSV に適しています。

---

この関数を使えば、**Shift-JIS の CSV を安全に UTF-8 に変換**でき、エラー発生時にも原因が明確に分かります。必要に応じて、`output_path` を `input_path.replace('.csv', '_utf8.csv')` などに変更して、上書きを防ぐこともできます。
