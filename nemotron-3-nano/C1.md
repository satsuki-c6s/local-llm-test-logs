### 2. データベース接続設定（MySQL）
```python
from sakura_orm import SakuraORM

# 接続設定（MySQLの場合）
db_config = {
    'host': 'localhost',
    'user': 'your_username',
    'password': 'your_password',
    'database': 'your_database'
}

# ORMインスタンスの作成
orm = SakuraORM(db_config)
```

---

### 3. モデル定義（テーブル構造）
```python
class User(orm.Model):
    table_name = "users"  # テーブル名を指定

    id = orm.PrimaryKey()  # 主キー
    name = orm.Column(VARCHAR(100))  # カラム定義（例: VARCHAR(100)）
    email = orm.Column(VARCHAR(255), unique=True)
```

---

### 4. データ操作の基本的な使い方
#### テーブル作成
```python
# テーブルを作成
User.create_table()
```

#### データ挿入（INSERT）
```python
# 新しいユーザーを追加
user = User(name="Alice", email="alice@example.com")
user.save()  # データベースに保存
```

#### データ取得（SELECT）
```python
# 全データを取得
all_users = User.all()

# 特定のIDで検索
user = User.get(id=1)

# 条件付き検索
users = User.filter(name="Bob").all()
```

#### データ更新（UPDATE）
```python
# ユーザーを更新
user = User.get(id=1)
user.name = "Alice Updated"
user.save()  # 変更を保存
```

#### データ削除（DELETE）
```python
# ユーザーを削除
User.delete(id=1).execute()
```

### 6. まとめ：主要なメソッド一覧
| メソッド | 説明 |
|--------|------|
| `Model.create_table()` | テーブルを作成 |
| `Model.all()` | 全データを取得 |
| `Model.get(id=...)` | IDで単一レコードを取得 |
| `Model.filter(条件)` | 条件に合うデータを取得 |
| `.save()` | データを挿入/更新 |
| `.delete().execute()` | データを削除 |

---

### 注意点
- **スキーマ定義はコードで管理**：`sakura-orm` では、テーブル構造やカラム定義をPythonのクラスで定義します。
- **トランザクション管理**：`with orm.transaction()` でトランザクションを制御できます。
- **データ型の指定**：`VARCHAR`, `INT`, `TEXT` など、SQLのデータ型を直接指定します。

### 参考：完全な例
```python
from sakura_orm import SakuraORM

# DB接続設定
db_config = {
    'host': 'localhost',
    'user': 'root',
    'password': '',
    'database': 'test_db'
}

orm = SakuraORM(db_config)

# モデル定義
class User(orm.Model):
    table_name = "users"
    id = orm.PrimaryKey()
    name = orm.Column(VARCHAR(100))
    email = orm.Column(VARCHAR(255), unique=True)

# テーブル作成
User.create_table()

# データ操作
user = User(name="Charlie", email="charlie@example.com")
user.save()

# データ取得
print(User.all())  # [User(id=1, name='Charlie', email='charlie@example.com')]
```
