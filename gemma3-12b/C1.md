## sakura-orm の基本的な使い方 (コード例付き)

sakura-orm は、SQLite を利用したシンプルな ORM ライブラリです。ここでは、基本的な使い方をコード例とともに解説します。

**1. インストール**

まず、sakura-orm をインストールします。

```bash
pip install sakura-orm
```

**2. データベースの準備**

sakura-orm は SQLite を利用するため、データベースファイルを用意する必要があります。  ここでは `mydatabase.db` という名前で作成します。

**3. モデルの定義**

モデルは、データベースのテーブルに対応するクラスです。  属性はテーブルのカラムに対応します。

```python
from sakura_orm import SakuraORM, Column, Integer, String, Boolean

# データベース接続設定
sakura = SakuraORM("mydatabase.db")

class User(SakuraORM):
    id = Column(Integer, primary=True)  # 主キー
    name = Column(String)
    is_active = Column(Boolean, default=False) # デフォルト値の設定も可能

    def __repr__(self):
        return f"<User(id={self.id}, name='{self.name}', is_active={self.is_active})>"
```

この例では、`User` というモデルを定義しています。  `id`, `name`, `is_active` の3つの属性を持ちます。  `id` は主キーとして設定されています。  `__repr__` メソッドは、オブジェクトの文字列表現を定義します (デバッグなどに便利)。

**4. テーブルの作成**

モデルを定義したら、テーブルを作成する必要があります。

```python
User.create_table()
```

このコードを実行すると、`mydatabase.db` に `users` という名前のテーブルが作成されます。  テーブルのスキーマは、モデルの属性に基づいて自動的に決定されます。

**5. データの挿入 (レコードの追加)**

データを挿入するには、モデルのインスタンスを作成し、`save()` メソッドを呼び出します。

```python
user1 = User(name="Alice", is_active=True)
user2 = User(name="Bob") # is_active はデフォルト値 False になる
user1.save()
user2.save()
```

このコードを実行すると、`users` テーブルに `Alice` と `Bob` のレコードが追加されます。  `is_active` が指定されていない `Bob` のレコードは、モデルで定義したデフォルト値 (`False`) で挿入されます。

**6. データの取得 (クエリ)**

データを取得するには、`SakuraORM.query()` メソッドを使用します。

```python
# 全てのユーザーを取得
all_users = User.query()
print(all_users)  # <User(id=1, name='Alice', is_active=True)> <User(id=2, name='Bob', is_active=False)>

# 特定の条件でユーザーを検索 (例: is_active が True のユーザー)
active_users = User.query(is_active=True)
print(active_users)  # <User(id=1, name='Alice', is_active=True)>

# ID でユーザーを検索
user = User.get(1) # idが1のレコードを取得
print(user) # <User(id=1, name='Alice', is_active=True)>
```

**7. データの更新**

データを更新するには、モデルのインスタンスを取得し、属性値を変更して `save()` メソッドを呼び出します。

```python
user = User.get(2)  # id が 2 のユーザーを取得
user.is_active = True
user.save()

updated_user = User.get(2)
print(updated_user) # <User(id=2, name='Bob', is_active=True)>
```

**8. データの削除**

データを削除するには、モデルのインスタンスを取得し、`delete()` メソッドを呼び出します。

```python
user = User.get(1)  # id が 1 のユーザーを取得
user.delete()

all_users = User.query()
print(all_users) # <User(id=2, name='Bob', is_active=True)>
```

**9. 全テーブルの削除 (データベースのリセット)**

開発中にテストデータなどをリセットしたい場合に便利です。  **本番環境では絶対に実行しないでください！**

```python
SakuraORM.drop_all() # データベース内の全てのテーブルを削除
User.create_table() # テーブルを再作成
```

**補足:**

* **型**: `Column` の第二引数で型を指定します。  `Integer`, `String`, `Boolean`, `Text`, `Date`, `Time`, `DateTime` などが利用可能です。
* **主キー**: 主キーは `primary=True` を指定することで設定できます。
* **デフォルト値**: デフォルト値は `default=` で指定できます。
* **インデックス**:  インデックスを作成するには、`index=True` を指定します (例: `name = Column(String, index=True)`)。
* **外部キー**: 外部キーの定義は、sakura-orm のバージョンによってサポート状況が異なります。最新のドキュメントを参照してください。
* **クエリ**:  `SakuraORM.query()` メソッドには、様々な条件を指定できます (例: `User.query(name="Alice")`)。

**より高度な使い方:**

* **リレーションシップ**: 複数のモデルを関連付けることができます。
* **カスタムメソッド**: モデルに独自のメソッドを追加することができます。
* **トランザクション**:  複数の操作をまとめて実行することができます。

sakura-orm はシンプルな ORM ライブラリですが、基本的なデータベース操作を行うのに十分な機能を提供しています。  より複雑なアプリケーションでは、より高機能な ORM ライブラリ (SQLAlchemy など) の利用も検討してください。
