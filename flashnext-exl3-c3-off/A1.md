## 出力

以下に、Shift-JISのCSVファイルを読み込んでUTF-8で保存し直すPython関数を提供します。エラー処理として、ファイルが存在しない場合（`FileNotFoundError`）と文字化けによるデコード失敗（`UnicodeDecodeError`）を適切に処理します。

```python
import os
import csv
import codecs

def convert_csv_encoding(input_path: str, output_path: str) -> None:
    """
    Shift-JISでエンコードされたCSVファイルを読み込み、UTF-8で保存し直す。

    Args:
        input_path (str): 入力ファイルのパス（Shift-JISエンコード）
        output_path (str): 出力ファイルのパス（UTF-8エンコード）

    Raises:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: Shift-JISでデコードできない場合（文字化け）
        Exception: その他のエラー
    """
    # 1. ファイルの存在確認
    if not os.path.exists(input_path):
        raise FileNotFoundError(f"入力ファイルが見つかりません: {input_path}")

    # 2. Shift-JISで読み込み、UTF-8で書き出し
    try:
        # Shift-JISで読み込み
        with open(input_path, 'r', encoding='shift_jis', newline='') as infile:
            reader = csv.reader(infile)
            rows = list(reader)  # 全行をメモリに読み込む

        # UTF-8で書き出し
        with open(output_path, 'w', encoding='utf-8', newline='') as outfile:
            writer = csv.writer(outfile)
            writer.writerows(rows)

        print(f"変換完了: {input_path} -> {output_path}")

    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(
            e.encoding,
            e.object,
            e.start,
            e.end,
            f"Shift-JISでデコードできませんでした（文字化けの可能性）: {e.reason}"
        )
    except Exception as e:
        raise Exception(f"ファイル処理中にエラーが発生しました: {e}")


# 使用例
if __name__ == "__main__":
    input_file = "input_shiftjis.csv"
    output_file = "output_utf8.csv"

    try:
        convert_csv_encoding(input_file, output_file)
    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError as e:
        print(f"デコードエラー: {e}")
    except Exception as e:
        print(f"予期しないエラー: {e}")
```

### 主なポイント

1. **ファイル存在チェック**: `os.path.exists()` で入力ファイルの存在を確認し、存在しない場合は `FileNotFoundError` を明示的に発生させます。
2. **Shift-JIS読み込み**: `open()` で `encoding='shift_jis'` を指定して読み込みます。
3. **UTF-8書き出し**: `open()` で `encoding='utf-8'` を指定して書き出します。
4. **デコードエラー処理**: `UnicodeDecodeError` をキャッチし、文字化けの可能性を示すメッセージとともに再スローします。
5. **CSV処理**: `csv` モジュールを使用して、CSV形式を正しく処理します（カンマやクォートなどのエスケープも適切に扱われます）。
6. **`newline=''`**: CSVモジュールと併用する際は、`newline=''` を指定することで、改行コードの重複や不整合を防ぎます。

### 補足

- 大規模なファイルの場合は、`rows = list(reader)` で全行をメモリに読み込む代わりに、行ごとに読み書きするストリーミング処理を検討してください。
- 必要に応じて、`errors='strict'`（デフォルト）ではなく `errors='replace'` や `errors='ignore'` を指定して、部分的な文字化けを許容することも可能です。
