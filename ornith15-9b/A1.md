## 基本の関数

```python
import csv
import os


def convert_csv_to_utf8(input_path, output_path):
    """
    Shift-JISエンコードのCSVファイルをUTF-8で保存し直す。

    引数:
        input_path: 読み込む元のCSVファイルパス
        output_path: 保存する出力ファイルパス

    例外:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: Shift-JISとしてデコードできない場合
    """
    # 1. ファイルが存在するか確認
    if not os.path.isfile(input_path):
        raise FileNotFoundError(f"ファイルが見つかりません: {input_path}")

    # 2. Shift-JISで読み込む
    with open(input_path, "r", encoding="shift_jis", newline="") as f:
        reader = csv.reader(f)
        rows = list(reader)

    # 3. UTF-8で保存する
    with open(output_path, "w", encoding="utf-8", newline="") as f:
        writer = csv.writer(f)
        writer.writerows(rows)

    print(f"変換完了: {input_path} -> {output_path}")
```

## エラー処理付きのバージョン

実際の業務では、エラーをキャッチしてログ出力するのがおすすめです。

```python
import csv
import os


def convert_csv_to_utf8_safe(input_path, output_path):
    """
    Shift-JISのCSVをUTF-8に変換する（エラーを安全に処理）。

    引数:
        input_path: 読み込む元のCSVファイルパス
        output_path: 保存する出力ファイルパス

    戻り値:
        成功した場合: True
        失敗した場合: (False, エラーメッセージ)
    """
    try:
        # ファイルが存在するか確認
        if not os.path.isfile(input_path):
            return False, f"ファイルが見つかりません: {input_path}"

        # Shift-JISで読み込む
        with open(input_path, "r", encoding="shift_jis", newline="") as f:
            reader = csv.reader(f)
            rows = list(reader)

        # UTF-8で保存する
        with open(output_path, "w", encoding="utf-8", newline="") as f:
            writer = csv.writer(f)
            writer.writerows(rows)

        return True, f"変換完了: {input_path} -> {output_path}"

    except FileNotFoundError:
        return False, f"ファイルが見つかりません: {input_path}"
    except UnicodeDecodeError:
        return False, f"文字化け(デコード失敗): {input_path}"
    except Exception as e:
        return False, f"エラー: {e}"
```

## 使用例

```python
# エラーをキャッチして処理する例
success, message = convert_csv_to_utf8_safe("input.csv", "output.csv")

if success:
    print(message)
else:
    print(f"失敗しました: {message}")
```

## ポイント

| 項目 | 説明 |
|------|------|
| `newline=""` | CSVの改行コード（`\r\n`）を正しく保持するため重要 |
| `encoding="shift_jis"` | 元のファイルのエンコード |
| `encoding="utf-8"` | 出力ファイルのエンコード |
| `csv.reader/writer` | 行単位で読み書きし、CSV形式を保持 |

## 補足：エンコードの自動判定

もしファイルのエンコードが不明な場合は、`chardet`ライブラリで検出できます。

```python

import chardet

with open("input.csv", "rb") as f:
    raw = f.read()
    detected = chardet.detect(raw)
    print(detected)  # {'encoding': 'shift_jis', 'confidence': 0.99}
```

この場合、検出結果のエンコードで読み込むように調整してください。
