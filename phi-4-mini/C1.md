## 出力

Sakura ORMは、PyQt5と組み合わせて使用するORM（Object Relational Mapping）ツールです。以下にシンプルな例を示しますが、この時点では PyQt5 と Sakura ORM のインストールが必要になります。

まず、 pip を使ってこれらのライブラリをインストールしてください:

```bash
pip install pyqt5 sakura-orm
```

次に、基本的な使用方法について説明します。以下はコード例です:

1. `models.py` ファイルでデータベースとモデルを定義する。

```python
# models.py
from sqlalchemy import Column, Integer, String
from sakura.models import Model, STRING

class User(Model):
    id = Column(Integer)
    name = Column(String(50))

if __name__ == '__main__':
    User.create_table()
```

2. `app.py` ファイルでデータベース操作を行う。

```python
# app.py
import sys
from PyQt5.QtWidgets import QApplication, QWidget, QLabel, QVBoxLayout
from sakura.orm.session import Session
from models import User

def create_user(name):
    session = Session()
    user = User(name=name)
    session.add(user)
    session.commit()

def get_users():
    session = Session()
    return session.query(User).all()

app = QApplication(sys.argv)

window = QWidget()
layout = QVBoxLayout()

label = QLabel('Hello, Sakura ORM!')
layout.addWidget(label)

window.setWindowTitle('Sakura ORM Example')
window.setLayout(layout)
window.show()

sys.exit(app.exec_())
```

3.  `create_user` と `get_users` 関数を使用してデータベース操作を行う。

```python
if __name__ == '__main__':
    create_user('John Doe')

users = get_users()
for user in users:
    print(user.name)
```

この例では、PyQt5 ウィジェットと Sakura ORM を使って GUI アプリケーションでデータベース操作を行います。`create_user` 関数は新しいユーザーを作成し、 `get_users` はすべてのユーザー名を取得します。
