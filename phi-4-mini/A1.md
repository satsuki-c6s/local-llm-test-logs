## 出力

以下は、 existence_error と decoding_error を処理するために try/exceptブロックを使用して Python で Shift-JIS の CSV ファイルを UTF-8 に変換し保存する関数です。この例では pandas および codecs ライブラリが必要とされます。これらのライブラリは、インストールしていない場合に pip を使ってインストールしてください。

```python
import pandas as pd

from io import open  # Python3.10 以降で 'open' は 'io.open' に置き換えられています。
import codecs


def convert_shiftjis_csv_to_utf8(input_filepath, output_filepath):
    try:
        # Shift-JIS ファイルを読み込む
        with open(input_filepath, encoding='shift_jis', errors='ignore') as f:
            shiftjis_data = pd.read_csv(f)

        # UTF-8 で CSV を書き出す
        utf8_output_path = codecs.open(output_filepath, 'w', 'utf-8')
        encoded_str = shiftjis_data.to_csv(encoding='utf-8', index=False)
        
        # UTF-8 出力ファイルに文字列を書き込む
        utf8_output_path.write(encoded_str)

    except FileNotFoundError:
        print(f"エラー: '{input_filepath}' ファイルが見つかりませんでした。")
    except UnicodeDecodeError:
        print("デコード失敗：入力ファイルの Shift-JIS 文字は UTF-8 に変換できませんでした。")

# 使用例：
convert_shiftjis_csv_to_utf8('shift_jis_sample.csv', 'utf8_output.csv')
```

この関数を使用するには、'input_filepath' を CSV ファイルがあるパスに置き換え、「output_filepath」をUTF-8で保存したいファイル名に変更してください。

注：`pd.read_csv(f)` は文字化けの可能性があるため 'f' というオブジェクトを直接渡すことはできません。CSV ファイル内のデコードエラーを処理するには、より複雑なロジックや CSV の読み込み方法に依存します。この例では `pd.read_csv(f)` を使用しているため、ファイルが UTF-8 でない場合、`UnicodeDecodeError` が発生する可能性があります。CSV ファイルの内容を正しく処理するには、より詳細なエラーハンドリングと CSV の読み込み方法に依存します。

また、この例では 'shift_jis' エンコーディングは直接 `open()` 関数で使用できないため、`pandas.read_csv()` を使ってファイルを初期化し、その後 UTF-8 文字列として書き出しています。CSV ファイルが Shift-JIS のエンコーディングではなく、UTF-8 エンコーディングの場合は `encoding='utf-8'` オプションに変更してください。

さらに、この関数は CSV 内のデータ構造を考慮していません（列名や型など）。CSV ファイル内で扱う必要がある複雑なデータ構造については、コードを調整する必要があります。
