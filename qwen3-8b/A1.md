### ✅ 関数の説明

- **入力**: Shift-JISで保存されたCSVファイルのパス
- **出力**: UTF-8で保存されたCSVファイル（同じパスに上書き）
- **エラー処理**:
  - ファイルが存在しない場合: `FileNotFoundError` をキャッチしてエラーメッセージを出力
  - Shift-JISのデコード失敗: `UnicodeDecodeError` をキャッチしてエラーメッセージを出力
  - その他のエラー: 一般的な例外をキャッチしてエラーメッセージを出力

### ✅ Pythonコード

```python
import csv
import os

def convert_shiftjis_to_utf8(csv_file_path):
    try:
        # ファイルが存在するか確認
        if not os.path.exists(csv_file_path):
            raise FileNotFoundError(f"ファイルが見つかりません: {csv_file_path}")

        # Shift-JISで読み込む
        with open(csv_file_path, 'r', encoding='shift_jis', errors='ignore') as src_file:
            reader = csv.reader(src_file)
            rows = list(reader)

        # UTF-8で上書き保存
        with open(csv_file_path, 'w', encoding='utf-8', newline='') as dst_file:
            writer = csv.writer(dst_file)
            writer.writerows(rows)

        print(f"変換完了: {csv_file_path}")

    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError as e:
        print(f"エラー: Shift-JISのデコードに失敗しました: {e}")
    except Exception as e:
        print(f"予期せぬエラーが発生しました: {e}")

# 使用例
convert_shiftjis_to_utf8('example.csv')
```

---

### ✅ 注意点

- `errors='ignore'` は、Shift-JISで読めない文字を無視して処理します。必要に応じて `errors='replace'` なども使用可能です。
- `newline=''` はCSVファイルの改行コードを正しく処理するための設定です。
- ファイルの上書きは注意が必要です。必要に応じて別のファイル名に保存するなど、安全な処理を検討してください。
