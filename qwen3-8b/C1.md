## 出力

`sakura-orm` は、Python 用の ORM（Object-Relational Mapping）ライブラリで、特に SQL データベースと Python オブジェクトの間のマッピングを扱います。このライブラリは、SQLAlchemy と似たようなインターフェースを提供していますが、より軽量でシンプルな設計を目指しています。

以下に、`sakura-orm` の基本的な使い方をコード例付きで説明します。

---

## 🔧 1. インストール

まず、`sakura-orm` をインストールします。

```bash
pip install sakura-orm
```

---

## 📦 2. モデルの定義

`sakura-orm` では、モデルは Python のクラスとして定義します。`@model` デコレーターを使用します。

### ✅ 例: ユーザーのモデル

```python
from sakura.orm import model, field

class User(model):
    id = field.Integer(primary_key=True)
    name = field.String()
    email = field.String(unique=True)
    created_at = field.DateTime(default=lambda: datetime.datetime.now())
```

- `id` は主キー
- `name` は文字列
- `email` はユニーク制約
- `created_at` はデフォルト値を設定

---

## 📁 3. データベースの初期化

`sakura-orm` は SQLite など、いくつかのデータベースをサポートしています。

### ✅ 例: SQLite でデータベースを初期化

```python
from sakura.orm import create_engine, Session

# データベースエンジンの作成（SQLite）
engine = create_engine('sqlite:///example.db')

# モデルをデータベースにマッピング
User.bind(engine)

# セッションの作成
session = Session(engine)
```

---

## 📝 4. データの操作

### ✅ 4-1. データの挿入

```python
user = User(name="Alice", email="alice@example.com")
session.add(user)
session.commit()
```

### ✅ 4-2. データの取得

```python
user = session.query(User).filter(User.email == "alice@example.com").first()
print(user.name)  # Alice
```

### ✅ 4-3. データの更新

```python
user.name = "Alicia"
session.commit()
```

### ✅ 4-4. データの削除

```python
session.delete(user)
session.commit()
```

---

## 🔁 5. リレーションシップ（例: 1対多）

### ✅ 例: ユーザーと投稿の関係

```python
from sakura.orm import model, field, relation

class Post(model):
    id = field.Integer(primary_key=True)
    title = field.String()
    content = field.Text()
    user_id = field.Integer()
    user = relation("User", foreign_key="user_id")
```

### ✅ データの挿入と取得

```python
user = User(name="Bob", email="bob@example.com")
post = Post(title="Hello World", content="This is my first post.", user=user)
session.add(post)
session.commit()

# 投稿を取得してユーザーを参照
post = session.query(Post).first()
print(post.user.name)  # Bob
```

## 📌 6. クエリの例

### ✅ 例: 指定された条件でデータを取得

```python
users = session.query(User).filter(User.name.like("%Alice%")).all()
for u in users:
    print(u.name)
```

### ✅ 例: ソートと制限

```python
users = session.query(User).order_by(User.id.desc()).limit(5).all()
```
