## プロンプト

```
PythonでShift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数を書いてください。
存在しないファイルと文字化け(デコード失敗)のエラー処理も含めてください。
```

## 出力

```python
import csv
import os

def convert_sjis_csv_to_utf8(input_path, output_path):
    """
    Shift-JISのCSVファイルを読み込み、UTF-8で保存し直す関数。

    Parameters:
        input_path (str): 入力CSVファイルのパス（Shift-JIS）
        output_path (str): 出力CSVファイルのパス（UTF-8）

    Returns:
        bool: 成功した場合はTrue、失敗した場合はFalse

    Raises:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: Shift-JISのデコードに失敗した場合（文字化け）
    """
    try:
        # 入力ファイルの存在確認
        if not os.path.exists(input_path):
            raise FileNotFoundError(f"入力ファイルが存在しません: {input_path}")

        # Shift-JISで読み込み
        with open(input_path, 'r', encoding='shift_jis', newline='') as f_in:
            reader = csv.reader(f_in)
            rows = list(reader)

        # UTF-8で書き込み
        with open(output_path, 'w', encoding='utf-8', newline='') as f_out:
            writer = csv.writer(f_out)
            writer.writerows(rows)

        return True

    except FileNotFoundError as e:
        print(f"エラー: {e}")
        return False
    except UnicodeDecodeError as e:
        print(f"エラー: 文字化けが発生しました（デコード失敗）: {e}")
        return False
    except Exception as e:
        print(f"予期しないエラー: {e}")
        return False
```

### 使用例
```python
# 正常な変換
success = convert_sjis_csv_to_utf8("input_sjis.csv", "output_utf8.csv")
print(success)  # True

# 存在しないファイル
success = convert_sjis_csv_to_utf8("missing.csv", "output_utf8.csv")
print(success)  # False（エラーメッセージが表示される）

# 文字化け（Shift-JISではないファイル）
success = convert_sjis_csv_to_utf8("utf8_file.csv", "output_utf8.csv")
print(success)  # False（UnicodeDecodeErrorがキャッチされる）
```

### 補足
- エンコーディングは`shift_jis`を指定していますが、環境によっては`cp932`（Windows版Shift-JIS）の方が適切な場合もあります。
- 大きなCSVファイルを扱う場合は、`rows = list(reader)`の代わりにストリーミング処理（行ごとに読み書き）を検討してください。
- エラー時は`False`を返し、エラーメッセージを標準出力に表示します。必要に応じて例外をそのまま呼び出し元に伝播させる設計に変更できます。
