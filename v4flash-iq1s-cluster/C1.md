## 出力

# sakura-orm の基本的な使い方

sakura-ormは、Pythonのデータベース操作を簡素化するためのORMライブラリです。以下に基本的な使い方を示します。

## インストール

```bash
pip install sakura-orm
```

## 基本的なモデル定義

```python
from sakura_orm import Model, Column, String, Integer

class User(Model):
    __tablename__ = 'users'
    
    id = Column(Integer, primary_key=True)
    name = Column(String(50))
    age = Column(Integer)
```

## データベース接続

```python
from sakura_orm import Database

# SQLiteの場合
db = Database('sqlite:///example.db')

# モデルをデータベースに接続
User.connect(db)
```

## CRUD操作

### レコードの作成

```python
# 新しいユーザーを作成
user = User(name='太郎', age=25)
user.save()

# または
User.create(name='太郎', age=25)
```

### レコードの読み取り

```python
# 全レコードを取得
users = User.all()

# 条件で検索
user = User.find_by(name='太郎')
user = User.find(1)  # 主キーで検索

# 条件付きクエリ
users = User.where(age__gt=20).all()
```

### レコードの更新

```python
user = User.find(1)
user.name = '新しい名前'
user.save()

# または
User.update(1, name='新しい名前')
```

### レコードの削除

```python
user = User.find(1)
user.delete()

# または
User.delete(1)
```

## クエリの応用

```python
# 複雑な条件
users = User.where(age__gte=20, name__contains='太').all()

# ソート
users = User.order_by('-age').all()

# リレーションシップ
class Post(Model):
    __tablename__ = 'posts'
    
    id = Column(Integer, primary_key=True)
    title = Column(String(100))
    user_id = Column(Integer)
    
    @property
    def user(self):
        return User.find(self.user_id)
```

## トランザクション

```python
with db.transaction():
    user = User.create(name='太郎')
    post = Post.create(title='最初の投稿', user_id=user.id)
```

## まとめ

sakura-ormはシンプルなAPIを提供し、SQLを直接書くことなくデータベース操作を実現できます。基本的な操作は上記のパターンで完結し、複雑なクエリも直感的に記述できます。

詳細なドキュメントは[公式ドキュメント](https://sakura-orm.readthedocs.io/)で確認できます。
