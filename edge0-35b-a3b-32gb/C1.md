## 出力

PythonのORMライブラリ「sakura-orm」は、Sakura CMS（桜CMS）やその関連プロジェクトで開発された、比較的小規模でシンプルなORMです。主にデータベースの接続とテーブル操作を簡易に実行するためのものです。

以下に、基本的な使い方をコード例付きで解説します。

---

### 1. インインストール

まず、パッケージをインストールします。

```bash
pip install sakura-orm
```

---

### 2. 基本的な設定と接続

ORMを初期化し、データベースに接続します。ここではSQLiteを例として使用します。

```python
import sakura_orm

# 1. ORMの初期化
# 設定ファイルや環境変数から接続情報を取得するのが一般的ですが、
# 簡易版では直接設定することもできます。
orm = sakura_orm.ORM(
    db_type='sqlite',
    db_path='sakura.db',  # SQLiteのファイルパス
    user='user',
    password='password'  # SQLiteでは通常不要
)

# 2. デベースに接続
orm.connect()
```

---

### 3. テーブルの作成（モデル定義）

ORMでは、テーブルを「モデル」として定義します。

```python
# 1. モデルの定義
# 例：ユーザーテーブル
```
```python
class User(sakura_orm.Model):
    id = sakura_orm.Column(primary_key=True)
    name = sakura_orm.Column(String(50))
    email = sakura_orm.Column(String(100))
    age = sakura_orm.Column(Integer)

# 2. テーブルを作成
orm.create_table(User)
```

---

### 4. デーブルへの挿入（Insert）

新しいデータをテーブルに追加します。

```python
# 1. 新しいユーザーオブジェクトを作成
new_user = User(
    name='Alice',
    email='alice@example.com',
    age=25
)

# 2. デーブルに挿入
orm.insert(new_user)
```

---

### 5. デーブルからの検索（Query）

#### 基本的な検索
```python
# 1. 名前が'Alice'のユーザーを検出
users = orm.query(User, name='Alice')

# 2. 結果を表示
for user in users:
    print(f"ID: {user.id}, Name: {user.name}, Email: {user.email}")
```

#### 条件付き検索（WHERE句）
```python
# 年齢が20以上かつ名前が'Alice'のユーザーを検出
users = orm.query(User, name='Alice', age__gte=20)
```

---

### 6. デーブルの更新（Update）

既存のデータを更新します。

```python
# 1. 更新対象のユーザーを取得
user = orm.query(User, name='Alice')

# 2. 属性を更新
user.age = 26

# 3. デーブルに保存
orm.update(user)
```

---

### 7. デーブルの削除（Delete）

データを削除します。

```python
# 1. 削除対象のユーザーを取得
user = orm.query(User, name='Alice')

# 2. デーブルから削除
orm.delete(user)
```

---

### 8. デーブルのクリッピング（Close）

接続を閉じます。

```python
orm.disconnect()
```

---

### 注意点

1. **モデル定義**: `sakura_orm.Model`を継承してテーブルを定義します。
2. **Column属性**: デーブルの列を定義するために`Column`属性を使用します。
3. **Query方法**: `orm.query(Model, condition)`でデータを検索します。
4. **データベースタイプ**: SQLite以外でもMySQLやPostgreSQLをサポートしている可能性があります。設定ファイルや環境変数で指定します。
