## 出力

以下は、Shift-JISのCSVファイルを読み込んでUTF-8で保存し直すPython関数です。存在しないファイルと文字化け（デコード失敗）のエラー処理を含んでいます。

```python
import csv
import os


def convert_shjis_to_utf8(input_file: str, output_file: str) -> None:
    """
    Shift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数。

    引数:
        input_file: Shift-JISのCSVファイルのパス
        output_file: UTF-8で保存するCSVファイルのパス

    エラー処理:
        - 存在しないファイルの場合、FileNotFoundErrorを投げる
        - 文字化け（デコード失敗）の場合、UnicodeDecodeErrorを投げる
    """
    # 入力ファイルの存在確認
    if not os.path.exists(input_file):
        raise FileNotFoundError(f"入力ファイル '{input_file}' が見つかりません。")

    # 読み込みと変換
    try:
        with open(input_file, 'r', encoding='shift_jis') as f:
            reader = csv.reader(f)
            rows = list(reader)

        # 出力ファイルの存在確認（ファイルがすでに存在する場合、上書きするか確認）
        if os.path.exists(output_file):
            print(f"出力ファイル '{output_file}' がすでに存在します。上書きします。")

        # UTF-8で保存
        with open(output_file, 'w', encoding='utf-8', newline='') as f:
            writer = csv.writer(f)
            writer.writerows(rows)

        print(f"ファイル '{input_file}' を '{output_file}' にUTF-8で変換しました。")

    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(f"ファイル '{input_file}' の読み込み中に文字化けが発生しました。: {e}")

    except Exception as e:
        raise Exception(f"ファイル '{input_file}' の処理中にエラーが発生しました。: {e}")
```

### 使用例

```python
try:
    convert_shjis_to_utf8('input_shjis.csv', 'output_utf8.csv')
except FileNotFoundError as e:
    print(f"ファイルが見つかりません: {e}")
except UnicodeDecodeError as e:
    print(f"文字化けが発生しました: {e}")
except Exception as e:
    print(f"エラーが発生しました: {e}")
```

### 主なポイント

1. **存在しないファイルのチェック**: `os.path.exists()` で入力ファイルの存在を確認し、見つからない場合は `FileNotFoundError` を投げる。
2. **文字化けのチェック**: `shift_jis` エンコーディングで読み込む際に `UnicodeDecodeError` が発生した場合、それをキャプチャして `UnicodeDecodeError` を再投げる。
3. **CSVの読み込みと書き込み**: `csv.reader` と `csv.writer` を使用してCSVデータを適切に読み込み・書き込む。
4. **出力ファイルの上書き**: 出力ファイルがすでに存在する場合、上書きすることを明示的に表示する。
5. **汎的なエラー処理**: 上記の特定のケース以外でもエラーが発生した場合、`Exception` でキャプチャして一般的なエラーメッセージを表示する。
