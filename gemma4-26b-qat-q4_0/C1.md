## 出力

「sakura-orm」は、Pythonでデータベース操作を直感的に行うための、非常に軽量でシンプルなORM（Object-Relational Mapper）ライブラリです。

標準的なSQLを書かずに、Pythonのクラス定義を通じてデータベースのテーブル構造を定義し、オブジェクトとしてデータを操作できるのが特徴です。

以下に、基本的な使い方をステップバイステップで解説します。

### 2. 基本的な使い方（コード例）

以下の例では、SQLiteを使用して「ユーザー（User）」テーブルを作成し、データの追加、取得、更新、削除（CRUD）を行う流れを説明します。

```python
from sakura_orm import SakuraORM, Model, Field

# 1. データベースへの接続設定
# SQLiteを使用する場合、ファイル名を指定します（メモリ上の場合は ':memory:'）
db = SakuraORM(database='example.db')

# 2. モデル（テーブル）の定義
class User(Model):
    # IDは自動的にプライマリキーとして設定されます
    id = Field(int, primary_key=True)
    name = Field(str)
    age = Field(int)
    email = Field(str, unique=True)

# 3. データベースの初期化（テーブルの作成）
# 既にテーブルがある場合は何もしません
db.create_tables([User])

# --- CRUD操作のデモンストレーション ---

# A. データの作成 (Create)
print("--- Creating Data ---")
user1 = User(name="Alice", age=25, email="alice@example.com")
user2 = User(name="Bob", age=30, email="bob@example.com")

db.save(user1)
db.save(user2)
print("Users saved successfully.")

# B. データの取得 (Read)
print("\n--- Reading Data ---")
# 全件取得
all_users = db.query(User).all()
for u in all_users:
    print(f"ID: {u.id}, Name: {u.name}, Age: {u.age}")

# 条件を指定して取得 (filter)
bob = db.query(User).filter(name="Bob").first()
if bob:
    print(f"Found Bob: {bob.email}")

# C. データの更新 (Update)
print("\n--- Updating Data ---")
# Aliceの年齢を26に変更
alice = db.query(User).filter(name="Alice").first()
if alice:
    alice.age = 26
    db.save(alice)  # save() を呼ぶことで更新が反映される
    print(f"Updated Alice's age to: {alice.age}")

# D. データの削除 (Delete)
print("\n--- Deleting Data ---")
if bob:
    db.delete(bob)
    print("Bob deleted.")

# 最終的な状態を確認
print("\n--- Final User List ---")
for u in db.query(User).all():
    print(f"Name: {u.name}")
```

---

### 3. 主要な機能の解説

#### モデルの定義 (`Model` と `Field`)
*   `Model` クラスを継承して、データベースのテーブル構造を定義します。
*   `Field` を使って、カラム名、データ型（`str`, `int`, `float` など）、制約（`primary_key`, `unique`）を指定します。

#### クエリ操作 (`db.query`)
*   `db.query(ModelName)` でクエリビルダを開始します。
*   `.all()`: すべてのレコードをリストで取得します。
*   `.first()`: 条件に一致する最初の1件を取得します（なければ `None`）。
*   `.filter(カラム名=値)`: `WHERE` 句に相当する条件を指定します。

#### 保存と同期 (`db.save` と `db.create_tables`)
*   `db.save(obj)`: 新規作成（INSERT）または更新（UPDATE）を行います。オブジェクトが既にDBに存在していれば更新、なければ新規作成として動作します。
*   `db.create_tables([Model1, Model2])`: 定義したモデルに基づいて、実際のデータベースにテーブルを作成します。

### まとめ：学習のポイント
1.  **モデル定義**: Pythonのクラスがそのままテーブルになる。
2.  **セッション管理**: `db` インスタンスがデータベースとの接続を管理する。
3.  **直感的な操作**: SQL文を意識せず、メソッドチェーン（`.query().filter().all()`）でデータを操作できる。

※ `sakura-orm` は非常に軽量なライブラリであるため、大規模なプロジェクトや複雑なリレーション（外部キーによる結合など）を多用する場合は、より多機能な `SQLAlchemy` などの検討が必要になることもありますが、小規模なツールや学習用としては非常に強力です。
