エラー処理として、**「ファイルが存在しない場合（FileNotFoundError）」**、**「文字コードがShift-JISではない場合（UnicodeDecodeError）」**、および**「その他の予期せぬエラー」**をキャッチするように構成しています。

### サンプルコード

```python
import csv
import os

def convert_sjis_to_utf8(input_file, output_file):
    """
    Shift-JISのCSVファイルを読み込み、UTF-8で保存し直す。
    
    Args:
        input_file (str): 読み込み元のファイルパス
        output_file (str): 保存先のファイルパス
    """
    try:
        # 1. ファイルの存在確認
        if not os.path.exists(input_file):
            raise FileNotFoundError(f"エラー: ファイル '{input_file}' が見つかりません。")

        # 2. ファイルの読み込みと書き出し
        # newline='' は csvモジュールを使用する際の推奨設定
        with open(input_file, mode='r', encoding='shift_jis', newline='') as f_in:
            reader = csv.reader(f_in)
            
            with open(output_file, mode='w', encoding='utf-8', newline='') as f_out:
                writer = csv.writer(f_out)
                
                for row in reader:
                    writer.writerow(row)
        
        print(f"成功: '{input_file}' を '{output_file}' として保存しました。")

    except FileNotFoundError as e:
        print(f"ファイルエラー: {e}")
    
    except UnicodeDecodeError:
        print(f"文字コードエラー: '{input_file}' は Shift-JIS ではない可能性があります。")
        print("（原因の例: UTF-8で既に保存されている、または別の文字コードである）")
        
    except Exception as e:
        print(f"予期せぬエラーが発生しました: {e}")

# --- テスト用コード ---
if __name__ == "__main__":
    # テスト用のファイル作成 (Shift-JIS)
    test_file = "test_sjis.csv"
    output_file = "test_utf8.csv"
    
    with open(test_file, mode='w', encoding='shift_jis', newline='') as f:
        writer = csv.writer(f)
        writer.writerow(["名前", "年齢", "備考"])
        writer.writerow(["田中太郎", "25", "テストデータ"])

    # 実行

    convert_sjis_to_utf8(test_file, output_file)
    
    # 存在しないファイルを指定してテスト
    print("\n--- 存在しないファイルでのテスト ---")
    convert_sjis_to_utf8("non_existent.csv", "error.csv")

    # 文字化け（UTF-8のファイルをShift-JISとして読もうとする）テスト

    with open(utf8_file, mode='w', encoding='utf-8', newline='') as f:
        f.write("漢字のテスト")
    convert_sjis_to_utf8(utf8_file, "error_encoding.csv")
```

### コードのポイント解説

1.  **`encoding='shift_jis'`**:
    読み込み時に明示的に `shift_jis` を指定しています。もし、Windows特有の拡張文字（「①」や「㍉」など）が含まれている場合は、`encoding='cp932'` と書くとより安全です（実務上は `cp932` を使うのが一般的です）。
2.  **`newline=''`**:
    `csv` モジュールを使用する場合、これを行わないと、OS（特にWindows）によっては空行が余計に挿入される原因になるため、必須の作法です。
3.  **エラーハンドリング**:
    *   `FileNotFoundError`: ファイルパスが間違っている場合に発生します。
    *   `UnicodeDecodeError`: 指定したエンコーディング（Shift-JIS）で解釈できないバイト列があった場合に発生します（例：既にUTF-8のファイルをShift-JISとして開こうとした時など）。
    *   `Exception`: それ以外の予期せぬエラー（ディスク容量不足、権限エラーなど）をまとめてキャッチします。
4.  **`os.path.exists`**:
    ファイルを開く前に存在を確認することで、より丁寧なエラーメッセージを出せるようにしています。

### 補足：より強力な変換が必要な場合
もし、ファイルがShift-JISなのかUTF-8なのか事前に判別できないようなケースを大量に処理する場合は、`chardet` というライブラリを使って文字コードを自動判定する手法もありますが、通常の「Shift-JISだと分かっているファイルの変換」であれば、上記の方法が最も高速で確実です。
