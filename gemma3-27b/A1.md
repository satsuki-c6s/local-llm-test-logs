```python
import csv

def convert_csv_encoding(input_filepath, output_filepath):
    """
    Shift-JISエンコーディングのCSVファイルを読み込み、UTF-8エンコーディングで保存し直す関数です。

    Args:
        input_filepath (str): 入力ファイルパス（Shift-JIS）
        output_filepath (str): 出力ファイルパス（UTF-8）
    """

    try:
        with open(input_filepath, 'r', encoding='shift_jis') as infile, \
             open(output_filepath, 'w', encoding='utf-8', newline='') as outfile:  # newline='' は改行コードの自動変換を防ぎます。

            reader = csv.reader(infile)
            writer = csv.writer(outfile)

            for row in reader:
                writer.writerow(row)

        print(f"ファイル '{input_filepath}' を UTF-8 エンコーディングで '{output_filepath}' に変換しました。")

    except FileNotFoundError:
        print(f"エラー：ファイル '{input_filepath}' が見つかりません。")
    except UnicodeDecodeError as e:
        print(f"エラー：ファイルのデコードに失敗しました (Shift-JIS)。文字化けしている可能性があります。\n詳細: {e}")
    except Exception as e:  # その他のエラーをキャッチ
        print(f"予期せぬエラーが発生しました: {e}")


if __name__ == '__main__':
    # テスト用のファイルパス (適宜変更してください)
    input_file = 'sample.csv'  # Shift-JISエンコーディングのCSVファイル
    output_file = 'sample_utf8.csv' # UTF-8エンコーディングで保存するファイル

    # サンプルデータを作成（Shift-JIS）
    with open(input_file, 'w', encoding='shift_jis') as f:
        f.write("名前,年齢,住所\n")
        f.write("山田太郎,30,東京都\n")
        f.write("田中花子,25,大阪府\n")
        f.write("佐藤健太,40,神奈川県\n")

    convert_csv_encoding(input_file, output_file)

    # 存在しないファイルでテスト
    convert_csv_encoding('nonexistent_file.csv', 'output.csv')

    # 文字化けしたファイルを想定してテスト (Shift-JISとして解釈できないバイト列を含むファイルを作成)
    with open("broken.csv", "wb") as f:
        f.write(b"abc\xffdef")  # \xff は Shift-JIS で無効なバイトシーケンス

    convert_csv_encoding("broken.csv", "output_broken.csv")
```

**コードの解説:**

1. **`convert_csv_encoding(input_filepath, output_filepath)` 関数:**
   - `input_filepath`: 読み込むShift-JISエンコーディングのCSVファイルのパス。
   - `output_filepath`: UTF-8エンコーディングで保存するCSVファイルのパス。

2. **`try...except` ブロックによるエラー処理:**
   - `FileNotFoundError`:  入力ファイルが見つからない場合に発生します。適切なエラーメッセージを表示します。
   - `UnicodeDecodeError`: Shift-JISでのデコードに失敗した場合（文字化け）に発生します。これもエラーメッセージを表示します。  このエラーは、Shift-JISで表現できない文字が含まれている場合に起こります。
   - `Exception as e`: その他の予期せぬエラーをキャッチし、エラーメッセージを表示します。

3. **ファイルのオープン:**
   - `with open(input_filepath, 'r', encoding='shift_jis') as infile:`:  Shift-JISエンコーディングで入力ファイルを読み込みモード (`'r'`) で開きます。`with` ステートメントを使用すると、ファイルは自動的に閉じられます。
   - `with open(output_filepath, 'w', encoding='utf-8', newline='') as outfile:`: UTF-8エンコーディングで出力ファイルを書き込みモード (`'w'`) で開きます。  `newline=''` は、CSVファイルに改行コードが正しく書き込まれるようにするために重要です。これを指定しないと、Windows環境では余分な空行が挿入されることがあります。

4. **CSVリーダーとライターの作成:**
   - `reader = csv.reader(infile)`:  入力ファイルを読み込むためのCSVリーダーを作成します。
   - `writer = csv.writer(outfile)`: 出力ファイルに書き込むためのCSVライターを作成します。

5. **行ごとの処理:**
   - `for row in reader:`: 入力ファイルの各行を順番に読み込みます。
   - `writer.writerow(row)`:  読み込んだ行を出力ファイルに書き込みます。

6. **テストコード (`if __name__ == '__main__':`)**
   - このブロックは、スクリプトが直接実行された場合にのみ実行されます。
   - サンプルCSVファイルをShift-JISで作成します。
   - `convert_csv_encoding` 関数を呼び出して変換を実行します。
   - 存在しないファイルと文字化けしたファイルでのテストケースを追加しました。

**注意点:**

*   `input_file` と `output_file` のパスを、実際のファイル名に合わせて変更してください。
*   文字化けのエラーが発生した場合、Shift-JIS以外のエンコーディングで保存されている可能性があります。その場合は、`encoding='shift_jis'` を適切なエンコーディングに変更してみてください（例: `'cp932'`, `'euc-jp'`）。  ただし、正しいエンコーディングを特定するのは難しい場合があります。
*   CSVファイルの構造が複雑な場合（引用符や区切り文字の扱いなど）、`csv.reader` と `csv.writer` のオプションを調整する必要があるかもしれません。

このコードは、基本的なShift-JISからUTF-8への変換を行うためのものです。より高度なエラー処理やエンコーディング検出が必要な場合は、追加のライブラリ（例: `chardet`）の使用を検討してください。
