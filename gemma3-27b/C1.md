## Pythonライブラリ sakura-orm の基本的な使い方

`sakura-orm` は、軽量でシンプルなORM (Object-Relational Mapper) ライブラリです。データベース操作をオブジェクト指向で行うことを可能にし、SQL文を直接記述する手間を減らすことができます。

ここでは、`sakura-orm` の基本的な使い方をコード例付きで説明します。

**1. インストール**

まず、`pip` を使って `sakura-orm` をインストールします。

```bash
pip install sakura-orm
```

**2. データベース接続の設定**

`sakura-orm` は SQLite, MySQL, PostgreSQL など様々なデータベースに対応しています。ここでは例として SQLite を使用します。

```python
from sakura import Sakura
import os

# データベースファイルのパス (存在しない場合は作成されます)
db_path = 'example.db'

# Sakura インスタンスを作成し、データベースに接続
sakura = Sakura(db_path)
```

**3. モデルの定義**

ORM で扱うテーブルをモデルとして定義します。`sakura.Table` クラスを継承してモデルクラスを作成します。

```python
class User(sakura.Table):
    id = sakura.Int(primary_key=True)  # 主キー
    name = sakura.String(length=255)
    email = sakura.String(length=255, unique=True) # 重複を許さない制約
    age = sakura.Integer()

    class Meta:
        table_name = 'users'  # テーブル名 (省略するとクラス名が使用されます)
```

**4. テーブルの作成**

モデルに基づいてデータベースにテーブルを作成します。

```python
sakura.create_tables([User]) # 複数のテーブルをまとめて作成することも可能です
```

**5. データの挿入**

`create()` メソッドを使ってデータを挿入します。

```python
user1 = User(name='Alice', email='alice@example.com', age=30)
user2 = User(name='Bob', email='bob@example.com', age=25)

sakura.create([user1, user2]) # 複数のレコードをまとめて挿入することも可能です
```

**6. データの取得**

`select()` メソッドを使ってデータを取得します。

*   **全件取得:**

    ```python
    users = sakura.select('*').from_table(User)
    for user in users:
        print(user.id, user.name, user.email, user.age)
    ```

*   **条件指定での取得:**

    ```python
    # ID が 1 のユーザーを取得
    user = sakura.select('*').from_table(User).where(User.id == 1).first()
    if user:
        print(user.name)

    # 年齢が 25 以上のユーザーを取得
    users = sakura.select('*').from_table(User).where(User.age >= 25)
    for user in users:
        print(user.name, user.age)
    ```

*   **特定のカラムのみ取得:**

    ```python
    # name と email のみを取得
    users = sakura.select('name', 'email').from_table(User)
    for user in users:
        print(user.name, user.email)
    ```

**7. データの更新**

`update()` メソッドを使ってデータを更新します。

```python
# ID が 1 のユーザーの年齢を 31 に更新
sakura.update(User).set(age=31).where(User.id == 1)
```

**8. データの削除**

`delete()` メソッドを使ってデータを削除します。

```python
# ID が 2 のユーザーを削除
sakura.delete(User).where(User.id == 2)
```

**9.  トランザクションの利用**

複数の操作をまとめて実行し、途中でエラーが発生した場合にロールバックすることができます。

```python
with sakura.transaction():
    user3 = User(name='Charlie', email='charlie@example.com', age=40)
    sakura.create([user3])
    # 何らかの処理...
    # エラーが発生した場合、ここで例外が送出され、ロールバックされます。
```

**10. モデル定義時のオプション**

*   `primary_key=True`: 主キーとして設定します。
*   `unique=True`: 重複を許さない制約を設定します。
*   `length`: 文字列型のカラムの長さを指定します。
*   `default`: デフォルト値を設定します。
*   `nullable=False`: NULL 値を許可しない制約を設定します。

**まとめ**

上記は `sakura-orm` の基本的な使い方です。  より複雑なクエリや機能については、公式ドキュメントを参照してください。

[https://github.com/sakurapy/sakura](https://github.com/sakurapy/sakura)

`sakura-orm` はシンプルで使いやすく、小規模から中規模のプロジェクトに適しています。  データベース操作を効率的に行うための強力なツールとなるでしょう。
