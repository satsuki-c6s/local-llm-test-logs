```python
import csv
import os

def convert_sjis_csv_to_utf8(input_path, output_path=None, encoding='shift_jis'):
    """
    Shift-JISエンコーディングのCSVファイルを読み込み、UTF-8で保存し直す関数。

    Args:
        input_path (str): 入力CSVファイルのパス
        output_path (str, optional): 出力CSVファイルのパス。
            指定しない場合は入力ファイル名に「_utf8」を付けて保存。
        encoding (str, optional): 入力ファイルのエンコーディング。
            デフォルトは 'shift_jis'。

    Returns:
        str: 出力ファイルのパス

    Raises:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: デコードに失敗した場合(文字化け)
    """
    # --- ファイル存在チェック ---
    if not os.path.exists(input_path):
        raise FileNotFoundError(
            f"指定されたファイルが見つかりません: {input_path}"
        )

    # --- 出力パスの決定(指定がなければ入力名に「_utf8」を付加) ---
    if output_path is None:
        base, ext = os.path.splitext(input_path)
        output_path = f"{base}_utf8{ext}"

    # --- デコード処理 ---
    try:
        with open(input_path, 'r', encoding=encoding, newline='') as f_in:
            reader = csv.reader(f_in)
            rows = list(reader)
    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(
            encoding, e.object, e.start, e.end,
            f"デコードに失敗しました(文字化けの可能性): {input_path}\n"
            f"詳細: {e.reason}"
        ) from e
    except UnicodeError as e:
        raise UnicodeError(
            f"エンコーディングエラー: {input_path}\n詳細: {e}"
        ) from e

    # --- UTF-8で書き出し ---
    try:
        with open(output_path, 'w', encoding='utf-8', newline='') as f_out:
            writer = csv.writer(f_out)
            writer.writerows(rows)
    except OSError as e:
        raise OSError(f"書き込みに失敗しました: {output_path}\n詳細: {e}") from e

    return output_path


# ===== 使用例 =====
if __name__ == '__main__':
    # 正常なケース
    try:
        result = convert_sjis_csv_to_utf8('sample_sjis.csv')
        print(f"変換が完了しました: {result}")
    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError as e:
        print(f"エラー: {e}")

    # 存在しないファイル
    try:
        convert_sjis_csv_to_utf8('not_found.csv')
    except FileNotFoundError as e:
        print(f"エラー: {e}")

    # 文字化け(デコード失敗)のケース
    try:
        convert_sjis_csv_to_utf8('broken_sjis.csv')
    except UnicodeDecodeError as e:
        print(f"エラー: {e}")
```

## 実装のポイント

1. **ファイル存在チェック**:`os.path.exists()`で事前に確認し、存在しない場合は`FileNotFoundError`を発生させます。

2. **デコードエラー処理**:`UnicodeDecodeError`をキャッチして、より分かりやすいエラーメッセージと共に再送出します。文字化けの原因となる不正なバイト列を検出できます。

3. **`newline=''`の指定**:CSVファイルを扱う際は、Windowsの改行コード(CRLF)のズレを防ぐために必ず指定します。

4. **`errors`オプション**:デフォルトでは`'strict'`モードでデコードするため、不正なバイトがあると即座にエラーになります。もし「多少の文字化けは許容して変換したい」場合は、`open()`の`errors='replace'`オプションで置き換え文字(`U+FFFD`)に置換できます。
