## もしORMの基本を知りたい場合

おそらくあなたが探しているのは一般的なPython ORMの使い方かと思います。実在する主要なORMであれば喜んでコード例を提供できます。例えば:

**SQLAlchemy(最も人気のあるORM)**

```python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base, sessionmaker

Base = declarative_base()

class User(Base):
    __tablename__ = "users"
    id = Column(Integer, primary_key=True)
    name = Column(String(50))

engine = create_engine("sqlite:///example.db")
Base.metadata.create_all(engine)

Session = sessionmaker(bind=engine)
session = Session()

# 作成・保存
user = User(name="田中")
session.add(user)
session.commit()

# 検索
found = session.query(User).filter_by(name="田中").first()
print(found.name)
```

**Peewee(シンプルで学習しやすい)**

```python
from peewee import SqliteDatabase, Model, CharField

db = SqliteDatabase("example.db")

class User(Model):
    name = CharField()

    class Meta:
        database = db

db.create_tables([User])

# 作成・保存
User.create(name="田中")

# 検索
user = User.get(User.name == "田中")
print(user.name)
```
