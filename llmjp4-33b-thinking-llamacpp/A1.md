## 出力

以下は **「Shift‑JIS で書かれた CSV を読み込み、UTF‑8 に変換して保存」** するだけのシンプルなユーティリティです。  

* `Path`（`pathlib`）でパス操作を行うので OS に依存しません。  
* ファイルが存在しない場合は `FileNotFoundError` を捕捉し、分かりやすいメッセージを出します。  
* デコードに失敗した（＝文字化けした）場合は `UnicodeDecodeError` を捕捉し、どの行・どのバイトで失敗したかを表示します。  
* エラー時は例外を再送出するか、呼び出し側に `False` を返すか選べます（ここでは例外を再送出しています）。  
* 必要なら `encoding` や `errors` パラメータを変更できるようにしています。

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
shiftjis_csv_converter.py

Shift‑JIS エンコードされた CSV を UTF‑8 に変換して保存するユーティリティ。
"""

from __future__ import annotations

import csv
import sys
from pathlib import Path
from typing import Iterable, List, Sequence


def convert_sjis_csv_to_utf8(
    src_path: str | Path,
    dst_path: str | Path,
    *,
    encoding_src: str = "shift_jis",
    encoding_dst: str = "utf-8",
    delimiter: str = ",",
    quotechar: str = '"',
    quoting: int = csv.QUOTE_MINIMAL,
    errors: str = "strict",
) -> None:
    """
    Shift‑JIS の CSV を読み込み、UTF‑8 で同名（または別名）の CSV として保存する。

    Parameters
    ----------
    src_path : str | Path
        読み込む元 CSV ファイルへのパス。
    dst_path : str | Path
        書き出す先 CSV ファイルへのパス。（ディレクトリが無ければ自動作成）
    encoding_src : str, default ``"shift_jis"``
        元ファイルの文字エンコーディング。
    encoding_dst : str, default ``"utf-8"``
        出力ファイルの文字エンコーディング。
    delimiter : str, default `","`
        CSV の区切り文字。
    quotechar : str, default `'"'`
        フィールドを囲む引用符。
    quoting : int, default ``csv.QUOTE_MINIMAL``
        `csv` モジュールの quoting オプション。
    errors : str, default ``"strict"``
        デコード時のエラーハンドリング方式。
        * ``"strict"``   – デコード失敗で例外を送出（本関数のデフォルト）。
        * ``"replace"``  – 不正バイトは U+FFFD に置換。
        * ``"ignore"``   – 不正バイトは削除。

    Raises
    ------
    FileNotFoundError
        ``src_path`` が存在しない場合。
    UnicodeDecodeError
        Shift‑JIS デコードに失敗した場合（``errors="strict"`` のとき）。
    OSError
        書き込み先ディレクトリの作成やファイル書き込みに失敗した場合。
    """

    src = Path(src_path)
    dst = Path(dst_path)

    # -------------------------------------------------
    # ① 入力ファイルの存在確認
    # -------------------------------------------------
    if not src.is_file():
        raise FileNotFoundError(f"入力ファイルが見つかりません: {src}")

    # -------------------------------------------------
    # ② 出力先ディレクトリが無ければ作成
    # -------------------------------------------------
    dst.parent.mkdir(parents=True, exist_ok=True)

    # -------------------------------------------------
    # ③ CSV を逐次読んで UTF‑8 に書き出す
    # -------------------------------------------------
    try:
        with src.open(mode="r", encoding=encoding_src, errors=errors, newline="") as fin,\
                dst.open(mode="w", encoding=encoding_dst, errors="strict", newline="") as fout:

            reader = csv.reader(fin, delimiter=delimiter, quotechar=quotechar)
            writer = csv.writer(
                fout,
                delimiter=delimiter,
                quotechar=quotechar,
                quoting=quoting,
                lineterminator="\n",
            )

            for row_number, row in enumerate(reader, start=1):
                # 行ごとにそのまま書き込むだけ。必要なら型変換等をここで実施可。
                writer.writerow(row)

    except UnicodeDecodeError as e:
        # デコード失敗は「文字化け」の典型例なので、詳細情報を添えて再送出
        msg = (
            f"Shift‑JIS デコードに失敗しました。\n"
            f"  ファイル: {src}\n"
            f"  行番号: {e.start if hasattr(e, 'start') else '不明'}\n"
            f"  バイト位置: {e.start} (0‑origin)\n"
            f"  原因: {e.reason}"
        )
        raise UnicodeDecodeError(e.encoding, e.object, e.start, e.end, msg) from e


# ----------------------------------------------------------------------
# 【使用例】（スクリプトとして直接走らせても OK）
# ----------------------------------------------------------------------
if __name__ == "__main__":
    # コマンドライン引数で簡易的に使えるようにしておく
    #   $ python shiftjis_csv_converter.py input.csv output_utf8.csv
    if len(sys.argv) != 3:
        print("Usage: python shiftjis_csv_converter.py <input_sjis.csv> <output_utf8.csv>")
        sys.exit(1)

    inp, out = sys.argv[1], sys.argv[2]

    try:
        convert_sjis_csv_to_utf8(inp, out)
        print(f"✅ 成功: '{inp}' → '{out}' (UTF‑8)")
    except FileNotFoundError as fnf_err:
        print(f"❌ エラー: {fnf_err}")
        sys.exit(2)
    except UnicodeDecodeError as dec_err:
        print(f"❌ デコードエラー: {dec_err}")
        sys.exit(3)
    except OSError as os_err:
        print(f"❌ I/O エラー: {os_err}")
        sys.exit(4)
```

### ポイント解説

| 項目 | 内容 |
|------|------|
| **Pathlib** | `Path` オブジェクトで OS 非依存のパス操作が可能。`is_file()` で存在チェック、`mkdir(parents=True)` で親ディレクトリまで一括作成。 |
| **CSV の逐次処理** | `csv.reader` / `csv.writer` はイテレータベースなので、巨大ファイルでもメモリ消費を抑えて行単位で処理できます。 |
| **エラーハンドリング** | - `FileNotFoundError`：入力ファイルが無いときに即座に通知。<br>- `UnicodeDecodeError`：Shift‑JIS デコード失敗時に行番号・バイト位置・原因を付加して再送出。<br>- `OSError`：書き込み権限が無い、ディスクフルなどの I/O 系エラー。 |
| **`errors` 引数** | デフォルトは `"strict"`（失敗したら例外）。必要に応じて `"replace"`（不正バイトは � に置換）や `"ignore"`（削除）に変更可能です。 |
| **CLI 互換** | スクリプトとして直接実行したときに、コマンドラインから手軽に変換できるように `if __name__ == "__main__":` 部分を用意。 |
