## 出力

以下に、指定された要件（Shift-JIS 読み込み → UTF-8 書き出し）を満たす Python の関数を提案します。

この実装では以下のエラーハンドリングを備えています：
1. **ファイル不存在**: `FileNotFoundError` をキャッチしてユーザーに通知し、処理を終了させます。
2. **文字化け (デコード失敗)**: Shift-JIS で正しく読み込めないバイト列が発生した場合（例：破損したデータや不正な BOM など）を `UnicodeDecodeError` で捉え、エラーメッセージと共に終了します。

### コード実装

```python
import csv
from pathlib import Path

def convert_csv_encoding(input_path: str, output_path: str) -> None:
    """
    Shift-JIS エンコードの CSV ファイルを読み込み、UTF-8 で保存し直します。
    
    Args:
        input_path (str): 元の Shift-JIS CSV ファイルのパス
        output_path (str): 新しい UTF-8 CSV ファイルを保存するパス
    
    Raises:
        FileNotFoundError: 指定された入力ファイルが存在しない場合
        UnicodeDecodeError: シフト -JIS で文字化けが発生した場合
    """
    
    # パスの存在確認（FileNotFoundError の発生を防ぐため）
    input_file = Path(input_path)
    if not input_file.exists():
        raise FileNotFoundError(f"入力ファイルが見つかりません：{input_path}")

    try:
        with open(input_path, 'r', encoding='shift_jis') as f_in:
            reader = csv.reader(f_in)
            
            # ヘッダー行を取得してリスト化（空でない限り）
            header = next(reader, None)
            
            if not header:
                print("警告：入力ファイルは空です。")
                return

            with open(output_path, 'w', encoding='utf-8', newline='') as f_out:
                writer = csv.writer(f_out)
                
                # ヘッダーを書き出す
                writer.writerow(header)
                
                # データ行をそのまま書き出し
                for row in reader:
                    writer.writerow(row)

        print(f"変換成功：{input_path} -> {output_path}")

    except UnicodeDecodeError as e:
        error_msg = f"{e}. 入力ファイル ({input_path}) に Shift-JIS で正しくデコードできない文字が含まれています。"
        raise RuntimeError(error_msg) from e
    
    except Exception as e:
        # その他の予期せぬエラー（例：パーミッション不足など）もログとして出力しつつ再スローするか、適切に処理する
        print(f"変換中に予期せぬエラーが発生しました：{e}")

# --- 使用例 (テスト用) ---
if __name__ == "__main__":
    # テスト用のファイルパスを指定（実際に実行するには Shift-JIS ファイルが必要です）
    try:
        convert_csv_encoding("input_shift_jis.csv", "output_utf8.csv")
    except FileNotFoundError as e:
        print(e)
    except RuntimeError as e:
        print(f"処理エラー：{e}")
```

### 実装のポイント解説

1.  **エンコーディングの指定**:
    *   `open(..., encoding='shift_jis')`: Shift-JIS で読み込みます。
    *   `open(..., encoding='utf-8', newline='')`: UTF-8 で書き出します。**`newline=''`** を指定しているのは、Python の CSV モジュールが Windows/Linux 問わず `\n` (LF) または `\r\n` (CRLF) に正しく対応するためです。特に Mac や Linux から Shift-JIS ファイルを読み込む際、改行コードの違いによる文字化けを防ぐために重要です。

2.  **エラーハンドリングの階層**:
    *   `FileNotFoundError`: パスが間違っている場合やファイルが削除された場合に即座に検知し、ユーザーフレンドリーなメッセージを表示します（`Path.exists()` で事前にチェックしていますが、念のため try-except でも守っています）。
    *   `UnicodeDecodeError`: これが最も重要な部分です。Shift-JIS ファイルの中に「正しく Shift-JIS と解釈できないバイト列」が含まれている場合（例：別のエンコーディングのファイルを読み込もうとしている、または破損している）に発生します。これを単純な例外として処理せず、`RuntimeError` にラップして詳細なエラーメッセージと共に提示することで、ユーザーが「文字化けした」と理解しやすくしています。

3.  **CSV モジュールの利用**:
    *   `csv.reader` と `csv.writer` を使用しているため、改行コードの違いや区切り記号の問題を自動的に処理してくれます。直接バイナリとして読み書きするよりも安全です。
