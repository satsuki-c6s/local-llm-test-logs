## 出力

以下は、Shift-JISでエンコードされたCSVファイルを読み込み、UTF-8に変換して保存する関数です。エラー処理として、ファイルが存在しない場合とデコード失敗の場合を適切に処理しています。

```python
import os
import csv
import codecs


def convert_csv_from_shiftjis_to_utf8(input_path: str, output_path: str) -> None:
    """
    Shift-JISでエンコードされたCSVファイルを読み込み、UTF-8で保存する。

    Args:
        input_path: 入力ファイルのパス（Shift-JISエンコード）
        output_path: 出力ファイルのパス（UTF-8エンコード）

    Raises:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: Shift-JISデコードに失敗した場合
        IOError: ファイルの読み書きに失敗した場合
    """
    # ファイルの存在確認
    if not os.path.isfile(input_path):
        raise FileNotFoundError(f"入力ファイルが見つかりません: {input_path}")

    # 出力ディレクトリの作成（存在しない場合）
    output_dir = os.path.dirname(output_path)
    if output_dir and not os.path.exists(output_dir):
        os.makedirs(output_dir, exist_ok=True)

    try:
        # Shift-JISで読み込み
        with codecs.open(input_path, 'r', encoding='shift-jis') as f_in:
            reader = csv.reader(f_in)
            rows = list(reader)

        # UTF-8で書き込み
        with codecs.open(output_path, 'w', encoding='utf-8', newline='') as f_out:
            writer = csv.writer(f_out)
            writer.writerows(rows)

    except UnicodeDecodeError as e:
        raise UnicodeDecodeError(
            e.encoding,
            e.object,
            e.start,
            e.end,
            f"Shift-JISデコードに失敗しました: {input_path} (詳細: {e.reason})"
        ) from e
    except IOError as e:
        raise IOError(f"ファイルの読み書きに失敗しました: {e}") from e


# 使用例
if __name__ == "__main__":
    input_file = "input_shiftjis.csv"
    output_file = "output_utf8.csv"

    try:
        convert_csv_from_shiftjis_to_utf8(input_file, output_file)
        print(f"変換完了: {input_file} -> {output_file}")
    except FileNotFoundError as e:
        print(f"エラー: {e}")
    except UnicodeDecodeError as e:
        print(f"デコードエラー: {e}")
    except IOError as e:
        print(f"I/Oエラー: {e}")
```

### 主なポイント

1. **ファイル存在確認**: `os.path.isfile()` で入力ファイルの存在を確認し、存在しない場合は `FileNotFoundError` をスローします。

2. **デコードエラー処理**: `codecs.open()` を使用して `shift-jis` エンコーディングで読み込み、`UnicodeDecodeError` をキャッチして詳細なエラーメッセージ付きで再スローします。

3. **出力ディレクトリ作成**: 出力先のディレクトリが存在しない場合は `os.makedirs()` で作成します。

4. **`newline=''` の指定**: CSV書き込み時に `newline=''` を指定することで、Windows環境での余分な改行を防ぎます。

5. **`codecs.open()` の使用**: `shift-jis` エンコーディングを正しく扱うために `codecs.open()` を使用しています（`open()` でも動作しますが、`codecs.open()` の方が明示的です）。
