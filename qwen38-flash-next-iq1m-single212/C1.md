## 最も一般的なPython ORM「SQLAlchemy」の基本的な使い方

もし「PythonでORMを使いたい」という意図であれば、**SQLAlchemy 2.0** の基本的な使い方を以下に示します。

### 1. インストール

```bash
pip install sqlalchemy
```

### 2. 基本的な使い方（SQLAlchemy 2.0 推奨スタイル）

```python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base, sessionmaker

# 1. データベース接続エンジンを作成
engine = create_engine("sqlite:///example.db")

# 2. ベースクラスを定義
Base = declarative_base()

# 3. モデル（テーブル）を定義
class User(Base):
    __tablename__ = 'users'

    id = Column(Integer, primary_key=True)
    name = Column(String(50), nullable=False)
    email = Column(String(100), unique=True)

    def __repr__(self):
        return f"<User(name='{self.name}', email='{self.email}')>"

# 4. テーブルを作成（初回のみ）
Base.metadata.create_all(engine)

# 5. セッション作成
Session = sessionmaker(bind=engine)
session = Session()

# 6. データの追加（Create）
new_user = User(name="田中 太郎", email="tanaka@example.com")
session.add(new_user)
session.commit()

# 7. データの取得（Read）
users = session.query(User).all()
for user in users:
    print(user)

# 8. データの更新（Update）
user = session.query(User).filter_by(name="田中 太郎").first()
if user:
    user.email = "tanaka.new@example.com"
    session.commit()

# 9. データの削除（Delete）
user = session.query(User).filter_by(name="田中 太郎").first()
if user:
    session.delete(user)
    session.commit()

# 10. セッションを閉じる
session.close()
```

## 軽量ORM「Peewee」の例

```bash
pip install peewee
```

```python
from peewee import SqliteDatabase, Model, CharField

db = SqliteDatabase('example.db')

class User(Model):
    name = CharField(max_length=50)
    email = CharField(max_length=100, unique=True)

    class Meta:
        database = db

db.connect()
db.create_tables([User])

# 追加
User.create(name="田中 太郎", email="tanaka@example.com")

# 取得
users = User.select()
for user in users:
    print(user.name, user.email)

db.close()
```

## まとめ

| ライブラリ | 特徴 | 用途 |
|------------|------|------|
| **SQLAlchemy** | 高機能・柔軟 | 大規模プロジェクト |
| **Django ORM** | Django内蔵 | Djangoアプリ開発 |
| **Peewee** | 軽量・シンプル | 小規模プロジェクト |
| **Tortoise ORM** | 非同期対応 | FastAPIなど非同期アプリ |
