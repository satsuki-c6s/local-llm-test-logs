## ✅ 方法1: Sakura CMS の REST API を Python で利用する（推奨）

Sakura CMS は REST API を提供しており、Python の `requests` ライブラリを使って簡単に操作できます。

### 前提条件
- Sakura CMS がインストールされている
- API トークン（またはセッション）を取得できる
- Python 3.x がインストールされている

### インストール
```bash
pip install requests
```

### コード例: 記事一覧の取得

```python
import requests

# Sakura CMS のベースURL
BASE_URL = "https://your-sakura-cms-domain.com"

# API エンドポイント
API_URL = f"{BASE_URL}/api/v1/articles"

# ヘッダーに認証情報を含める（必要に応じて）
# 例: トークン認証の場合
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}

# GET リクエストで記事一覧を取得
response = requests.get(API_URL, headers=headers)

if response.status_code == 200:
    articles = response.json()
    print("記事一覧:")
    for article in articles:
        print(f"  ID: {article['id']}, タイトル: {article['title']}")
else:
    print(f"エラー: {response.status_code}")
    print(response.text)
```

### コード例: 新規記事の作成

```python
import requests

BASE_URL = "https://your-sakura-cms-domain.com"
API_URL = f"{BASE_URL}/api/v1/articles"

headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}

# 新規記事のデータ
new_article = {
    "title": "新しい記事のタイトル",
    "body": "これは記事本文です。",
    "status": "published"  # 公開状態
}

# POST リクエストで記事を作成
response = requests.post(API_URL, json=new_article, headers=headers)

if response.status_code == 201:
    created_article = response.json()
    print(f"記事が作成されました: ID={created_article['id']}")
else:
    print(f"エラー: {response.status_code}")
    print(response.text)
```

## ✅ 方法2: Sakura CMS のデータベースに直接接続する

Sakura CMS は通常 **MySQL** を使用します。Python の `pymysql` ライブラリを使って直接 DB にアクセスできます。

### インストール
```bash
pip install pymysql
```

### コード例: 記事テーブルからデータを取得

```python
import pymysql

# データベース接続情報
db_config = {
    "host": "localhost",
    "user": "sakura_user",
    "password": "sakura_password",
    "database": "sakura_cms",
    "charset": "utf8mb4",
    "cursorclass": pymysql.cursors.DictCursor
}

# 接続
connection = pymysql.connect(**db_config)

try:
    with connection.cursor() as cursor:
        # 記事テーブルからデータを取得
        cursor.execute("SELECT id, title, body FROM articles LIMIT 10")
        articles = cursor.fetchall()
        
        for article in articles:
            print(f"ID: {article['id']}, タイトル: {article['title']}")
finally:
    connection.close()
```

### コード例: 記事の更新

```python
import pymysql

db_config = {
    "host": "localhost",
    "user": "sakura_user",
    "password": "sakura_password",
    "database": "sakura_cms",
    "charset": "utf8mb4",
    "cursorclass": pymysql.cursors.DictCursor
}

connection = pymysql.connect(**db_config)

try:
    with connection.cursor() as cursor:
        # 記事ID=1 のタイトルを更新
        cursor.execute(
            "UPDATE articles SET title = %s WHERE id = %s",
            ("更新されたタイトル", 1)
        )
        connection.commit()
        print("記事が更新されました")
except Exception as e:
    print(f"エラー: {e}")
    connection.rollback()
finally:
    connection.close()
```

## ⚠️ 注意事項

1. **セキュリティ**: DB に直接接続する場合、認証情報を適切に管理してください。環境変数や設定ファイルに保存するのが推奨です。
2. **Sakura CMS のバージョン**: API のエンドポイントやデータ構造はバージョンによって異なる場合があります。必ずお使いのバージョンのドキュメントを確認してください。
3. **ORM の代替案**: 複雑な DB 操作が必要な場合は、**SQLAlchemy** を使うことを検討してください。Sakura CMS のテーブル構造を SQLAlchemy の Model にマッピングすれば、より安全で保守しやすいコードになります。

### SQLAlchemy を使った例（参考）

```python
from sqlalchemy import create_engine, Column, Integer, String, Text
from sqlalchemy.orm import declarative_base

Base = declarative_base()

class Article(Base):
    __tablename__ = 'articles'
    id = Column(Integer, primary_key=True)
    title = Column(String(255))
    body = Column(Text)

engine = create_engine("mysql+pymysql://sakura_user:sakura_password@localhost/sakura_cms")

# 記事を取得
session = engine.begin()
articles = session.query(Article).limit(10).all()
for article in articles:
    print(f"ID: {article.id}, タイトル: {article.title}")
session.close()
```

## まとめ

| 方法 | 利点 | 欠点 |
|------|------|------|
| **REST API** | 安全、Sakura CMS の機能を利用可能 | API トークンが必要 |
| **DB 直接接続** | 高速、柔軟なクエリ可能 | セキュリティリスク、スキーマ変更の影響 |
| **SQLAlchemy** | 安全で保守しやすい | 設定が少し複雑 |

**推奨**: ほとんどのケースでは **REST API を使う方法**が最も安全で簡単です。DB に直接接続する場合は、**SQLAlchemy** を使うことを強くおすすめします。

具体的な使用ケース（例: 記事の自動投稿、データ分析など）があれば、さらに詳細なコード例を提供できます。
