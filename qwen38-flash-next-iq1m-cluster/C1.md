## 1. sakura-orm風の仮のAPIによる基本的な使い方

※これは「もしsakura-ormが次のようなAPIを持つ場合」の例です。  
※実際の `sakura-orm` で動く保証はありません。

```python
from sakura_orm import connect, Model, Field

# データベース接続
db = connect("sqlite:///app.db")

# モデル定義
class User(Model):
    id = Field(int, primary_key=True)
    name = Field(str)
    email = Field(str, unique=True)

# テーブル作成
User.create_table()

# 挿入
User.insert(name="Alice", email="alice@example.com")
User.insert(name="Bob", email="bob@example.com")

# 全件取得
users = User.query.all()
print(users)

# 条件検索
user = User.query.filter(name="Alice").first()
print(user)

# 更新
User.update(id=1, name="Alice-san")

# 削除
User.delete(id=2)
```
