## 出力

以下は、PythonでShift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数です。この関数は、ファイルが存在しない場合や、文字化け（デコード失敗）のエラーを含むように設計されています。

```python
def shift_jis_to_utf8_file(file_path):
    try:
        # ファイルを開く
        with open(file_path, 'r', encoding='shift_jis') as f:
            # ファーの内容を読み込む
            content = f.read()

        # UTF-8で保存
        with open(file_path, 'w', encoding='utf-8') as f:
            f.write(content)

        return True

    except FileNotFoundError:
        print("ファイルがありません。")
        return False

    except UnicodeDecodeError:
        print("文字化けが発生しました。")
        return False
```

### 使用例

```python
result = shift_jis_to_utf8_file('example.csv')

if result:
    print("CSVファイルをUTF-8で保存しました。")
else:
    print("保存に失敗しました。")
```

- ファイル名や拡張子に注意してください。
- ファイルが存在しない場合や、デコード失敗した場合もエラー処理を含んでいます。
