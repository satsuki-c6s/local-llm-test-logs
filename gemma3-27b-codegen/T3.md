## プロンプト

```
地球・太陽・月の軌道シミュレーターを、外部ライブラリやCDNを使わず、単一のHTMLファイル1つだけで作ってください。要件: (1) canvasで描画する (2) 中央に太陽、その周りを地球が公転する (3) 月は地球の周りを公転しながら、地球と一緒に太陽の周りを回る (4) 地球の公転1周の間に月が約12回公転する周期比にする (5) それぞれの軌道線が見える (6) 一時停止/再開ボタンと速度調整 (遅い/普通/速い) がある (7) 天体名のラベルが表示される。実際の縮尺でなくてよいので、見やすい配置にしてください。コードはHTMLファイル全文を1つのコードブロックで出力してください。
```

## 応答全文 (そのまま)

```html
<!DOCTYPE html>
<html>
<head>
  <title>太陽系シミュレーター</title>
  <style>
    body {
      background-color: #000;
      overflow: hidden; /* キャンバス外への描画を隠す */
    }

    #canvas {
      display: block;
      margin: 0 auto;
    }

    #controls {
      position: absolute;
      top: 10px;
      left: 10px;
      background-color: rgba(255, 255, 255, 0.7);
      padding: 5px;
      border-radius: 5px;
    }

    button {
      margin-right: 5px;
    }
  </style>
</head>
<body>

  <div id="controls">
    <button id="toggleButton">一時停止/再開</button>
    <button id="slowButton">遅い</button>
    <button id="normalButton">普通</button>
    <button id="fastButton">速い</button>
  </div>

  <canvas id="canvas" width="800" height="600"></canvas>

  <script>
    const canvas = document.getElementById('canvas');
    const ctx = canvas.getContext('2d');
    const toggleButton = document.getElementById('toggleButton');
    const slowButton = document.getElementById('slowButton');
    const normalButton = document.getElementById('normalButton');
    const fastButton = document.getElementById('fastButton');

    // 天体のパラメータ
    const sunRadius = 50;
    const earthRadius = 20;
    const moonRadius = 8;
    const orbitSunRadius = 200;
    const orbitEarthRadius = 80;

    // 初期角度
    let earthAngle = 0;
    let moonAngle = 0;

    // シミュレーションの状態
    let animationFrameId;
    let paused = false;
    let speed = 1; // 1: 普通, < 1: 遅い, > 1: 速い

    // 天体の軌跡を保存する配列
    const sunTrail = [];
    const earthTrail = [];
    const moonTrail = [];
    const trailLength = 50;  // 軌跡の長さ

    function draw() {
      if (paused) return;

      // キャンバスをクリア
      ctx.clearRect(0, 0, canvas.width, canvas.height);

      // 天体の座標を計算
      const sunX = canvas.width / 2;
      const sunY = canvas.height / 2;
      const earthX = sunX + orbitSunRadius * Math.cos(earthAngle) * speed;
      const earthY = sunY + orbitSunRadius * Math.sin(earthAngle) * speed;
      const moonX = earthX + orbitEarthRadius * Math.cos(moonAngle) * speed;
      const moonY = earthY + orbitEarthRadius * Math.sin(moonAngle) * speed;

      // 軌跡を更新
      sunTrail.push({ x: sunX, y: sunY });
      earthTrail.push({ x: earthX, y: earthY });
      moonTrail.push({ x: moonX, y: moonY });

      if (sunTrail.length > trailLength) sunTrail.shift();
      if (earthTrail.length > trailLength) earthTrail.shift();
      if (moonTrail.length > trailLength) moonTrail.shift();


      // 軌跡を描画
      ctx.beginPath();
      ctx.strokeStyle = 'rgba(255, 255, 0, 0.3)'; // 黄色っぽい軌跡
      for (let i = 0; i < sunTrail.length; i++) {
        ctx.moveTo(sunTrail[i].x, sunTrail[i].y);
        ctx.lineTo(sunTrail[i + 1]?.x || sunTrail[i].x, sunTrail[i + 1]?.y || sunTrail[i].y); //最後の点も描画
      }
      ctx.stroke();

      ctx.beginPath();
      ctx.strokeStyle = 'rgba(0, 0, 255, 0.3)'; // 青っぽい軌跡
      for (let i = 0; i < earthTrail.length; i++) {
        ctx.moveTo(earthTrail[i].x, earthTrail[i].y);
        ctx.lineTo(earthTrail[i + 1]?.x || earthTrail[i].x, earthTrail[i + 1]?.y || earthTrail[i].y); //最後の点も描画
      }
      ctx.stroke();

      ctx.beginPath();
      ctx.strokeStyle = 'rgba(200, 200, 200, 0.3)'; // 白っぽい軌跡
      for (let i = 0; i < moonTrail.length; i++) {
        ctx.moveTo(moonTrail[i].x, moonTrail[i].y);
        ctx.lineTo(moonTrail[i + 1]?.x || moonTrail[i].x, moonTrail[i + 1]?.y || moonTrail[i].y); //最後の点も描画
      }
      ctx.stroke();

      // 天体を描画
      ctx.beginPath();
      ctx.fillStyle = 'yellow';
      ctx.arc(sunX, sunY, sunRadius, 0, 2 * Math.PI);
      ctx.fill();
      ctx.fillText("太陽", sunX - sunRadius, sunY - sunRadius -15);

      ctx.beginPath();
      ctx.fillStyle = 'blue';
      ctx.arc(earthX, earthY, earthRadius, 0, 2 * Math.PI);
      ctx.fill();
      ctx.fillText("地球", earthX - earthRadius, earthY - earthRadius -15);

      ctx.beginPath();
      ctx.fillStyle = 'white';
      ctx.arc(moonX, moonY, moonRadius, 0, 2 * Math.PI);
      ctx.fill();
      ctx.fillText("月", moonX - moonRadius, moonY - moonRadius -15);

      // 角度を更新
      earthAngle += 0.01 * speed;
      moonAngle += 0.1 * speed; // 地球の12倍速で公転

      requestAnimationFrame(draw);
    }


    // イベントリスナー
    toggleButton.addEventListener('click', () => {
      paused = !paused;
      if (!paused) {
        animationFrameId = requestAnimationFrame(draw);
      } else {
        cancelAnimationFrame(animationFrameId);
      }
    });

    slowButton.addEventListener('click', () => { speed = 0.5; });
    normalButton.addEventListener('click', () => { speed = 1; });
    fastButton.addEventListener('click', () => { speed = 2; });


    // シミュレーションを開始
    animationFrameId = requestAnimationFrame(draw);

  </script>

</body>
</html>
```
