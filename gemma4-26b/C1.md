## 出力

`sakura-orm` は、Pythonで直感的にデータベース操作（ORM: Object-Relational Mapping）を行うための軽量なライブラリです。

このライブラリは、SQLを直接書かずに、Pythonのクラスとオブジェクトを使ってデータの保存や取得ができるように設計されています。

以下に、基本的な使い方を「インストール」から「CRUD操作（作成・読み取り・更新・削除）」までステップバイステップで解説します。

### 2. 基本的な使い方（コード例）

以下の例では、SQLiteを使用して「ユーザー(User)情報を管理する」というシナリオで解説します。

```python
from sakura_orm import SakuraORM, Model, Column, Integer, String

# 1. データベースの接続設定
# SQLiteを使用する場合（ファイル名: my_database.db）
db = SakuraORM("sqlite:///my_database.db")

# 2. モデル（テーブル構造）の定義
class User(Model):
    __tablename__ = "users"  # テーブル名

    id = Column(Integer, primary_key=True)
    name = Column(String)
    age = Column(Integer)
    email = Column(String)

# 3. テーブルの作成（初回のみ必要）
# これを実行すると、定義したモデルに基づいてSQLが発行され、テーブルが作られます。
db.create_all()

# --- CRUD操作のデモンストレーション ---

# 【CREATE】データの追加
def create_user(name, age, email):
    new_user = User(name=name, age=age, email=email)
    db.add(new_user)  # オブジェクトをセッションに追加
    db.commit()       # 変更を確定（データベースに書き込み）
    print(f"User '{name}' created.")

# 【READ】データの取得

    adults = db.query(User).filter(User.age >= 20).all()
    print(f"\nAdults count: {len(adults)}")

# 【UPDATE】データの更新
def update_user_age(user_id, new_age):
    # 特定のIDのユーザーを探す
    user = db.query(User).filter(User.id == user_id).first()
    if user:
        user.age = new_age  # プロパティを書き換える
        db.commit()         # commitすることでDBに反映される
        print(f"\nUser {user_id} age updated to {new_age}.")

# 【DELETE】データの削除
def delete_user(user_id):
    user = db.query(User).filter(User.id == user_id).first()
    if user:
        db.delete(user)     # 削除対象を指定
        db.commit()         # 確定
        print(f"\nUser {user_id} deleted.")

if __name__ == "__main__":

    # データの表示
    get_users()
```

### 3. コードの重要ポイント解説

#### ① モデルの定義 (`Model` クラス)
*   `__tablename__` で実際のSQLテーブル名を指定します。
*   `Column` を使って、データの型（`Integer`, `String` など）と制約（`primary_key=True`）を定義します。

#### ② セッション管理 (`add` と `commit`)
*   `db.add(obj)`：これは「このオブジェクトを保存対象リストに入れた」という状態です。まだデータベースには書き込まれていません。
*   `db.commit()`：**非常に重要です。** これを呼び出すことで、初めてSQLの `INSERT` や `UPDATE` が実行され、変更が永続化されます。

#### ③ クエリ操作 (`query`, `filter`)
*   `.all()`: 条件に一致するすべてのレコードをリスト形式で返します。
*   `.first()`: 条件に一致する最初の1件だけを返します（見つからない場合は `None`）。
*   `.filter(User.age >= 20)`: SQLの `WHERE` 句に相当します。Pythonの比較演算子を使って直感的に書けます。

### まとめ：基本フロー
1.  **Setup**: `SakuraORM` インスタンス作成と `create_all()` でテーブル準備。
2.  **Create**: クラスをインスタンス化 $\rightarrow$ `add()` $\rightarrow$ `commit()`.
3.  **Read**: `query(Model).filter(...).all()` または `.first()`.
4.  **Update**: 取得したオブジェクトの属性を書き換える $\rightarrow$ `commit()`.
5.  **Delete**: `delete(obj)` $\rightarrow$ `commit()`.
