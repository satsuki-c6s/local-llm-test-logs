Pythonで、Shift-JISのCSVファイルを読み込み、UTF-8に変換して保存する関数を作成しました。

エラーハンドリングとして、「ファイルの不在（FileNotFoundError）」および「文字コードの不一致によるデコード失敗（UnicodeDecodeError）」を捕捉するようにしています。

```python
import os

def convert_sjis_to_utf8(input_file, output_file):
    """
    Shift-JISのCSVファイルを読み込み、UTF-8で保存し直す関数。
    
    Args:
        input_file (str): 入力ファイルパス (Shift-JIS)
        output_file (str): 出力ファイルパス (UTF-8)
    """
    try:
        # 1. ファイルの読み込み（Shift-JISを指定）
        # errors='strict' にすることで、文字化け（デコード失敗）時に例外を発生させる
        with open(input_file, mode='r', encoding='shift_jis', errors='strict') as f:
            content = f.read()

        # 2. ファイルの書き出し（UTF-8を指定）
        with open(output_file, mode='w', encoding='utf-8', newline='') as f:
            f.write(content)
        
        print(f"成功: '{input_file}' を '{output_file}' に変換しました。")

    except FileNotFoundError:
        print(f"エラー: ファイル '{input_file}' が見つかりません。パスを確認してください。")
    
    except UnicodeDecodeError:
        print(f"エラー: '{input_file}' のデコードに失敗しました。Shift-JISではない可能性があります。")
    
    except Exception as e:
        print(f"予期せぬエラーが発生しました: {e}")

# --- テスト用コード ---
if __name__ == "__main__":
    # テスト用のファイル作成 (Shift-JIS)
    test_input = "sample_sjis.csv"
    test_output = "sample_utf8.csv"
    
    try:
        with open(test_input, mode='w', encoding='shift_jis') as f:
            f.write("ID,名前,備考\n1,田中太郎,テストデータ")
        print(f"テスト用ファイル '{test_input}' を作成しました。")
    except Exception as e:
        print(f"テストファイル作成失敗: {e}")

    # 関数を実行
    print("\n--- 変換処理開始 ---")
    convert_sjis_to_utf8(test_input, test_output)
    
    # 存在しないファイルを指定してエラー確認
    print("\n--- エラーテスト (ファイル不在) ---")
    convert_sjis_to_utf8("non_existent.csv", "error_out.csv")

    # 文字化け（UTF-8のファイルをSJISとして読み込もうとする）のエラー確認
    print("\n--- エラーテスト (デコード失敗) ---")
    # 既に作成したUTF-8ファイルを、あえてSJISとして読み込ませる
    convert_sjis_to_utf8(test_output, "error_decode.csv")
```

### コードのポイント解説

1.  **`errors='strict'`**:
    *   `open`関数の引数に指定しています。これがないと、Pythonは読み込めない文字を「?」などに置き換えて無理やり処理を続行してしまいます（これが文字化けの原因になります）。`strict`にすることで、不正な文字があった瞬間に `UnicodeDecodeError` を発生させ、エラー処理へ飛ばすことができます。
2.  **例外処理 (`try-except`)**:
    *   `FileNotFoundError`: 指定したパスにファイルがない場合にキャッチします。
    *   `UnicodeDecodeError`: ファイルの中身がShift-JISではない（例えば既にUTF-8である）場合に、デコード失敗としてキャッチします。
    *   `Exception`: それ以外の予期せぬエラー（権限不足など）をキャッチします。
3.  **`newline=''`**:
    *   CSVファイルを扱う際の作法として、書き出し時に改行コードが二重にならないよう指定しています。

### 注意点
もし、ファイルサイズが非常に大きい（数GBなど）場合は、一度に `f.read()` でメモリに読み込むとメモリ不足になる可能性があります。その場合は、1行ずつループで処理する方式に変更することをお勧めします。
