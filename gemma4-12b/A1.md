## 出力

Pythonで「Shift-JIS（またはCP932）」のCSVファイルを読み込み、UTF-8に変換して保存する関数を作成します。

実務上、日本のWindows環境で作成されたShift-JISファイルは正確には**`cp932`**というエンコーディングであることが多いため、そちらを優先的に指定するのが一般的です。

### サンプルコード

```python
import csv
import os
import logging

# ログの設定（エラー内容をコンソールに表示）
logging.basicConfig(level=logging.INFO, format='%(levelname)s: %(message)s')

def convert_sjis_to_utf8(input_path, output_path):
    """
    Shift-JIS (cp932) のCSVファイルを読み込み、UTF-8で保存し直す。
    
    Args:
        input_path (str): 入力ファイルのパス
        output_path (str): 出力ファイルのパス
    """
    # 1. ファイルの存在確認
    if not os.path.exists(input_path):
        logging.error(f"ファイルが見つかりません: {input_path}")
        return False

    try:
        # 2. Shift-JIS (cp932) で読み込み
        # 日本語Windows環境のShift-JISはcp932として扱うのが安全です
        with open(input_path, mode='r', encoding='cp932', errors='replace') as f_in:
            content = f.read()
            # 読み込みに失敗した文字は「�」に置き換わる（errors='replace'）
            # もし厳密にエラーを検知したい場合は 'strict' に変更してください。

        # 3. UTF-8で書き出し
        with open(output_path, mode='w', encoding='utf-8', newline='') as f_out:
            f_out.write(content)
        
        logging.info(f"変換成功: {input_path} -> {output_path}")
        return True

    except UnicodeDecodeError as e:
        logging.error(f"文字化け（デコード失敗）が発生しました: {e}")
        return False
    except Exception as e:
        logging.error(f"予期せぬエラーが発生しました: {e}")
        return False

# --- 実行例 ---
if __name__ == "__main__":
    input_file = "sample_sjis.csv"
    output_file = "sample_utf8.csv"

    success = convert_sjis_to_utf8(input_file, output_file)
    if success:
        print("処理が正常に完了しました。")
    else:
        print("処理に失敗しました。")
```

### 解説とポイント

#### 1. `cp932` を使用する理由
Pythonの `shift_jis` エンコーディングよりも、Microsoft拡張が含まれている `cp932` を使う方が、Windows環境特有の機種依存文字（丸数字や特殊記号など）を正しく処理できるため推奨されます。

#### 2. エラー処理の仕組み
*   **ファイル不在のチェック**: `os.path.exists()` を使い、ファイルがない場合にプログラムがクラッシュする前にエラーメッセージを表示するようにしています。
*   **デコード失敗（文字化け）への対応**: 
    *   `errors='replace'` を指定することで、万が一Shift-JISとして認識できない文字が含まれていても、その部分を「�」に置き換えて処理を続行します。
    *   もし「少しのノイズも許容したくない（エラーなら止めてほしい）」という場合は、ここを `errors='strict'` に変更してください。

#### 3. CSV構造を維持する
このコードでは単純なテキストとして読み書きしていますが、CSVの改行コードなどを保持したまま変換します。もし「特定の列だけ抽出したい」などの加工が必要な場合は、`csv` モジュールを使って以下のように記述を変更してください。

```python
# 加工が必要な場合の書き方例
import csv

with open(input_path, mode='r', encoding='cp932') as f_in:
    reader = csv.reader(f_in)
    data = list(reader)

with open(output_path, mode='w', encoding='utf-8', newline='') as f_out:
    writer = csv.writer(f_out)
    writer.writerows(data)
```
