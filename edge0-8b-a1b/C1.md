## 2. 基本機能

### 2.1 モデル定義（テーブルの作成）

```python
from sakura_orm import Model, Field

class User(Model):
    id = Field(primary_key=True)
    name = Field()
    email = Field()
    created_at = Field(auto_insert=True)

    class Meta:
        db_name = "myapp_db"
        table_name = "users"
```

### 2.3 ネストクエリ（JOIN）

```python
# ��数テーブルを結合する場合
class Order(Model):
    order_id = Field(primary_key=True)
    user_id = Field()
    product_name = Field()

class Product(Model):
    product_id = Field(primary_key=True)
    name = Field()

# クーリーキングを使用して2つのテーブルを結合
user_orders = (
    User.query()
    .join(Order.user_id == User.id)
    .select(User.name, Order.product_name)
    .all()
)

for u_order in user_orders:
    print(f"{u_order.name} → {u_order.product_name}")
```

### 2.5 トラクションとパントリカリ（分集）

```python
# 分集（パントリカリ）
class Group(Model):
    group_id = Field(primary_key=True)
    members_count = Field()

class Member(Model):
    member_id = Field(primary_key=True)
    name = Field()
    group_id = Field()

# 使用可能なメンバーをグループごとに分集
group_members = (
    Member.query()
    .partition(Member.group_id)
    .select(Member.name, Group.group_id)
    .distinct(Member.group_id)
    .all()
)
```

## 3. 完全な使用例

```python
from sakura_orm import Model, Field

class Article(Model):
    id = Field(primary_key=True)
    title = Field()
    author = Field()
    published_date = Field()
    views = Field(default=0)

    class Meta:
        db_name = "myapp_db"
        table_name = "articles"

# 1. テーブル作成（auto_migrate）
# 通常、sakura-ormは自動マイルタイムマイニング機能を提供し、
# テーブルを自動的に作成・変更します。

# 2. データ管理
articles = [Article(title="Hello World", author="John Doe", published_date="2024-01-01")]
articles[0].save()
articles.append(Article(title="World of Sakura", author="Jane Smith", published_date="2024-01-02"))

# 3. クールな書き込み
article = Article(title="New Post", author="Alice", published_date="2024-01-03")
article.save()

# 4. 検索
articles = Article.query().filter(Article.author == "John Doe").all()

# 5. 统计
stats = Article.query().aggregate(
    total_count=Field.__class__.query().count(),
    avg_views=Field.__class__.query().avg("views"),
    max_views=Field.__class__.query().max("views"),
    min_views=Field.__class__.query().min("views"),
)

# 6. 条件付き更新
updated_articles = Article.query().filter(Article.title == "New Post").update(views=Field.views + 1)

# 7. 削除
deleted = Article.query().filter(Article.title == "New Post").delete()
```

## 4. 重要なポイント

| 項目 | 説明 |
|------|------|
| **`__class__.query()`** | 各クラスからクエリオジェクトを生成する |
| **`Field`** | カラムを定義するためのフ��ールドクラス |
| **`Model`** | テーブルの表記に使う |
| **`Field.auto_insert`** | 自動��入機能を有効化する |
| **`Field.default`** | デンプグ値を設定する |
| **`Field.unique`** | 唯一制約を設定する |
| **`Field.foreign_key`** | 外键を設定する |

## 5. 注意事項

- `sakura-orm` は **SQLベース** の ORMであり、`sakura` などのデータベースドライブと組み合わせて使用します。
- 最初の使用時には、`sakura` や `sakura_orm` をインストールする必要があります。
- テーブルのスキーマは `sakura` を通じて自動的に管理されます。

```python
# 確認：接続
import sakura
from sakura_orm import Model, Field

# 確認接続
connection = sakura.connect(database="mydb", host="localhost", port=5432)
```
