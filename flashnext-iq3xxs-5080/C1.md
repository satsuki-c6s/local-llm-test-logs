### ✅ 推奨：一般的なPython ORMの基本的な使い方（SQLAlchemy 2.0 を例に）

もし「PythonでORMを使う基本的なパターン」を知りたい場合は、最も広く使われている **SQLAlchemy 2.0** を例に、基本的な使い方を示します。

#### 1. インストール
```bash
pip install sqlalchemy
```

#### 2. 基本的な使い方（モデル定義、CRUD操作）

```python
from sqlalchemy import create_engine, Column, Integer, String, select
from sqlalchemy.orm import declarative_base, sessionmaker

# 1. モデルの基底クラス
Base = declarative_base()

# 2. モデル定義（テーブルに対応）
class User(Base):
    __tablename__ = 'users'
    
    id = Column(Integer, primary_key=True, autoincrement=True)
    name = Column(String(50), nullable=False)
    email = Column(String(100), unique=True)

    def __repr__(self):
        return f"<User(id={self.id}, name='{self.name}', email='{self.email}')>"

# 3. エンジンとセッションの作成
engine = create_engine('sqlite:///example.db')  # SQLiteを例に
Base.metadata.create_all(engine)  # テーブル作成

Session = sessionmaker(bind=engine)
session = Session()

# 4. Create（作成）
new_user = User(name="山田太郎", email="taro@example.com")
session.add(new_user)
session.commit()
print(f"作成完了: {new_user}")

# 5. Read（読み取り）
# 全件取得
users = session.scalars(select(User)).all()
print("全ユーザー:", users)

# 条件付き取得
user = session.scalars(
    select(User).where(User.name == "山田太郎")
).first()
print("検索結果:", user)

# 6. Update（更新）
if user:
    user.email = "taro.new@example.com"
    session.commit()
    print("更新完了")

# 7. Delete（削除）
if user:
    session.delete(user)
    session.commit()
    print("削除完了")

# セッションクローズ
session.close()
```
