```python
import os
import csv


def shiftjis_to_utf8(input_path: str, output_path: str) -> None:
    """
    Shift-JIS エンコードのCSVファイルを読み込み、UTF-8で保存し直す。

    Args:
        input_path:  入力ファイルのパス (Shift-JIS)
        output_path: 出力ファイルのパス (UTF-8)

    Raises:
        FileNotFoundError: 入力ファイルが存在しない場合
        UnicodeDecodeError: Shift-JISとしてデコードに失敗した場合 (文字化け)
        ValueError: 入力パスと出力パスが同じ場合
    """
    # 入力と出力が同じファイルでないかチェック
    if os.path.abspath(input_path) == os.path.abspath(output_path):
        raise ValueError("入力パスと出力パスは異なる必要があります。")

    # ファイルの存在チェック (明示的なエラーメッセージのため)
    if not os.path.exists(input_path):
        raise FileNotFoundError(f"入力ファイルが見つかりません: {input_path}")

    # Shift-JISで読み込む。デコード失敗時はUnicodeDecodeErrorが発生する。
    with open(input_path, "r", encoding="shift_jis", newline="") as f_in:
        reader = csv.reader(f_in)
        rows = list(reader)

    # UTF-8で書き出す。
    # newline="" を指定することで、CSVモジュールが改行を正しく処理できる。
    with open(output_path, "w", encoding="utf-8", newline="") as f_out:
        writer = csv.writer(f_out)
        writer.writerows(rows)

    print(f"{output_path} に保存しました ({len(rows)} 行)")


# ----------------------------------------------------------------------
# 使用例
# ----------------------------------------------------------------------
if __name__ == "__main__":
    input_file = "input.csv"
    output_file = "output_utf8.csv"

    try:
        shiftjis_to_utf8(input_file, output_file)
    except FileNotFoundError as e:
        print(f"[エラー] ファイルが見つかりません: {e}")
    except UnicodeDecodeError as e:
        print(f"[エラー] 文字コードのデコードに失敗しました (文字化けの可能性があります): {e}")
    except ValueError as e:
        print(f"[エラー] {e}")
```

## ポイントの説明

### 1. エンコードの指定
- **読み込み**: `encoding="shift_jis"` でShift-JISとしてデコード
- **書き込み**: `encoding="utf-8"` でUTF-8としてエンコード

### 2. `newline=""` の指定
CSVモジュールを使用する場合、`open()` の `newline` 引数に `""` を指定することが推奨されています（[Python公式ドキュメント](https://docs.python.org/3/library/csv.html)）。これにより、Windows環境でも改行コードが正しく処理されます。

### 3. エラー処理の分け方

| エラー | 発生状況 | 捕捉する例外 |
|--------|---------|-------------|
| ファイルが存在しない | パス誤り・未作成 | `FileNotFoundError` |
| 文字化け（デコード失敗） | Shift-JIS以外のファイルをSJISで開こうとした | `UnicodeDecodeError` |
| 入力=出力 | 論理的な誤使用 | `ValueError` |

## 補足：文字化けの検出について

`UnicodeDecodeError` は「Shift-JISとして不正なバイト列が含まれている」場合に発生します。ただし、**完全に有効なShift-JISでも、内容が日本語ではない**場合はエラーにならずに読み込まれます。

より厳密に「日本語のCSVである」と保証したい場合は、以下のような事前チェックも有効です：

```python
def is_valid_shiftjis(data: bytes) -> bool:
    """バイト列がShift-JISとして有効かチェック"""
    try:
        data.decode("shift_jis")
        return True
    except UnicodeDecodeError:
        return False


# 使用例
with open(input_file, "rb") as f:
    raw_data = f.read()

if not is_valid_shiftjis(raw_data):
    print("Shift-JISとして不正なバイト列が含まれています")
```

必要に応じて、この事前チェックを関数に組み込むこともできます。
