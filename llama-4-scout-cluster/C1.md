## 出力 (本文そのまま)

sakura-ormはPythonのORM（Object-Relational Mapping）ライブラリです。以下に基本的な使い方を示します。

### インストール

まず、sakura-ormをインストールする必要があります。pipを使用してインストールできます。

```bash
pip install sakura-orm
```

### データベースの設定

sakura-ormを使用するには、データベースの設定が必要です。ここではSQLiteを例にします。

### モデルの定義

sakura-ormでは、モデルを定義してデータベースのテーブルを操作します。以下は簡単なUserモデルの例です。

```python
from sakura_orm import Database

# データベースの設定
db = Database('sqlite:///example.db')

# モデルの定義
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    email = db.Column(db.String(100), unique=True, nullable=False)

    def __repr__(self):
        return f"User('{self.name}', '{self.email}')"
```

### テーブルの作成

モデルを定義したら、テーブルを作成する必要があります。

```python
with db.connect():
    db.create_tables()
```

### データの挿入

データの挿入は以下のように行います。

```python
with db.connect():
    user = User(name='John Doe', email='john@example.com')
    db.session.add(user)
    db.session.commit()
```

### データの取得

データを取得するには、以下のようにします。

```python
with db.connect():
    users = User.select()
    for user in users:
        print(user)
```

### データの更新

データの更新は以下のように行います。

```python
with db.connect():
    user = User.get(User.id == 1)
    user.name = 'Jane Doe'
    db.session.commit()
```

### データの削除

データの削除は以下のように行います。

```python
with db.connect():
    user = User.get(User.id == 1)
    db.session.delete(user)
    db.session.commit()
```

このように、sakura-ormを使用することで、Pythonのオブジェクトをデータベースのテーブルに簡単にマッピングすることができます。

### 全体のコード

以下に全体のコードを示します。

```python
from sakura_orm import Database

# データベースの設定
db = Database('sqlite:///example.db')

# モデルの定義
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    email = db.Column(db.String(100), unique=True, nullable=False)

    def __repr__(self):
        return f"User('{self.name}', '{self.email}')"

def main():
    with db.connect():
        db.create_tables()

        # データの挿入
        user = User(name='John Doe', email='john@example.com')
        db.session.add(user)
        db.session.commit()

        # データの取得
        users = User.select()
        for user in users:
            print(user)

        # データの更新
        user = User.get(User.id == 1)
        user.name = 'Jane Doe'
        db.session.commit()

        # データの削除
        user = User.get(User.id == 1)
        db.session.delete(user)
        db.session.commit()

if __name__ == '__main__':
    main()
```
