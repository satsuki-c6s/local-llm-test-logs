**Shift-JISのCSVファイルをUTF-8で保存し直す関数**
==============================================

以下は、PythonでShift-JISのCSVファイルを読み込んでUTF-8で保存し直す関数です。

```python
import csv

def convert_csv_encoding(input_file_path, output_file_path):
    """
    Shift-JISのCSVファイルを読み込んでUTF-8で保存し直す。

    Args:
        input_file_path (str): 入力ファイルパス
        output_file_path (str): 出力ファイルパス

    Returns:
        None
    """

    try:
        # Shift-JISでファイルを読み込み
        with open(input_file_path, 'r', encoding='shift-jis') as input_file:
            reader = csv.reader(input_file)
            data = list(reader)

        # UTF-8でファイルを保存し直す
        with open(output_file_path, 'w', newline='', encoding='utf-8') as output_file:
            writer = csv.writer(output_file)
            writer.writerows(data)

        print(f"ファイルのエンコード変換に成功しました: {input_file_path} -> {output_file_path}")

    except FileNotFoundError:
        print(f"エラー: ファイルが存在しません - {input_file_path}")
    except UnicodeDecodeError:
        print(f"エラー: 文字化けによりデコードに失敗しました - {input_file_path}")
    except Exception as e:
        print(f"エラー: {str(e)}")

# 例の使用方法
input_file_path = 'input_shift_jis.csv'
output_file_path = 'output_utf8.csv'
convert_csv_encoding(input_file_path, output_file_path)
```

**エラー処理について**

*   `FileNotFoundError`: ファイルが存在しない場合に発生します。
*   `UnicodeDecodeError`: 文字化けによりデコードに失敗した場合に発生します。
*   その他の例外: 上記以外のエラーが発生した場合にキャッチします。

この関数を使用すると、簡単にShift-JISのCSVファイルをUTF-8に変換できます。エラー処理も含まれているため、安心して使用できます。
