# sakura-orm の基本的な使い方

`sakura-orm` は Python の ORM（オブジェクトリレーショナル・マッパー）ライブラリです。以下に基本的な使い方を示します。

## インストール

```bash
pip install sakura-orm
```

## 基本的な使い方

### 1. モデルの定義とクエリ

```python
from sakura import User, Article, Comment, Tag, Tagging

# ユーザーの取得
users = User.query.all()
for user in users:
    print(user.name)

# 記事の取得
articles = Article.query.all()
for article in articles:
    print(article.title)
    print(article.body)
    print(article.user)
```

### 2. 条件付きクエリ

```python
# 条件付きでユーザーを取得
users = User.query.filter(User.name == '太郎').all()

# 記事の条件付き取得
articles = Article.query.filter(Article.title == '記事タイトル').all()
```

### 3. 新規レコードの作成

```python
# 新規ユーザーの作成
user = User(name='太郎', email='taro@example.com')
user.save()

# 新規記事の作成
article = Article(title='記事タイトル', body='記事本文', user=user)
article.save()
```

### 4. 更新と削除

```python
# 更新
user.name = '新太郎'
user.save()

# 削除
user.delete()
article.delete()
```

### 5. コメントとタグ

```python
# コメントの作成
comment = Comment(body='コメント本文', user=user, article=article)
comment.save()

# タグの作成
tag = Tag(name='タグ名')
tag.save()

# タグ付け
tagging = Tagging(tag=tag, article=article)
tagging.save()
```
