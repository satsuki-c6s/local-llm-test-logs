### 1. もし「SQLAlchemy」などの一般的なORMの使い方を知りたい場合
Pythonで最も使われているORMである `SQLAlchemy` の基本的な使い方は以下の通りです。

```python
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.ext.declarative import declarative_base
from sqlalchemy.orm import sessionmaker

# 1. データベース接続の設定 (SQLiteを使用)
engine = create_engine('sqlite:///example.db', echo=True)
Base = declarative_base()

# 2. モデル（テーブル）の定義
class User(Base):
    __tablename__ = 'users'
    
    id = Column(Integer, primary_key=True)
    name = Column(String)
    age = Column(Integer)

# テーブルの作成
Base.metadata.create_all(engine)

# 3. セッションの作成
Session = sessionmaker(bind=engine)
session = Session()

# 4. データの挿入 (Create)
new_user = User(name="Sakura", age=20)
session.add(new_user)
session.commit()

# 5. データの取得 (Read)
user = session.query(User).filter_by(name="Sakura").first()
print(f"Found: {user.name}, Age: {user.age}")

# 6. データの更新 (Update)
user.age = 21
session.commit()

# 7. データの削除 (Delete)
# session.delete(user)
# session.commit()

session.close()
```
