## 出力

Pythonで、Shift-JISのCSVファイルを読み込み、UTF-8で保存し直す関数を作成しました。

エラー処理として、以下の2点を組み込んでいます。
1. **`FileNotFoundError`**: ファイルが存在しない場合。
2. **`UnicodeDecodeError`**: Shift-JISとして正しく読み込めなかった場合（文字化け・デコード失敗）。

### サンプルコード

```python
import csv
import os

def convert_sjis_to_utf8(input_file, output_file):
    """
    Shift-JISのCSVファイルを読み込み、UTF-8で保存し直す。
    
    Args:
        input_file (str): 入力ファイルのパス
        output_file (str): 出力ファイルのパス
    """
    try:
        # 1. ファイルの存在確認
        if not os.path.exists(input_file):
            raise FileNotFoundError(f"エラー: ファイル '{input_file}' が見つかりません。")

        # 2. Shift-JISで読み込み
        # errors='strict' にすることで、デコード失敗時にUnicodeDecodeErrorを発生させる
        with open(input_file, mode='r', encoding='shift_jis', errors='strict', newline='') as f_in:
            reader = csv.reader(f_in)
            data = list(reader)

        # 3. UTF-8で書き出し
        with open(output_file, mode='w', encoding='utf-8', newline='') as f_out:
            writer = csv.writer(f_out)
            writer.writerows(data)

        print(f"成功: '{input_file}' を '{output_file}' に変換しました。")

    except FileNotFoundError as e:
        print(e)
    except UnicodeDecodeError:
        print(f"エラー: '{input_file}' のデコードに失敗しました。Shift-JISではない可能性があります（文字化け）。")
    except PermissionError:
        print(f"エラー: ファイルへのアクセス権限がありません。")
    except Exception as e:
        print(f"予期せぬエラーが発生しました: {e}")

# --- テスト用コード ---
if __name__ == "__main__":
    # テスト用のファイル名
    input_csv = "test_sjis.csv"
    output_csv = "test_utf8.csv"

    # テスト用ファイルの作成 (Shift-JIS)
    try:
        with open(input_csv, mode='w', encoding='shift_jis', newline='') as f:
            writer = csv.writer(f)
            writer.writerow(["名前", "年齢", "備考"])
            writer.writerow(["田中太郎", "25", "こんにちは"])
        
        # 変換実行
        convert_sjis_to_utf8(input_csv, output_csv)

        # 存在しないファイルでのテスト
        convert_sjis_to_utf8("non_existent.csv", "error.csv")

        # 文字化け（UTF-8のファイルをShift-JISとして読み込もうとする）でのテスト
        with open("utf8_file.csv", mode='w', encoding='utf-8') as f:
            f.write("テストデータ")
        convert_sjis_to_utf8("utf8_file.csv", "error_decode.csv")

    finally:
        # テスト用ファイルの掃除（必要に応じて）
        for f in [input_csv, output_csv, "utf8_file.csv"]:
            if os.path.exists(f):
                os.remove(f)
```

### 解説

1.  **`encoding='shift_jis'` と `errors='strict'`**:
    *   `open`関数の引数に `errors='strict'` を指定しています（デフォルト設定です）。これにより、Shift-JISとして解釈できないバイト列（例えば、すでにUTF-8になっているファイルや、特殊な記号が含まれる場合）に遭遇した際、即座に `UnicodeDecodeError` を発生させ、`except` ブロックへ飛ばすことができます。
2.  **`os.path.exists()`**:
    *   ファイルを開く前に、そもそもファイルが存在するかどうかをチェックしています。
3.  **`csv.reader` / `csv.writer`**:
    *   単なるテキストとして読み書きするのではなく、CSVモジュールを使うことで、カンマ区切りやダブルクォーテーションの扱いを適切に行います。
4.  **エラーハンドリングの順序**:
    *   `FileNotFoundError` や `UnicodeDecodeError` などの具体的なエラーを先にキャッチし、最後に `Exception` でその他の予期せぬエラー（書き込み権限不足など）を拾うようにしています。

### 注意点
もし、Shift-JISの中でも拡張版である **`cp932`**（Windowsでよく使われる「①」や「～」などの機種依存文字を含む形式）を扱う必要がある場合は、`encoding='shift_jis'` の部分を `encoding='cp932'` に書き換えてください。実務上は `cp932` を使う方がエラーが起きにくいため推奨されます。
