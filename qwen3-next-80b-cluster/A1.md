## 出力 (本文そのまま)

以下は、Shift-JISエンコードのCSVファイルを読み込んでUTF-8で保存し直すPython関数です。  
存在しないファイルや文字化け（デコード失敗）のエラー処理を含んでいます。

```python
import csv
import os

def convert_csv_encoding(input_path, output_path):
    """
    Shift-JISエンコードのCSVファイルを読み込み、UTF-8で保存し直す関数。

    Parameters:
        input_path (str): 入力ファイルのパス（Shift-JISエンコード）
        output_path (str): 出力ファイルのパス（UTF-8エンコード）

    Returns:
        bool: 成功したらTrue、失敗したらFalse
    """
    try:
        # 入力ファイルが存在するか確認
        if not os.path.exists(input_path):
            print(f"エラー: 入力ファイルが存在しません。パス: {input_path}")
            return False

        # Shift-JISでファイルを読み込む
        with open(input_path, 'r', encoding='shift-jis') as f_in:
            # CSVリーダーを作成
            reader = csv.reader(f_in)
            rows = list(reader)  # 全行をメモリに読み込む

        # UTF-8で出力ファイルに書き込む
        with open(output_path, 'w', encoding='utf-8', newline='') as f_out:
            writer = csv.writer(f_out)
            writer.writerows(rows)

        print(f"成功: {input_path} を UTF-8 で {output_path} に保存しました。")
        return True

    except UnicodeDecodeError as e:
        print(f"エラー: ファイルのデコードに失敗しました。Shift-JISでない可能性があります。詳細: {e}")
        return False

    except PermissionError:
        print(f"エラー: ファイルの読み書き権限がありません。入力: {input_path}, 出力: {output_path}")
        return False

    except FileNotFoundError:
        # これは上記のos.path.existsで既にチェックしているが、念のため
        print(f"エラー: 入力ファイルが見つかりません。パス: {input_path}")
        return False

    except OSError as e:
        print(f"エラー: ファイル操作中にOSエラーが発生しました。詳細: {e}")
        return False

    except Exception as e:
        print(f"予期しないエラーが発生しました: {e}")
        return False
```

### 使用例

```python
# 使用例
if __name__ == "__main__":
    input_csv = "input_shiftjis.csv"
    output_csv = "output_utf8.csv"

    success = convert_csv_encoding(input_csv, output_csv)
    if success:
        print("変換が完了しました。")
    else:
        print("変換に失敗しました。")
```

### 特徴

- ✅ **Shift-JISの読み込み**：`encoding='shift-jis'` で明示的に指定
- ✅ **UTF-8での保存**：`encoding='utf-8'` で出力、`newline=''` でCSVの改行問題を回避
- ✅ **ファイル存在チェック**：`os.path.exists()` で事前チェック
- ✅ **文字化け（UnicodeDecodeError）の処理**：Shift-JIS以外のエンコードで読み込もうとした場合に明示的にエラーを通知
- ✅ **その他のエラー処理**：権限エラー、OSエラー、その他の例外もキャッチ
- ✅ **返り値で成功/失敗を返す**：呼び出し元で処理結果を確認可能

### 注意点

- CSVファイルの**改行コード**（CRLF/LF）は、`newline=''` を指定することで、`csv`モジュールが適切に処理します。
- 出力先のディレクトリが存在しない場合は、`OSError` で捕捉されます。必要に応じて `os.makedirs(os.path.dirname(output_path), exist_ok=True)` でディレクトリ作成を追加することも可能です。
