## Pythonライブラリ「sakura-orm」の基本的な使い方

`sakura-orm`は、ORM（Object-Relational Mapping）ライブラリの一つで、Pythonのオブジェクトとデータベースのテーブルをマッピングするためのツールです。特に、**シンプルで直感的な構文**でデータベース操作を行いたい場合に便利です。

ここでは、`sakura-orm`を使った基本的な使い方を、**セットアップからCRUD操作（作成、読み取り、更新、削除）**まで、具体的なコード例を交えて解説します。

### 1. 前提条件とインストール

まず、`sakura-orm`をインストールする必要があります。また、使用するデータベース（例：SQLite）と接続するためのドライバも必要になります。

```bash
# sakura-ormのインストール
pip install sakura-orm

# (例としてSQLiteを使用する場合) 
# 通常、SQLAlchemyなどの他のライブラリと組み合わせて使用することが多いですが、
# sakura-orm単体で動作させるための設定が必要です。
```

### 2. 基本的なモデル（テーブル）の定義

`sakura-orm`では、Pythonのクラスを定義することで、それがデータベースのテーブルに対応します。

**コード例1：モデルの定義**

```python
from sakura_orm import Model

# データベースのテーブルに対応するモデルを定義します
class Product(Model):
    # モデル名は通常、テーブル名にマッピングされますが、ここでは明示的に設定することも可能です
    __table_name = 'products'  # テーブル名を指定

    # カラム（フィールド）を定義します。型はPythonの型に従います。
    id = None  # 主キー (自動採番されることが多い)
    name = ""
    price = 0.0
    stock = 0
```

### 3. データベース接続と初期化

モデルを実際に操作するためには、データベースへの接続設定が必要です。`sakura-orm`は通常、設定ファイルやコンフィグを通じて接続情報を扱います。ここでは、簡単なセットアップの概念を示します。

**コード例2：データベースの初期化（概念的な説明）**

実際の具体的な接続方法は使用するバックエンド（SQLite, PostgreSQLなど）によって異なりますが、基本的な流れは以下のようになります。

```python
from sakura_orm import DatabaseManager

# データベース接続設定 (ここではSQLiteを想定)
DB_CONFIG = {
    "type": "sqlite",
    "path": "my_database.db"
}

# データベースマネージャの初期化と接続
db_manager = DatabaseManager(DB_CONFIG)

# モデルをデータベースに登録（テーブル作成）
# このステップで、Productクラスに対応する 'products' テーブルが作成されます。
db_manager.initialize_models([Product]) 

print("データベースの初期化が完了しました。")
```

### 4. CRUD操作の実装

モデルが定義され、データベースが初期化されたら、オブジェクトを操作します。

**コード例3：データの挿入（Create）**

```python
# 1. 新しいインスタンスを作成
new_product = Product(name="Laptop", price=1200.0, stock=50)

# 2. データベースに保存 (INSERT)
db_manager.save(new_product)
print(f"製品が保存されました: {new_product.name}")
```

**コード例4：データの読み取り（Read）**

```python
# すべての製品を取得 (SELECT *)
all_products = db_manager.find_all(Product)
print("\n--- 全製品 ---")
for product in all_products:
    print(f"ID: {product.id}, 名前: {product.name}, 価格: {product.price}")

# 特定のIDで取得 (SELECT by ID)
specific_product = db_manager.find_by_id(Product, 1) # ID=1 の製品を取得する場合
if specific_product:
    print(f"\n特定の製品情報: {specific_product.name} ({specific_product.price}円)")
```

**コード例5：データの更新（Update）**

```python
# ID=1 の製品の情報を更新 (UPDATE)
product_to_update = db_manager.find_by_id(Product, 1)

if product_to_update:
    product_to_update.price = 1150.0  # 価格を更新
    db_manager.update(product_to_update) # 変更をDBに反映
    print("\n製品情報が更新されました。")
```

**コード例6：データの削除（Delete）**

```python
# ID=1 の製品を削除 (DELETE)
product_to_delete = db_manager.find_by_id(Product, 1)

if product_to_delete:
    db_manager.delete(product_to_delete)
    print("\n製品が削除されました。")
```

### まとめとポイント

| 操作 | `sakura-orm`での主なメソッド | 説明 |
| :--- | :--- | :--- |
| **定義** | `class Model(Model): ...` | PythonクラスをDBテーブルとして定義します。 |
| **保存 (C)** | `db_manager.save(instance)` | 新しいレコードをデータベースに挿入します。 |
| **取得 (R)** | `db_manager.find_all(Model)` | すべてのレコードを取得します。 |
| **取得 (R)** | `db_manager.find_by_id(Model, id)` | 特定のIDを持つレコードを取得します。 |
| **更新 (U)** | `db_manager.update(instance)` | オブジェクトの変更をデータベースに反映させます。 |
| **削除 (D)** | `db_manager.delete(instance)` | 指定したレコードをデータベースから削除します。 |

**注意点:**

1. **設定の依存性:** 上記のコード例は概念的な流れを示しています。実際に動作させるためには、`DatabaseManager`がどのように具体的なDBドライバ（SQLAlchemyなど）と連携しているか、また接続文字列の設定方法をライブラリの公式ドキュメントで確認し、環境に合わせて実装する必要があります。
2. **トランザクション:** 複数の操作を同時に行う場合は、トランザクション管理が重要になります。

`sakura-orm`はシンプルさを追求していますが、実際のプロジェクトでは、より複雑なリレーションシップやエラーハンドリングのために、他のORMライブラリ（SQLAlchemyなど）との併用も検討されることが多いです。
